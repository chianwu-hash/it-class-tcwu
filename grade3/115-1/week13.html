任務一：Shift，大寫與符號

先切到英文、關閉Caps Lock，看看同一顆鍵怎麼變身！

小寫變大寫Shift ＋ Aa → A
數字樓上的符號Shift ＋ 11 → !
問號也在樓上Shift ＋ // → ?
  1. 先按住Shift不放，再輕按另一顆鍵。
  2. 放開Shift，接著打小寫字母；不要一直按住。
  3. 先試 a A ! ?，再打一句招呼 Hi!。

按完看看結果；這是自由練習，不需要按檢查。

單按一下Shift可能切換中英模式；如果突然打出不同語言，先看看輸入模式。這裡示範英文的半形 ! 和 ?。

從剪貼簿的清單，接到表情面板

任務二：表情百寶箱

上週看過老師從剪貼簿選內容；今天選一個新的表情，放在自己的句子後面！

① 點好位置② 開啟面板③ 選入表情④ 看看結果

Windows 鍵 ＋ . 逗號鍵右邊那顆 . 鍵

  1. 在下方輸入「今天我的心情很好！」，也可以先打「開心」。中文先選好字。
  2. 點句子後面，按Windows＋句號鍵。
  3. 選一個喜歡的表情，按Esc收合面板；看看表情是不是放在想要的位置。
  4. 再輸入一個字，試試面板收合後還能接著寫。有餘力再找「符號」分類。

表情自己選，不必和範例相同。這一句先留著，後面會帶到記事本接著做。

面板裡有表情、顏文字和符號，跟著老師認識。若出現剪貼簿歷程的「開啟」按鈕，今天不用按。

面板打不開，先告訴老師；可以改到記事本試試，仍不行就先用 :) 表示心情。

看看焦點在哪裡，再輸入

任務三：Tab走格子

Tab 下一格；Shift＋Tab 上一格。

  1. 點第一格「招呼語」，輸入 Hi!。
  2. 按Tab到「心情」，輸入「開心」。再按Shift＋Tab回到招呼語。
  3. 回來看到文字反白，先不要打字；這時輸入會取代原文。
  4. 按Tab兩次到「祝福」，輸入「祝你開心」。中文選好字後，按Enter換行，再放入一個符號。

點第一格開始，看見外框亮起，代表現在準備在這一格輸入。

在這個練習裡，Tab換欄位，Enter在第三格換行。中文選字時，Enter可能先確認候選字。

Tab也可能走到頁面的其他按鈕；找不到目前在哪裡，就用滑鼠點回第一格，再試一次。

網頁看任務，記事本接著做

任務四：Alt＋Tab換視窗

先跟老師開好「課程網頁」和「記事本」兩個視窗。切換視窗，原本的內容還會在！

課程網頁

看任務，複製自己的心情句。

記事本

貼入剛才的心情句，接著做留言卡。

Alt ＋ Tab：按住Alt、輕按Tab，選到目標後再放開Alt。

  1. 回到上方「我的心情句」，選取自己剛完成的文字，用上週學過的Ctrl＋C複製。
  2. 按Alt＋Tab切到記事本，點空白處，用Ctrl＋V貼入。
  3. 再按Alt＋Tab切回網頁，看接下來的留言卡任務。
  4. 回到記事本，確認剛貼入的句子還在。

看看視窗標題再決定。視窗很多時，按住Alt、再輕按幾次Tab，直到選到記事本。

這是切換不同視窗，不是切換瀏覽器分頁，也不會把視窗關掉。切錯了可以先用工作列找回來，再跟老師練一次。

把剛才的方法串起來

一起完成：鍵盤魔法留言卡

在記事本接著做，不用重打心情句。讓留言卡有招呼、心情、祝福三行！

Hi!
今天我的心情很好！😊
我想送你一個祝福：★
  1. 在心情句最前面按Enter，留出上方空白行；點回上方輸入 Hi!。H和!用Shift，i用小寫。
  2. 第二行保留自己的心情與表情，不必重新打一次。
  3. 點心情句最後，按Enter建立第三行。輸入「我想送你一個祝福：」，也可以只打「祝福」。
  4. 按Windows＋句號，切到符號分類，選入一個喜歡的符號；按Esc回來檢查。
  5. 用Alt＋Tab回到網頁核對，再切回記事本看看成果。
  • 三行有分開嗎？
  • 大寫、表情與符號放對位置嗎？
  • 切換視窗後，原來的內容還在嗎？

表情與符號自己選，不必和範例相同。這是當堂練習，請老師看看；不用上傳或繳交檔案。
