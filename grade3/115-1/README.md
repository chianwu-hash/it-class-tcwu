# 三年級 115 學年度上學期網頁

此資料夾放置三年級 115 學年度上學期的教學網頁與網頁用資產，避免和 114 學年度下學期舊週頁混在 `grade3/` 根目錄。

## 放置規則

- 週頁：`week01.html`、`week02.html`
- 學期首頁：`index.html`
- 學期 navbar：`navbar.js`
- 圖片資產：`images/weekXX/`

## 路徑注意

- 115-1 週頁位於 `grade3/115-1/`，引用 shared module 時要使用 `../../shared/...`。
- 115-1 週頁引用本學期圖片時，優先使用 `images/weekXX/...`。
- 不要在 115-1 新頁面引用 `grade3/images/weekXX/` 的舊學年度資產，除非已確認是跨學年度共用素材。
- 現有 `week_visibility` 尚未區分學年度。115-1 首頁若要做週卡可見性控制，需先調整資料設計或另訂規則，避免和舊 114 週碼互相影響。
- 根目錄 `index.html` 的目前學年度三年級入口應連到 `grade3/115-1/index.html`；舊 `grade3/index.html` 只作為 114-2 封存入口。

## 舊頁面

- 114 學年度下學期既有網頁目前仍保留在 `grade3/` 根目錄，避免破壞已發布連結。
- 新學年度頁面從本資料夾開始建立。
