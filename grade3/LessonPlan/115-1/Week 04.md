- 節數：1 節（40 分鐘）

## 單元定位與設計理由

第 01～03 週多數操作在教學網頁內完成。本週不再安排多個彼此分散的網頁活動，而以「取得英文姓名通行證」作為單一任務情境，讓學生把已在網頁中練過的點選、拖曳、視窗控制與小寫輸入，轉移到真實 Windows 操作。

本週的螺旋學習只帶回與主線直接相關的舊技能：

| 先前技能 | 本週再次使用 | 本週提升 |
| --- | --- | --- |
| 第 02 週：最大化、還原、最小化、從工作列找回 | 在課程網頁與任務資料夾之間切換 | 從模擬視窗轉移到真實 Windows 視窗 |

## 本週教學邊界

1. **本週只教單按 `Shift` 切換中／英文輸入模式。**學生輸入英文前先看 Windows 右下角；顯示「中」時，單按一次 `Shift` 切成「英」。本週不教 `Shift`＋字母輸入單一大寫，也不教 `Shift` 搭配上排特殊符號，避免把「中英文切換」與「大小寫輸入」混在一起；姓名第一字大寫仍使用狀態較明確的 `Caps Lock`。
2. 本週不教完整標準指法、`F`／`J` 定位凸點與十指分工；這些內容留待後續鍵盤主題。
3. 右鍵功能表只練習「叫出來、觀察、收起來」，不操作刪除、重新命名、內容或顯示其他選項。
4. 不以操作速度排名；評量重點是能依目的選擇正確操作，並在失敗後自行重試。
5. `Caps Lock` 只影響英文字母大小寫。學生完成姓名後必須再按一次關閉，避免影響下一次輸入。

## 課前準備

1. 延續第 01～03 週進教室、點名、座位、課堂身分卡及求助規則。
2. **教師於課前使用電腦教室管理系統，將練習資料夾 `第04關任務箱` 統一發送到每臺學生電腦桌面。**資料夾由教師端準備，不是課程網頁自動建立；學生不建立、不複製，也不重新命名。若管理系統無法發送，改用隨身碟或共用資料夾手動複製，並於課前逐臺確認。
3. `第04關任務箱` 內放置圖片 `藏寶圖.png`，內容為光精靈 2、火精靈 4、海精靈 8、樹精靈 16；四張數字牌上方直接標示精靈名稱，避免學生只靠外型猜測。另放置 16 張安全文字線索卡。課前把檔案總管縮到一次約看見 6～8 個項目，確認學生必須使用滾輪才能找到藏寶圖。不要使用系統重要圖示、學生個人檔案或不可復原資料作為右鍵與雙擊目標。
4. 課前逐臺確認滑鼠左鍵、右鍵與滾輪可用；確認雙擊速度設定不致讓大多數學生難以操作。個別設備若雙擊異常，先更換滑鼠或座位，不在課堂中帶全班修改系統設定。
5. 確認學生鍵盤的 `Caps Lock` 可用。若鍵盤沒有明顯指示燈，以實際輸入 `a`／`A` 確認狀態，不要求學生尋找不存在的燈。
6. 準備課程網頁中的姓名輸入區，範例與輸入框要同時可見；正式製作網頁時，使用課堂身分卡與 `guest_progress` 保存打字進度。課前確認工作列右下角能看見「中／英」狀態，並實測單按 `Shift` 可切換；網頁需提供 Shift 鍵位置提示。本週只把「中切英」列為輸入前排錯步驟，不延伸教授 Shift 組合鍵。
7. 教師先實際走完「完成 `Mia`→讀取分組算式→最小化課程網頁→雙擊 `第04關任務箱`→在 `藏寶圖` 上右鍵觀察並收起→移動與縮放視窗→滾輪找回 `藏寶圖`→雙擊開圖→從工作列找回課程→只輸入算式的數字答案」全流程，確認不同電腦畫面與捷徑位置一致。
8. 若 Windows 桌面或檔案總管介面和課本 2023 年畫面不同，以現場畫面示範為準，並說明這是目前介面的調整，不把新版差異說成課本原圖內容。

## 主線任務：找到 Mia 的英文姓名通行證

### 任務情境

> 彩虹精靈把通關數字藏在桌面的 `第04關任務箱`。先在教學區練習 `Mia`，再把相同方法用在正式姓名 `Leo` 並取得自己的算式；接著用正確的 Windows 操作找到 `藏寶圖`，回到網頁只輸入算式的數字答案。

全班只使用這一條故事線。教學網頁負責顯示當前任務、姓名輸入與完成回饋；滑鼠與視窗的核心操作必須回到真實 Windows 完成，不以網頁模擬取代。

### 第一關：練習 Mia，再用 Leo 取得分組算式

1. 先看著四步驟在教學區完成 `Mia`，即時確認 `mia`、`Mia`、`MIA` 的差別；答對後再把同一方法轉移到正式第 1 關 `Leo`。
2. 通過後，網頁依課堂身分卡的座號分成五組，顯示一題只有精靈名稱、沒有數值的算式。
3. 先看清楚兩位精靈與運算符號，再開始 Windows 尋寶。

### 第二關：前往桌面，打開任務箱

1. 在課程網頁按最小化，把視窗暫時收進工作列。
2. 在桌面找到老師課前已經放好的 `第04關任務箱`；不用自己新增或改名字。
3. 游標停在圖示上，快速按兩下左鍵。
4. 若圖示只有反白而沒有開啟，保持滑鼠不要移動，再把兩次點擊縮短。

口訣：

> 同一個位置，快速點兩下。

教師觀察：

- 是否把雙擊做成兩次相隔太久的單擊。
- 兩次點擊之間是否移動滑鼠，造成圖示被拖曳。
- 開啟後是否等待老師指令，不繼續任意點選檔案。

### 第三關：請藏寶圖守衛現身

1. 在 `藏寶圖` 圖示上按一下右鍵。
2. 觀察出現的快捷功能表；不同圖示的功能可能不同。
3. 不選任何功能，移到空白處按一下左鍵，把功能表收起來。

口訣：

> 找功能，按右鍵；先觀察，不亂選。

教師觀察：

- 是否真的按右鍵，而不是再度雙擊左鍵。
- 功能表出現後能否停手觀察。
- 是否能點空白處安全收起，而不是點到刪除或重新命名。

### 第四關：整理任務視窗

1. 按最大化，再按還原，複習兩種視窗狀態。
2. 在視窗最上方的標題列按住左鍵，拖曳到指定位置後放開。
3. 把游標移到視窗角落，等待游標變成斜向雙箭頭。
4. 按住左鍵拖曳，將視窗調整成仍看得到內容與桌面的大小。

口訣：

> 標題列搬位置，角落拖曳改大小。

教師觀察：

- 移動視窗時是否抓住標題列，而不是內容區。
- 調整大小前是否先看到雙向箭頭。
- 是否能延續第 03 週「按住、移動、放開」的動作節奏。

### 第五關：使用滾輪找到藏寶圖

1. 將滑鼠指標移到任務資料夾內容區。
2. 滑動滾輪向下尋找 `藏寶圖`。
3. 找到後停下，不繼續快速滾動；快速按兩下左鍵把圖片打開。
4. 依自己的算式，記住兩位精靈牌子上的數字。

口訣：

> 看下面，往下滾；要回去，往上滾。

教師觀察：

- 學生是否知道內容移動不等於圖示被搬走。
- 是否能控制小幅度滾動，而不是一次滾到底後找不到目標。
- 游標是否在可捲動的內容區；若滾輪無反應，先檢查目前視窗焦點。

### 第六關：回到課程網頁，交出通關密語

1. 將任務視窗最小化或依教師指令保留。
2. 在工作列找到原本仍開啟的課程瀏覽器。
3. 按一下瀏覽器圖示，把課程網頁找回來。
4. 完成網頁上的算式，在第 2 關只輸入數字答案，例如 `6`；不用再輸入 `Mia`。

這一關承接第 02 週的「最小化後從工作列找回」，不另做模擬視窗。

## 英文姓名通行證：從 mia 到 Mia

### 英語文本來源

- 國語來源：本週無中文打字或中英混合打字，標記 N/A。
- 英語版本：翰林 Here We Go 1，第一冊，Unit 1〈What’s Your Name?〉。
- 取材頁碼：學生課本 p.12～19。
- 原文可見 `My name is Mia.`、`I’m Abu.` 等姓名用法。
- 取材理由：第 03 週已用同一單元的 `mia`、`abu` 練習小寫字母。本週不換一批無關文字，而是把相同姓名改成符合英文姓名慣例的 `Mia`、`Abu`，讓大小寫操作具有語文意義。

### 概念比較

| 寫法 | 本週說明 |
| --- | --- |
| `mia` | 三個都是小寫；第 03 週曾用來練習找字母 |
| `Mia` | 英文姓名的一般寫法；第一個字母大寫 |
| `MIA` | 三個字母全是大寫；本週不是要完成的姓名寫法 |

### 輸入英文前先確認「中／英」

1. 看 Windows 工作列右下角的輸入法狀態。
2. 若顯示「中」，單按一次 `Shift`，確認變成「英」。
3. 再點回網頁輸入框開始輸入。

本步驟只處理中文模式干擾。不要按住 Shift 再打英文字母；姓名第一字大寫仍依下一段使用 `Caps Lock`。

### Caps Lock 操作步驟

以 `Mia` 為例：

1. 先確認輸入框是空白的。
2. 按一下 `Caps Lock`，開啟大寫狀態。
3. 輸入 `M`。
4. 再按一下 `Caps Lock`，關閉大寫狀態。
5. 接著輸入 `ia`。
6. 檢查結果是 `Mia`，不是 `mia` 或 `MIA`。

口訣：

> 名字第一字要大寫：開大寫、打一字、關大寫、接著打小寫。

若鍵盤沒有指示燈，請學生看輸入結果確認狀態；不把找燈當成過關條件。若輸入成 `MIA`，先引導學生觀察 `Caps Lock` 是否忘了關閉，再用 Backspace 修正，不直接替學生清空重打。

### 本週姓名輸入關卡草案

定位：同一打字活動共 6 關；正式第 1 關 `Leo` 是全班鍵盤檢核，第 2 關是彩虹精靈 Windows 尋寶主線，第 3～6 關是快手延伸。課堂前段另有兩關暖身：先輸入小寫 `mia`，再把預先出現的錯字 `Abw` 用 Backspace 修正為 `Abu`；Caps Lock 教學區另有一個可直接對照四步驟輸入 `Mia` 的即時練習框。暖身與即時練習只供教師觀察，不另存正式進度。下列 6 關需先確認課堂身分卡，並將逐關完成狀態保存到 `guest_progress`。不計時、不排名。

```javascript
const levelsData = [
  { id: 1, ans: "Leo" },
  { id: 2, ans: String(seatAnswer) },
  { id: 3, ans: "Abu" },
  { id: 4, ans: "MIA" },
  { id: 5, ans: "Mia, Abu" },
  { id: 6, ans: "My name is Mia." }
];
```

- 第 1 關 `Leo`：全班鍵盤最低標準。把剛才看著步驟完成 `Mia` 的方法轉移到不同姓名；首字大寫，其餘字母小寫，完成後解鎖尋寶。
- 第 2 關數字答案：彩虹精靈尋寶主線。座號以 `(seatNo - 1) % 5` 分組，依序使用「光＋火＝6、樹－火＝12、海＋光＝10、火×海＝32、樹－光＝14」；網頁只顯示精靈名稱與運算符號，學生必須到藏寶圖查數值，回來只輸入運算結果。
- 第 3 關 `Abu`：快手任務 1。換一個 Unit 1 人名，再做一次「開大寫、打一字、關大寫、接小寫」。
- 第 4 關 `MIA`：快手任務 2。情境為精靈任務的全大寫代碼；開啟 `Caps Lock` 後連續輸入，再關閉。
- 第 5 關 `Mia, Abu`：快手任務 3。輸入精靈同行姓名清單，加入英文半形逗號與逗號後的空格。
- 第 6 關 `My name is Mia.`：快手任務 4，也是向彩虹精靈完整介紹自己的綜合關卡。文字取自 Unit 1 原句，包含兩個首字大寫位置、三個空格與英文半形句點。
- 每關第一次答對後同時顯示「再練習一次」與「前往下一關」。再練習必須換成同技能的不同題目：第 1 關 `Leo ↔ Ben`、第 2 關輪換到下一組不同精靈算式、第 3 關 `Abu ↔ Mia`、第 4 關 `MIA ↔ ABU`、第 5 關 `Mia, Abu ↔ Abu, Mia`、第 6 關 `My name is Mia. ↔ My name is Abu.`。兩題可交替重複，但不得連續出現同一題。
- 第一次答對才保存正式進度與解鎖下一關；「再練習一次」是額外熟練，不再寫入 `guest_progress`，不得把學生已到達的關卡倒退。
- 完成後提醒再次確認 `Caps Lock` 已關閉。

第 2 關把 Windows 操作、精靈數值與單一算式串成主線，最後只交出數字答案，避免在複雜操作後再增加輸入負擔；第 3～6 關才是由短到長的快手延伸。逗號、句點都使用英文模式下不需要 Shift 組合鍵的按鍵；本週的 `Shift` 只單按切換中／英文，不出現 `!`、`?`、冒號等需要 Shift 組合鍵的符號。

## 評量與分層

### 主線任務完成標準

1. 能快速按兩下左鍵，開啟指定任務資料夾。
2. 能在指定圖示按一下右鍵叫出快捷功能表，再點空白處安全收起。
3. 能拖曳標題列移動視窗，並從角落拖曳調整大小。
4. 能使用滾輪找到 `藏寶圖`，雙擊開圖並查到算式所需數值。
5. 能從工作列找回課程網頁。
6. 遇到右下角顯示「中」時，能單按 `Shift` 切成「英」，再使用 `Caps Lock` 完成 `Mia`，並輸入正整數答案完成第 2 關。

### 教師觀察與後台檢核

- Windows 操作以教師現場觀察為主；不能只因學生最後打出 `Mia`，就推定前面的雙擊、右鍵、縮放與滾輪都已完成。
- 可使用一張座位表或簡短檢核記號，記錄學生是否完成「雙擊／右鍵／縮放／滾輪」四項實作。
- 姓名輸入若製作成正式網頁打字關卡，使用共用打字模組與課堂身分卡進度；教師後台檢核 `weekCode: "04"` 與對應 activityKey。
- 學生若由同學協助，協助者只能指位置或示範一次，不代替操作。

### 分層策略

- **基礎組**：任務箱放在固定且明顯的位置；教師貼近示範雙擊節奏；視窗只要求完成一次角落縮放；先在說明下方完成 `Mia` 練習，再完成正式第 1 關 `Leo`。
- **標準組**：依序完成雙擊、右鍵、移動、縮放、滾輪與工作列找回；完成第 2 關分組密語。
- **挑戰組**：不看逐步口令完成縮短版 Windows 任務，並完成主線及快手全部 6 關，正確保留大小寫、空格、數字、逗號與句點。

### 快手與延伸任務

- 快手任務名稱：「英文通行證進階挑戰」，內容是同一打字活動的第 3～6 關；第 2 關尋寶屬於本週 Windows 主線，不另開新網站。
- 快手完成標準：第 3～6 關全部正確完成，並在最後確認 `Caps Lock` 已關閉。
- 快手任務只使用本週已教或已複習的按鍵：單按 `Shift` 切換中／英文、英文字母、`Caps Lock`、空白鍵、數字、英文半形逗號與句點。
- 若仍有餘力，可請學生用一句話比較：「點一下是選取，快速點兩下是開啟，按一下右鍵是看功能。」這是口頭延伸，不新增操作關卡。
- 快手任務不加入 `Shift` 組合鍵、驚嘆號、問號、完整標準指法或檔案刪除／重新命名。

### 時間不足時的保底完成項目

優先確保每位學生親自完成：

1. 雙擊開啟任務箱。
2. 右鍵叫出功能表並安全收起。
3. 至少一次拖曳視窗角落調整大小。
4. 使用滾輪找到並雙擊 `藏寶圖`。
5. 回到網頁只輸入算式的數字答案，並確認 `Caps Lock` 已關閉。

若課程進行到第 30 分鐘仍有多數學生停在 Windows 操作，教師先帶全班完成第 2 關；第 3～6 關維持快手性質，不以教師代操作或口頭回答冒充實作完成。

## 常見卡關與引導

| 情況 | 教師提示與處理 |
| --- | --- |
| 雙擊後只有反白 | 「滑鼠先不要移動，兩下要在同一個位置，而且要靠近一點。」 |
| 雙擊變成拖曳圖示 | 提醒手掌放鬆、兩次點擊時不要推動滑鼠；必要時換較穩定的桌面位置 |
| 右鍵功能表出現後不知怎麼收 | 「移到沒有圖示的空白處，按一下左鍵。」 |
| 拖不到整個視窗 | 「搬視窗要抓最上面的標題列，不要抓裡面的檔案。」 |
| 視窗角落游標沒有變化 | 放慢速度靠近邊界，先看到雙向箭頭再按住拖曳 |
| 滾輪沒有反應 | 先把游標移回內容區並按一下，確認目前操作的是任務視窗 |
| 輸入英文卻出現注音或中文字 | 先看右下角；若顯示「中」，單按一次 `Shift` 切成「英」，再回到輸入框 |
| 輸入成 `mia` | 檢查是否還沒開啟 `Caps Lock`，刪除後重新輸入第一個字母 |
| 輸入成 `MIA` | 檢查輸入 `M` 後是否忘了關閉 `Caps Lock`，用 Backspace 修正 |
| 完成後下一次仍全是大寫 | 再按一次 `Caps Lock`，輸入一個測試小寫字母確認已關閉 |

## 網頁功能契約草案

- 頁面名稱：`grade3/115-1/week04.html`
- 年級：grade3
- 類型：C 打字闖關頁；但頁面定位以顯示單一任務流程與姓名輸入為主，Windows 操作不做成多站式網頁模擬
- 參考頁面：`grade3/115-1/week03.html` 與 `grade3/115-1/week03.js` 的課堂身分卡、打字進度與共用鍵盤提示；版面應比第 03 週更集中
- Navbar：使用 `grade3/115-1/navbar.js?v=YYYYMMDD`，不可手刻導覽列
- 身分流程：沿用 115-1 三年級課堂身分卡；同頁不顯示 Google 登入入口
- Auth：使用 `initClassCardAuth({ courseId: "grade3-115-1", mode: "required" })`
- Windows 操作進度：以現場觀察為主；除非後續明確設計可可靠驗證的回報機制，否則不因學生點「完成」就寫入正式過關紀錄
- 姓名打字：使用 `initTypingChallenge()` 搭配 `guestProgress`，不自行重寫進度邏輯
- `weekCode`：`"04"`
- 姓名打字 activityKey 草案：`typing_task_6`
- `levelsData`：使用 `{ id, ans }`；依序為 `Leo`、動態數字答案、`Abu`、`MIA`、`Mia, Abu`、`My name is Mia.`
- 再練習：每關至少 2 題；答對後留在原卡片，由學生選「再練習一次」或「前往下一關」。再練習換題、清空輸入與提示，但不回寫正式進度
- 最低完成標準：先完成教學區的 `Mia` 即時練習，再完成正式第 1 關 `Leo`；正式過關後顯示「尋寶已解鎖」。第 2 關為本週 Windows 主線，通過後顯示主線完成；第 3～6 關標示為快手延伸
- 共用工具：使用 `shared/typing-tools.js` 顯示英文目標字母，並提供 Backspace、Caps Lock 與 Shift 的滑入／焦點位置提示；Shift 只說明單按切換中／英文，不加入完整標準指法或 Shift 組合鍵教學
- 未確認課堂身分卡前：姓名輸入框與檢查按鈕必須鎖定；不可先完成後才發現無法保存
- 進度：透過 `createClassCardProgress()` 寫入 `guest_progress`，不可使用 localStorage 保存活動進度
- 繳交功能：無；本週不建立作品作業、不提供上傳入口，也不使用六年級作業或閱讀服務
- 解鎖邏輯：教學區 `Mia` 僅提供即時練習，不寫進度；完成正式第 1 關 `Leo` 後由 `initTypingChallenge()` 解鎖第 2 關尋寶；完成動態數字答案後顯示本週主線完成提示
- 努力樹：三年級 115-1 目前不支援 `guest_progress`，頁面與完成提示不得顯示或承諾努力樹獎勵
- 備援：若任務資料夾未部署或 Windows 操作環境異常，教師以投影帶全班辨認操作，學生仍需在可用電腦上輪流完成至少雙擊、右鍵、縮放與滾輪；姓名輸入保留 `Mia` 最低任務
