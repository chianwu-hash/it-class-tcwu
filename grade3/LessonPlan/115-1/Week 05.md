# 三年級資訊課教案｜Week 05

- 學年度／學期：115 學年度第一學期（三年級上學期）
- 週次：第 05 週；1 節，40 分鐘
- 主題：鍵盤辨字偵探與我的 Windows 桌面
- 教材或平台：巨岩《Windows 11 電腦小小兵》S088、115-1 三年級資訊課程網站、學生電腦的 Windows 桌面與設定
- 課本參考：第 3 課 p.56～57（更換佈景主題）、p.61（從 Microsoft Store 取得更多佈景主題）；第 5 課 p.100（英數鍵與 Backspace）、p.101（Caps Lock 狀態）、p.107（按住 Shift 輸入大寫字母）、p.110（刪除與修改文字）。辨認相似字元、個人帳號英打與虛構密碼格式題是依課本鍵盤技能設計的補充練習。

## 教學定位與本週邊界

第 03 週已練習小寫字母與 Backspace；第 04 週練習單按 Shift 切換中／英輸入模式、Caps Lock 及最小化後從工作列找回視窗。本週先用可換題的暖身練習**Caps Lock 連續大寫**，再用英文名字引出**按住 Shift、點一下字母、放開 Shift，暫時輸入一個大寫字母**。容易認錯的 `L／l／1`、`O／o／0` 獨立成第三組暖身，並用英文單字與虛構帳號情境逐碼輸入。接著進入真正的 Windows 桌面，利用桌面右鍵與「個人化 → 佈景主題」選擇電腦內建的主題。英打快手第 4 關顯示學生自己的學校帳號，讓學生反覆輸入；第 5、6 關以虛構題預習密碼格式。

**本週不發帳號密碼條；自己的帳號由網站在確認課堂身分卡後顯示。**本週不輸入學生的身分證字號或新密碼，也不登入親師生平台。第 06 週才發個人帳號密碼條，依紙條練習真實登入；若下週正式流程另有調整，須在第 06 週教案確認。公開範例不可直接當作新密碼。

## 課前準備

1. 確認課堂身分卡與第 05 週網頁可用，第 4 關能依本人身分取得帳號，英打闖關能寫入 `guest_progress`；本週不發放個人帳密條。
2. 在一臺學生電腦實走「最小化網頁 → 桌面空白處右鍵 → 個人化 → 佈景主題 → 選一套已有主題 → 最小化設定 → 從工作列找回網頁」。記下原主題，確認課末可還原；若教室管理政策鎖定個人化，改用教師畫面示範，學生口述每一步並練最小化／找回。
3. 課前確認電腦上可選的主題縮圖與 2023 年課本畫面的差異，以現場介面為準。教室電腦若會還原，告訴學生下次主題可能恢復；若不會還原，課末由學生依老師指示改回原主題。
4. 若要開放 Store 延伸任務，教師先確認「瀏覽主題／取得更多佈景主題」入口可用，且可取得免費主題。需要個人帳號、付費或受學校政策限制時，只示範入口，不要求學生完成安裝。
5. 教師示範暖身時使用 `ABC`、`Amy`、`lone` 等公開題目；辨字進階題 `lone01` 是虛構帳號字串。正式闖關另用 `l1o0`、`Hi`、`A0o1`、`A123456780`、`apple1234`。第 4 關的真實帳號只在本人畫面顯示，不投影任何學生的帳號、身分證字號或密碼。

## 教學流程（40 分鐘）

| 時間 | 活動定位與內容 | 教師重點 | 學生表現 |
| --- | --- | --- | --- |
| 0～4 分鐘 | 暖身與課堂身分卡 | 確認輸入法是「英」；說明本週在本人畫面練真實帳號，下週才發個人紙條 | 完成課堂身分卡，辨認右下角輸入法狀態 |
| 4～12 分鐘 | 三組可換題暖身 | 先用 Caps Lock 輸入連續大寫並關閉；接著以名字示範 Shift 只讓開頭大寫；最後在鍵盤圖找 `L／O` 與 `1／0`，對照大寫鍵帽、小寫輸出及逐碼提示 | 各組先做一題，答對後有餘裕再換題；能指出 Caps Lock、Shift、L、O、1、0 的位置 |
| 12～21 分鐘 | Windows 個人化：更換佈景主題 | 示範桌面空白處右鍵進「個人化 → 佈景主題」，選一套電腦已有主題；早完成者可在老師確認後進行 Store 延伸 | 觀察桌布／色彩變化，從工作列找回課程頁；Store 延伸不列入全班標準 |
| 21～29 分鐘 | 網頁鍵盤第 1～3 關 | 引導逐碼看題與錯誤提示；這三關接續暖身並保存正式進度 | 完成 `l1o0`、`Hi`、`A0o1`，發現錯字自行修正 |
| 29～38 分鐘 | 必做快手：自己的帳號 | 第 4 關只在本人畫面顯示帳號；先看著輸入，過關後用「再練習一次」至少重打一次。第 5、6 關虛構密碼格式題留給快手學生 | 親手打自己的帳號至少兩遍，不朗讀、不複製；有餘裕者預習虛構密碼格式 |
| 38～40 分鐘 | 收尾與檢核 | 複述 Caps Lock 與 Shift 的不同時機，確認桌面依教室要求還原；預告下週發紙條 | 說出一個辨字方法、一個桌面操作步驟，整理座位 |

暖身的「換一題」供已完成者加練，不逐題點名或儲存成績；第 12 分鐘應轉入 Windows 任務。若第 21 分鐘仍有多數學生在找佈景主題，教師先帶全班停在目前步驟，讓學生回到課程頁，課末再用教師畫面總結；保留第 1～4 關時間。Store 與第 5～6 關是延伸，不列入全班最低完成標準。

## 關卡內容與素材來源

本週沒有國語課文、中打或英語課文取材；國語與英語課本來源為 N/A。`Hi` 取自 S088 第 5 課 p.107；`Amy` 可參考 p.110。Caps Lock 暖身 `ABC／DOG／VIP`、Shift 名字暖身 `Amy／Tom／Lily` 與辨字暖身 `lone／login／lone01` 為本課自編題；其中 `lone01` 是虛構帳號情境，不是學生帳號。第 1～3 與第 5～6 關為自編虛構題。第 4 關在課堂身分卡確認後，從教師核對的名冊取得該學生的真實學校帳號，不把全班帳號寫進網頁原始碼。

| 關別 | 題目 | 學習重點 | 定位 |
| --- | --- | --- | --- |
| 1 | `l1o0` | 字母與數字辨認 | 主線 |
| 2 | `Hi` | Shift 暫時大寫 | 主線 |
| 3 | `A0o1` | 大寫、小寫與數字混合；Backspace 修正 | 主線 |
| 4 | 學生自己的學校帳號（逐人由受控查詢取得） | 看著帳號逐碼輸入；過關後至少用同一帳號再練一次 | 必做快手 |
| 5 | `A123456780` | 一碼大寫加九個數字的虛構預設密碼格式；不是身分證字號 | 英打快手 |
| 6 | `apple1234` | 小寫英文單字加數字的公開格式範例；不得直接作為新密碼 | 英打快手 |

頁面可提示下一個按鍵、錯誤位置與 Backspace 修正，不自動將 `o` 改為 `0` 或把 `l` 改為 `1`。第 4 關重玩時仍練**同一位學生自己的帳號**，第 1～3、5～6 關重玩才更換虛構字串；重玩不得讓已保存進度倒退。網站的關卡進度只保存關別與完成狀態，不把學生帳號或輸入內容寫入 `guest_progress`、網址或瀏覽器儲存空間。

## Windows 個人化操作與卡關處理

1. **回到桌面**：把瀏覽器最小化，不關閉分頁；在桌面空白處按右鍵。這一步延續第 04 週的真實 Windows 操作。
2. **找佈景主題**：選「個人化」，進入「佈景主題」（有些 Windows 畫面顯示「主題」）。課本 p.56 有對應位置，現場介面以學生電腦為準。
3. **選已有主題**：先認出目前主題，再從縮圖選另一套。課本 p.57 示範選主題後觀察桌布；不要求學生一定找到課本上的同名主題。
4. **觀察與回來**：最小化設定視窗，觀察桌布與色彩變化；從工作列按瀏覽器圖示回到本週網頁。課末依老師指示恢復原主題。

**延伸任務（選做）**：完成主線且教師確認 Store 可用時，在佈景主題頁選「瀏覽主題／取得更多佈景主題」，進入 Microsoft Store 找一套免費主題，按「取得」或「安裝」，再回佈景主題頁套用。若出現登入、付費或學校限制，就停下來告訴老師，不自行輸入個人帳號或付款資料。此延伸對應 S088 p.61 的「從 Microsoft Store 取得更多佈景主題」。

如果右鍵點在圖示上而看不到「個人化」，移到桌面空白處再試。若設定被學校政策鎖定，不要求學生反覆嘗試；改看教師示範並完成最小化／找回操作。

## 評量與分層

- **全班最低標準**：三組暖身各練一題，第 1～4 關完成並保存，第 4 關過關後至少再輸入一次自己的帳號；學生實際嘗試 Windows 更換佈景主題，或在被鎖定時能指出教師示範步驟；知道本週不發帳密條。
- **基礎組**：使用鍵盤位置與逐碼提示，教師可指鍵位但不代打；桌面操作按網頁四步驟逐項做。
- **標準組**：主線完成後自行更換內建佈景主題、找回網頁；第 4 關自己的帳號輸入至少兩遍。
- **挑戰組**：完成第 5～6 關並使用「再練習一次」換虛構題；第 4 關可再重打自己的帳號。若教師已確認 Store 可用，可做 Store 延伸。不在本週設定真實密碼。
- **教師檢核**：後台查看 `guest_progress` 的關別（第 4 關過關後會進到第 5 關）；第 4 關重打次數與 Windows 操作由教師現場觀察，後台進度不代表桌面任務已完成。

## 網頁功能契約

- 頁面：`grade3/115-1/week05.html`，115-1 三年級 C 類打字闖關頁，另有靜態 Windows 個人化實作指引。舊 `grade3/week05.html` 屬 114 學年度，不修改。
- 使用學期 `navbar.js`、`initNavbarAuth()`、`initClassCardAuth()`、`createClassCardProgress()`、`initTypingChallenge()` 與共用鍵盤提示。課堂身分卡確認前鎖定闖關，同頁不顯示 Google 登入。
- 頁首另有三組課堂身分卡後可操作的暖身：Caps Lock 連續大寫、Shift 名字開頭大寫、`L／l／1` 與 `O／o／0` 辨字。每組可換題、可看鍵盤位置與逐碼提示；暖身不寫入 `guest_progress`，不改變六關正式進度。
- `courseId: 'grade3-115-1'`、`weekCode: '05'`、`activityKey: 'typing_task_5'`；六關資料使用 `{ id, ans }`，進度經 `guestProgress` 寫入 `guest_progress`，不使用 localStorage 記關卡進度。
- `class_card_students` 的 `practice_account` 只保存校方產生的帳號，不匯入身分證字號、預設密碼或新密碼。第 4 關透過受控 RPC 以課堂身分卡的班級、座號與生日四碼查自己的帳號；不把全班帳號嵌進 HTML／JS，不把帳號加入課堂身分卡的 localStorage 物件。課堂身分卡不是正式平台登入，故本週只提供帳號練習，不提供真實密碼。
- 帳號查詢失敗時，第 4 關鎖住並提示找老師，不用虛構帳號冒充本人。首頁、navbar 與完成提示不得導向尚未支援的努力樹。
- 驗證重點：本人與錯誤身分不得互看帳號、進度保存與重整接回、同一帳號重玩不倒退、切換課堂身分後舊帳號消失、網路與進度資料不含學生帳號，以及 Windows 四步驟文字與下週發條時點一致。真正的 Windows 設定是否可用，需在教室學生電腦課前實測。
