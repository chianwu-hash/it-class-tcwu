# 英語題文 Andika 字型

- 字型：Andika 7.000，SIL Global。
- 用途：考前練功房英語題目、選項、共用材料與解析中的英文字母，作為接近國小英語課本字形的替代字型；不是課本同款字型。
- 官方下載：https://software.sil.org/andika/download/
- 原始套件：https://software.sil.org/downloads/r/andika/Andika-7.000.zip
- 授權：SIL Open Font License 1.1，完整原文見同目錄 `OFL.txt`。
- 僅使用官方未修改的 Regular、Bold WOFF2，並由本站供應，使用者不必自行安裝。
- 不含從出版社 PDF 擷取的字型。課本字型比對與選擇依據見 `docs/development/quiz-english-font-20261027.md`。
