# 三年級數學選答 5 題上線收據

- 本批為規則群 dry-run 通過的 5 題，候選 SHA 與隔離等值讀回證據逐題吻合。133 題維持原分流。
- 既有專用帳號以一份私有卷完成正式 OAuth。逐一操作 14 個選項，核對畫面內容、順序與原選項 ID。5 題皆透過介面送答，判分全對，同一請求重試皆只保留一筆，正式庫讀回的 5 個答案 ID 與原鍵相符，5 份解析皆可回看。
- 重新整理後，桌面及手機寬度均可回顧整卷。2 個題目媒體與 3 張教材頁通過正式供圖與 SHA 核對。答前隱藏答案、正式匿名拒絕及隔離環境同班其他帳號拒絕均通過。
- 正式庫先停用匯入，逐題比對後以同一筆交易啟用。啟用後題庫、課程關聯及學習來源各 5 筆與凍結資料一致。沿用現行網站及資料庫函式。
- 私有清冊及總帳更新至 v31，累計上線 221 題。逐題資料、OAuth 證據與 SQL 收據留存於私有工作目錄。
