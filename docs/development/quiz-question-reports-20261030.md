# 題目與選項出錯回報（2026-10-30）

學生在答題畫面按「題目出錯回報」，用文字描述錯誤後按「送出回報」。系統自動附上本人身分、題目、試卷版本、當時選項順序；也可選問題類型及特定選項。老師從「教師後台 → 題目出錯回報」進入題庫工作臺的回報區，查看原題、標記狀態及填寫教師備註。

## 適用範圍

- 三／六年級考前練功坊的一般卷、老師準備的卷、自組卷、整卷作答回顧及「我的錯題」。
- 考古題每組的答題畫面。回報記錄該次作答的固定版本，而非日後重新開放的新版本。
- 問題類型為題目、選項、答案、解析、媒體及其他。文字必填，最多 1000 字；不需學生複製題目或截圖。
- 回報顯示於後台，不另寄電子郵件。標記「已處理」僅更新處理紀錄；修改正式題庫及既有作答仍須另行核對。

## 資料與權限

新增 `quiz_question_reports` 與 `quiz_question_report(jsonb)` RPC。學生只能對本人已加入的題目送出回報，不接受前端提供的身分、題幹或正解。一般卷由 attempt 的題序、選項順序和固定版本建立快照，考古題由 attempt.version_id 建立題組快照。學生端僅取得回報識別碼及狀態，沒有教師快照、正解或其他人的回報。

資料表開啟 RLS，撤銷 anon／authenticated 直接存取。只有現有 `is_teacher()` 教師可列出、查看及更新全站回報，包含學生自組卷。現有教師題庫草稿仍維持原建立者限制。伺服器保存核對過的學生名冊身分，不採信前端欄位。

同一人同一 request_id 的相同內容重試只保存一次；變更內容卻重用識別碼會拒絕。每人每小時最多 20 筆，重試既有回報不占新額度。教師更新需符合原 updated_at，避免覆寫其他老師的新處理。

媒體沿用現有 quiz-media Edge signer，未部署或更換 Edge／Worker。原 `quiz_media_access` 保留為 `quiz_media_access_before_reports`，新包裝在教師傳入回報 id 時，只允許該題快照引用的媒體；其他呼叫完全轉回原授權。考古題保留 Supabase backend，普通題圖片保留 Drive backend。學生不能使用回報 id 取得教師媒體。

## 介面與身分

回報表單在答案更新重新渲染時保留文字；遺失回應後使用同一 request_id 重試。換人／同帳號切換測試身分時，由原作答流程清空表單並使舊回應失效。後台僅首次登入、按「更新回報」、換篩選／分頁時讀取，不新增 focus／TOKEN_REFRESHED 輪詢或進度 localStorage。

後台位置：`admin-progress.html` 的「題目出錯回報」連到 `/admin-quiz.html#question-reports`。待處理為預設篩選，每頁 20 筆，另有處理中、已處理、確認無需修改。
