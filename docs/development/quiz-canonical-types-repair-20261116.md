# 題型與夥伴轉接修正

## 問題與範圍

後期來源轉換器把普通單選也包成單欄 `fields`；夥伴自組卷 gate、私有複製與作答核心原本只支援外層 `single`。因此相同共用入口遇到期中卷會補按鈕，遇到含 fields 的期末卷就沒有，並非按期中／期末分開實作。

本次修正共用來源契約、既有題庫版本規劃及完整夥伴結構化作答；個人原作答／自評與外層 workspace 未改動。不重新送 AI，也不恢復已暫停的新題轉化。

## 資料處理

- 掃描 16,970 來源列、13,562 固定卷／草稿題目副本；匯出採資料庫端 UTF-8 Base64，避免 Windows 管線中文字元失真。私有來源留於 D 槽，不提交公開 repo。
- 1,084 個啟用來源可轉為 single：六年級數學 28、三年級數學 13、六年級國語 305、英語 132、自然 16、社會 590。
- 固定卷／草稿內 44 筆可轉換副本保留原版本與回應契約，透過夥伴相容支援處理；不能覆寫既有學生作答。
- 1 筆接受多個合理選項，保留原判分；另 1 筆先前已停用的缺項舊版本維持停用，已存在的替代版不重跑。
- 修復候選保留來源、單元、難度、學習重點、課本與頁碼、解析、媒體及證據；選項逐一透過原 `quiz_fields_grade` 與新 single 答案映射比對。
- 11 批正式資料庫交易回滾演練已全部通過；保護固定版本、草稿、作答、開放回應、進度與獎勵資料摘要。已依本次明確核准正式套用，1,084 筆新版本全量正式回讀通過。

## 共用行為

- 新來源單選採 single；單欄圈碼透過可逆映射變成正式 schema 接受的 ID。勾選、排序、多欄、特殊多接受答案與開放作答保留各自控制及接受條件。
- 夥伴自組／教師卷私有複製保留完整非單選來源於 server-only 欄位，學生只收到移除答案與解析的結構。
- 原本人分題、固定送出、草稿接回、版本衝突、請教／共同回顧及獎勵沿用；多欄整組不拆給不同人。開放題維持不自動判分、不計正確率，送出後供自我核對與共同回顧。
- 題目／選項媒體與解析音檔繼續走原成員／揭答限制，不因結構化支援而提早公開答案。
- 原單選仍採既有零起算 choice 作答；原考古題 adapter 不變。夥伴入口按鈕採深青綠白字，個人主要練習按鈕保持原色。
