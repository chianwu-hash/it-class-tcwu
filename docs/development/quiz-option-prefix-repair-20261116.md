# 單選選項重複原序標記修正（2026-11-16）

學生畫面已有A／B／C／D徽章，部分原轉換器仍把①②③④或(1)(2)留在選項正文，造成同一層標記重複。本次修正在共用轉換層完成，不改原外層、欄位型別、選項順序或判分；新來源與舊固定版本的呈現共用相同規則。

## 規則與防誤刪

- 新增`shared/quiz-option-labels.mjs`，只有完整唯一的一組原序標記、每項有實際正文且rich文字相符時，才移除前綴；支援圈碼、括號、分隔符、數字／字母及全形。原選項即使亂序，仍依標記集合識別，不依當前A/B位置猜測。
- 單一數值、年份、小數、單位、算式、變數組合及純代號保持。圖位正文中的①仍保留，只刪外面多餘的①前綴；原文句子以①②標號且選項引用那些句子時，保留語意連結。勾選與排序沒有重複單選徽章，不套單選消標記。
- `convertChoiceQuestion()`在來源／學生內容整理後共用此步驟；一般答題、回顧、錯題和既有轉換入口一起套用。夥伴有`normal single`時，同步更新純文字及rich選項，保持零起算的作答索引、原correct與草稿。原始資料與正解不改。
- 前一批49種已核對閱讀來源中，6種因等義消標記增補相容指紋，保留舊指紋與原件SHA；沒有將未知內容加入白名單或放寬guard。原53筆仍全部命中原件核對計畫。
