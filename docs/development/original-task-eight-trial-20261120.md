# 八種原題作答介面：獨立試用版（2026-11-20）

使用者要求以「題型種類」製作，每類只選一題代表。本輪交付八題可操作介面及固定解析，不把既有來源候選的筆數當作題型數。

| 類型 | 作答方式 | 解析 |
| --- | --- | --- |
| 算式與計算過程 | 原答案欄及共用算式按鍵，一起保存 | 完整算式、數量關係與答案 |
| 直式計算 | 原商／餘數欄、方格畫板、文字與自由筆跡 | 按位對齊的直式圖、相減及驗算 |
| 方格作圖 | 原題底圖上畫直線、多邊形與標記，可放大 | 同一來源教師參考圖及對應邊的放大關係 |
| 圓與扇形作圖 | 指定半徑、圓心角與方向後選圓心；可量長度／角度 | 完整扇形圖與作圖步驟 |
| 原圖塗色 | 在原九等分圓圖上逐區選取、取消及復原 | 完整塗色例圖，說明其他位置也可以 |
| 長度／角度量測 | 保留原量角器圖與答案選項，提供三點量角工具 | 從同一排刻度相減求角度 |
| 圖表繪製 | 保留兩張原表與原空白圖，填軸名、畫點線並寫討論／結論 | 兩張完整參考折線圖、全組座標與結論 |
| 實驗／觀察紀錄 | 原比較表的觀察格、堆積選項、討論與結論就地填寫 | 區分實際觀察與示範趨勢，不編造學生實測 |

## 元件與資料邊界

- `shared/quiz-original-task.mjs`／`.css`：八類明示來源 adapter 的共用呈現，不依答案或關鍵字猜題型。
- `shared/drawing/`：原圖背景、幾何圖形、區塊塗色、文字標記、復原／刪除、縮放與鍵盤操作。座標維持正規化，底圖由外部授權 renderer 提供；原圖及參考圖不塞進學生筆跡。
- `shared/sketch/editor.mjs`：有 drawing 設定或 version 2 時轉交新畫板，version 1 保持原路徑。開放作答保存畫面也辨識只有 marks、沒有自由筆跡的圖形。
- `supabase/quiz-original-drawing.sql`：只有一個既有 helper `quiz_sketch_valid(jsonb)` 的候選更新，舊 version 1 保持；version 2 加線段、多邊形、橢圓、扇形及純文字標記。精度、容量、文字與未知鍵皆有界線。沒有資料列、RLS 或 ACL 變更；基準函式不符即拒絕。
- `automation/quiz-original-task-preview.mjs <私有資料目錄>`：僅綁定 127.0.0.1，使用隨機能力入口、HttpOnly／SameSite cookie 與 POST Origin 檢查。題目和固定解析分開供應，參考圖須先核對對應題目；資料保存在本機隔離 PGlite 及私有檔案，不使用 localStorage、不接正式學生資料。
- 私有資料目錄提供 `tasks.public.json`、`reviews.private.json`、原圖與來源證據；不將書商題文、答案、媒體或帶權限的試用網址 commit。泛用服務及 UI 可入 repo，來源包留私有證據。

## 發布狀態與後續

**這是可實際操作的八題獨立試用版，尚未正式發布或整庫啟用。** 來源 adapter 目前隨私有試用包提供；正式個人／考古卷／夥伴的全來源路由、媒體授權及新固定版本仍須另接線驗收，不把本機試用當作已上線通用能力。

候選 SQL 只在本機隔離資料庫套用，尚未取得本候選的正式核准，未改正式函式／snapshot。使用者操作回饋定案後，才依 AGENTS 的 SQL 核准、main PR、live snapshot 與發布腳本流程推進；不得先啟用 version 2 題目或沿用其他 SQL 的歷史核准。
