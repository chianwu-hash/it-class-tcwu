## 核對規則

1. 僅比較副本，去除注音內空白、將明示一聲與省略一聲視同、將前／後置輕聲統一；學生原字串完全保留。不同聲調不得混同，多音節、混入國字／標點或重複聲調顯示格式需修正。
2. 已完整覆蓋的目標字，三典皆無此音時標「注音不符」，例如直ㄓˋ；字音正確但已知造詞不符合時標「與造詞讀音不符」，例如靦ㄊㄧㄢˇ配靦腆。
3. 多音字先核原題提供的詞，再核學生造詞。已知詞音吻合可顯示相符，未知詞保留待核對；同字多組與原參考分組不同時，不以通用合法讀音取代原題要求。
4. 單一教學讀音相符但造詞未知，可顯示「注音符合本字讀音」，明說造詞意思與用法須另核。這不是宣稱造詞或整題正確。
5. 《重編》獨有音、未覆蓋新字、未知詞／給詞或分組差異保留待核對。耶、勁不同版本音讀分歧不硬判。原參考靦／靦腆與佼好字形疑義仍保留既有說明，不靜默改原例答。
6. 只有既有流程授權揭答後才顯示；原答、一次送出、整組自評、備註、個人／夥伴及共同回顧權限不變。此處沒有SQL、DML、AI呼叫或整題評分變更。
