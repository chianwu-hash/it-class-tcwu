# 三年級課程頁固定視覺風格

2026-11-11 使用者定案：三年級每週課程沿用既有親切、可愛的視覺語言，不需每週提醒。不因本週沒有AI資訊圖卡，就省略網頁本身的小圖示與分色設計。

## 基準與必留元素

- 固定視覺基準：`grade3/week20.html`；現行115-1的落地參考為同學期第09、10週。功能則找同學期最新同型頁，視覺與功能參考分開列出，不能把最新頁的漏項當成新風格。
- Noto Sans TC／臺灣繁體字、醒目粗標題、適合三年級閱讀的字級與間距。
- sky／teal／emerald藍綠漸層頁首、黃色週次徽章，以及不遮字的主題裝飾圖示。
- 白底大圓角任務卡、彩色邊框、柔和陰影；每個主要任務標題保留彩色圓形圖示、簡短引導小標與完整文字標題。
- 每週選擇符合技能的可愛小圖示，例如鍵盤、手指、貓咪、魔法棒、救生圈與旗幟。沿用既有Font Awesome或已核准資產，不必另行生圖，也不每週換另一套圖示風格。
- 同層級步驟／練習可放一致的圓形小圖示；按鈕維持清楚的實心配色、圓角、足夠點擊範圍與可見焦點。不要為裝飾取代文字或增加無關動畫。
- 活動可用天藍、藍綠、紫、琥珀等色區分；不是每張卡都要同色，也不是只留下白底、純文字與編號。

## 每週資訊圖卡

2026-11-11起，正式上課週頁依[每週資訊圖卡規範](weekly-infographic-sop.md)至少做一張當週重點圖卡，第11週本次補做；不是選配，也不省略網頁本身圖示。流程仿照六年級，風格仍參考三年級第01週正式滑鼠／教室規則卡：年幼兒童、可愛清楚卡通、白底藍綠／天藍、黃橘重點、大字短句，不套六年級紫色水彩版。生圖時實際附上三年級參考，壓WebP、Cloudinary回讀與同頁燈箱驗收都必做。

## 實作邊界與無障礙

裝飾圖示使用 `aria-hidden="true"`，不取代可讀標題、按鈕名稱或狀態文字；不可只靠顏色／圖示傳達對錯。圖示字型載入失敗時文字與操作仍可理解。尊重減少動態效果設定，手機圖示不可擠壓標題、遮住按鈕或造成水平溢出。

優先沿用同學期既有 `.hero`、`.card-heading`、`.icon`、`.eyebrow`、`.action` 等結構與樣式。若頁面有建置來源，同步修改來源與產物，不能只在產出HTML補圖示、下次重建又消失。風格修復不另造登入、navbar、進度或獎勵流程。

只有使用者指定新的視覺方向或具體教學需求時才調整整體風格，並在契約記錄原因。不可把「簡化」自行解讀成移除圓形圖示、分色任務標題與既有親切感。

## 每週必做驗收

1. 開工前在功能契約填入固定視覺基準、同學期參考頁、保留元素與必要差異。
2. 完工後用同一瀏覽器、同一視窗尺寸對照基準／同學期參考與新頁。至少1280px桌機、390px手機，檢視頁首、主要任務標題、練習卡及按鈕，保存對照截圖。
3. 確認圖示真正顯示（字型已載入、不是空方框），圓底／配色正確、圖示與標題不重疊；不能只以CSS import、圖示class或DOM存在當成驗收。
4. 同時確認手機不溢出、文字與焦點可見、減少動態效果下仍有回饋，並回歸本批碰到的操作流程。
5. 發布前檢查表逐項記錄「符合／必要差異／N/A及理由」，缺少畫面對照不能標記視覺驗收完成。風格檢查與登入／保存等功能驗收都必須完成。
