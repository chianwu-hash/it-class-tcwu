# Notebook回覆頁碼被UI引用徽章改寫：已驗證的擷取處理

2026-11-13六年級自然期末卷實測：Notebook已完成的JSON回覆中，數字陣列頁碼被網頁轉成來源引用按鈕；innerText還可能把按鈕數字、換行與more_horiz插進JSON字串。這是實際DOM證據，不把引用1、2當課本頁碼。

處理方式：保留原UI回覆、送出日誌與原DOM；只在離線DOM移除已觀察到的citation-marker按鈕，讀取textContent。缺失的頁碼欄隔離為空，不猜值、不改答案。再交AGY按課本實際頁腳逐題重建並複核。第二批移除36個引用按鈕、17個頁碼欄遺失；第三批17欄缺頁另重建。沒有重新送出AI查詢。

第三批另有10個ID省略共同前綴，依請求清單唯一、精確的完整尾碼還原；保留前後雜湊，斷言除了ID外所有欄位不變，並再核51題完整涵蓋。

後續提示詞可試把頁碼改成單一數字欄或數字字串陣列，減少被當引用陣列的機會；這項預防方案尚未獨立實測，不宣稱已保證有效。擷取修復不能代替原圖、答案及頁碼內容複核。

原始失敗、DOM擷取與逐題修正收據保留私有工作目錄，不把教材和答案上傳公開repo。
