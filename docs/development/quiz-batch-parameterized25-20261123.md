# 參數化批次與除法算式 25 筆上線

依 Codex／Claude 共識，把候選、來源、抽樣題、答案及課本頁碼放在同一份私有固定清單；題數、欄位數、5% 抽樣數與 manifest checks 由程式推導。共用腳本不再逐批改題目 ID、答案或頁碼。此轉接器目前限定無題目媒體、每來源一題的算式數值欄位，其他題型沿原分流。

寫入前保存固定意圖與 SQL SHA；回應不明先以固定版本完整讀回，不盲目重送。最終清單生成器把意圖檔本身列入 input。OAuth 重跑先查既存作答，完全相符就驗保存內容，不再次送答；runner 核實收據實際抽樣數及題目，保留原始失敗開始時間。Worker 的完整檔案／索引／設定核對與遺失回應恢復已整理為共用函式，經模擬傳輸測試；本批沒有新增題圖，未執行正式 Worker 寫入。

| 檢查 | 結果 |
| --- | --- |
| 來源與教師鍵 | 25 筆、75 份原始檔 SHA 重核，商與餘數逐筆獨立驗算。 |
| dry-run／等值讀回 | 25 題、50 作答欄位，75 組全對及逐欄錯答情境通過；缺算式拒絕、同請求重送與保存接回通過。 |
| 課本 | 25 題逐題核原頁及正式綁定；第 83–88 頁共 6 張既有課本供圖 SHA 通過。 |
| 正式 OAuth | 按 5% 抽 2 題，桌機／手機開頁、切頁、返回保留答案與算式，判分及重開通過。再次執行沿用 2 筆保存答案，未重送。 |
| 正式上線 | 老師練習卷整批上架，25 題完整內容、答案、共用材料、原序與課本逐筆讀回一致；學生正式練習庫列出。 |
| 共用回歸 | 7 項測試通過，含 Worker 回應遺失後讀回、異動拒絕、抽驗缺題／重複拒絕、事前意圖與生成 checks、續跑及排他鎖。 |
| 總帳 v60 | 708 筆列管來源累計上線 425 筆，剩 283 筆；其中既有題池 351 筆，老師練習來源 74 筆。 |

從開始記錄到正式入口驗證約 11 分 48 秒，包含這輪工具開發；其中 OAuth 收據檢查、啟用及 SQL 讀回三階段共 25.107 秒，這不是整批生產時間。重跑三階段皆跳過。初期選批到清單固定約 242 秒；主動準備工時未記錄，開發初驗修正 2 次、總帳準備修正 1 次，正式寫入無需故障恢復。

上批為 9 筆／28 欄／14 張題圖，本批為 25 筆／50 欄／0 張題圖。上批缺準備時間，不能做同條件速度倍數比較；目前證據支持減少逐批腳本手改及重送操作。完整私有來源、原頁、固定 SQL、執行版本與逐筆收據在儲存庫外保存。網站前端與資料庫函式未變更，不需 Vercel 部署。
