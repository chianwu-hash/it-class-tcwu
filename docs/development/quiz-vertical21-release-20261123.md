# 直式 21 筆上線與筆跡批次轉接

本批 21 筆＝16 筆除法生活題＋5 筆公斤／公克直式。保留全文與原作答要求，共 42 個自動判分答數欄、21 個筆跡區。16 題要求先寫橫式再算直式，兩項都寫在同一筆跡區並同次保存；計算過程供參考核對，不以單一算式字串自動判錯。兩項要求的來源位置到筆跡儲存映射另存私有清單，沒有把過程丟掉。

| 檢查 | 結果 |
| --- | --- |
| 原件與教師鍵 | 63 份來源檔 SHA、原題完整度與數值獨立核算通過；16 份教師直式圖已目視核對。 |
| dry-run／等值讀回 | 21 題、42 答數欄，63 組全對／逐欄錯答通過；缺筆跡拒絕、同請求重送及保存接回通過。 |
| 課本 | 21 題逐題核原頁與正式綁定，6 個印刷頁碼對 5 張課本圖；重用前批 3 張供圖證據，新驗 2 張 SHA。 |
| 正式 OAuth | 5% 抽 2 題，涵蓋重量換算與除法筆跡。桌機／手機開頁、切換不同課本圖、返回保留全部筆跡及答案，送答與重開一致。 |
| 原生直式參考 | 依已核教師鍵重建文字直式，明示整理來源；桌手機量測商、被除數個位與餘數對齊，實看手機捲至完整解析。新增邊界證據與圖片 SHA 綁定為啟用前 gate。 |
| 正式上線 | 老師練習卷整批上架，21 題內容、原序、答數、材料與教材逐題讀回一致；正式學生練習庫列出。 |
| 總帳 v62 | 708 筆列管來源累計上線 461 筆，剩 247 筆。直式另 2 筆維持原分流：教師答句矛盾、既有媒體登錄待處理。 |

共用工具新增 sketch 參數轉接，沿現有筆跡與 fields-v1 契約。樣本的 expected 由 JavaScript 共用推導寫入固定 plan，Python 與瀏覽器讀同一份，移除第二套答案推導。驗收腳本以完整跨頁標題判讀，翻頁選不同圖 ID，避免把同一張 111／112 跨頁圖誤算成切頁。補充邊界收據可作為 read-only gate，批次 SHA 與附件雜湊通過後才啟用。11 項自動測試通過，包含筆跡格式與補充附件被改動時阻擋。

統一計時為 development 批次：選來源至入口 853.917 秒，清單通過至入口 557.717 秒，含筆跡轉接、原生直式參考與新邊界驗證；runner 收據／啟用／讀回為 25.543 秒。正式寫入故障恢復 0、三階段重跑皆跳過、共用腳本逐題 ID／答案／頁碼手改 0。參考截圖因背景穩定等待重試 1 次，總帳準備修正 1 次；主動人工工時未記錄。不能拿此開發批次和前批起點不同的數字推估速度倍數。

私有題目、答案、來源與固定 SQL、筆跡、教材及畫面證據留儲存庫外；程式與本批收據同一 PR。無前端或資料庫函式變更，沒有 Vercel 部署。
