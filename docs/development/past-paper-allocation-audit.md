# 考古題配題結構盤點

日期：2026-11-05。狀態：完成現有卷目錄基線；逐卷語意結構尚待原卷複核，不能據此啟用新分配。

## 使用者定案

先整理現有考古題，記錄整份試卷的獨立題、題組及各題組的子題數，再實作夥伴練功的整組分配。

- 獨立題：可獨立作答的一道題，為一個可分配單位。
- 題組：共同題幹／文章／圖表／情境下的多道子題，整包分給同一人；工作量仍按內含子題數計算。
- 整份試卷：包含上述兩者，不能把整卷稱為一道題組。
- 可分配單位數＝獨立題數＋題組數。是否有人分不到題，應看此總數，不是只看題組數。原先「題組少於人數就無題可分」的推論不成立。
- 先保持題組完整，再盡量平衡每人的實際題數；不要求數學上完全相同，也不因本盤點變更花葉政策。

例如一卷有12道獨立題、3道題組，各含2、3、4道子題：可分配單位為15個，實際題數為21題。分給三人時可將三組分別交給三人，再用獨立題補到每人7題。

## 唯讀盤點結果與限制

已從現有資料庫唯讀取得50份試卷的現用版本：40份啟用、10份停用。基線記於 [past-paper-allocation-baseline.json](past-paper-allocation-baseline.json)。未讀取學生作答，未更新資料庫、現有配題或正式網站。

現有 `document.groups` 是技術容器，不能直接當成語意題組：整大題的多道是非題可能放在同一容器；同篇文章的子題也可能分散於不同容器。共同素材相同只能用來提示複核，不能自動定案。整段聽力共用一個音檔，也不代表所有題目必須綁成一組。

因此基線只列技術容器數、作答欄位數、阻擋項目數與版本雜湊；獨立題數、題組數及正式題數保留為未確認，不以欄位數冒充子題數。停用卷另列，盤點不代表重新開放。

## 每卷結構紀錄

逐卷比對原卷與已轉錄內容，建立獨立的配題結構表，保留原始題號及資料映射，不重寫原卷：

| 欄位 | 用途 |
| --- | --- |
| 試卷ID、現用版本、內容雜湊 | 固定盤點對象；換版後須重核 |
| 獨立題數、題組數、各組子題數、全卷實際題數 | 分配與人數判斷 |
| 單位ID、種類、原卷大題／題號、共用材料範圍 | 保持題組完整、區別同號題 |
| 來源檔案雜湊與頁次 | 回到原卷驗證 |
| group ID、field ID清單 | 對應現有呈現、送答及權限 |
| 作答欄位數、需自我核對數、阻擋項目 | 和實際子題數分開；不改既有評分分母 |
| 複核狀態、疑義與證據 | 不把推測當成完成 |

每個可作答欄位須且僅須出現在一個分配單位；題組可跨技術容器，技術容器也可能拆成多個獨立題。多空格不自動等於多道子題。阻擋／未轉錄題目須說明，不可靜默漏算或分配。

先複核40份啟用卷，再整理10份停用卷。疑義先記錄並核對來源；未完成複核的卷不得啟用新分配。盤點完成後才調整後端ownership與新房分配；既有小隊不重新洗牌。這份文件不表示整組分配或新答題介面已實作／驗收。
