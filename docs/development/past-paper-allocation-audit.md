## 已收斂的重要例外

- 共用文章／圖表與「承上題」跨技術容器仍成同組；單題自己的長文章不因材料很長而被叫成多題題組。
- 同一世界地圖的六個引線目標整組保留；原卷明確指定三道人物題為一組時，依使用者不拆題組原則保守整包。
- 成功及文澳國語部分field打包多個來源測點，用sourcePart記錄，不拆或改寫現有field。文澳四國多音字的兩個語意題組共享s4，已列storageCouplings，後續需同一負責人或另驗adapter。
- 名間英語聽力A–F是彙總blocked佔位，已逐項展開原頁實際題目；其中排序全序列仍是一題。閱讀短文的一個field包含三組圈選，最後依原頁修正為三個子題，紙本55改為57。
- 六年級自然加分題一個field包四個分類目標，四個sourcePart皆保留optional，不灌進必填或60%分母。
- 共享詞庫原本是否可重複不是現行schema的結構化欄位；決策另外列sharedOptionPools、來源與跨單位限制，接配題前要核對固定原卷規則，不能猜成可重複。

## 複核與驗證

Codex先檢視資料並對疑義查原卷；Claude以受監督chat-mode分六批讀取50份證據（原卷文字、現用轉錄與必要原頁），最後再讀30次來源／程式檔收斂例外。不是50卷逐頁雙人視覺重校，也沒有重驗全部答案／媒體。前批「未看PNG」「可能缺選項圖」及初判保留在私有歷史回覆，不能冒稱已證實產品缺圖；最後以修正後決策為準。既有勘誤／限縮／改編不因本次和原頁不同就回復。

離線驗證覆蓋50份卷，檢查來源唯一覆蓋、合題／題組分割與固定決策一致、版本／SHA、blocked、選做及共用payload限制；另有合成資料正向及負向測試。唯讀重查50份現用版本、SHA及啟用狀態皆未改變。

```text
python -B automation/past-paper-structure-verify.py --structure docs/development/past-paper-allocation-structure.json --source <私有唯讀匯出.json> --decisions docs/development/past-paper-allocation-decisions.json
python -B automation/tests/past-paper-structure-test.py
```

原件／題文／答案／私有匯出及Claude完整回覆不進公開repo；由來源SHA、頁次與固定版本回查。上輪[目錄基線](past-paper-allocation-baseline.json)是整理前紀錄，內含null及pending狀態，不是本次完成資料。

## 接配題前仍須完成

本次`allocationEnabled:false`及`allocationContractReady:false`是明確邊界。沒有改ownership、輪配公式、學生UI、訂正或花葉；沒有重新分配已出發小隊。

後續先在隔離環境接這份結構，處理sharedOptionPools、storageCouplings及blocked轉可用的新版本，再驗2～4人分配、整組同人、題數平衡、權限／媒體、送答／部分失敗／同ID重送及舊房相容。口試未知、不可用題、選做與固定計數口徑不得被靜默改成可完整配題／必填。正式切換仍另走PR、main及發布腳本；本次未發布。
