# 題型標題與亂序解析引用修正

## 問題與處理

使用者回報題幹前多餘的「是非題／選擇題」，以及正確答案在畫面為C、AI解析卻仍說原題①的對照錯誤。

共用呈現隱去開頭獨立題型標題，原題型／來源字串及既有圈碼輸入相容性保留。解析以不可變來源的原選項順序與ID為依據，改引用完整選項內容；不能依目前畫面順序猜原序，也不關閉亂序。圖示選項沒有可讀文字時，才由其穩定ID找當下實際字母。既有選項、答案、作答、課本頁碼、原外層介面均不改，無SQL／資料庫寫入。

新來源共用轉換器同步把解析的位置引用改為內容；新增唯讀 `audit-explanation-references.mjs --check` 作為凍結前關卡。舊來源不覆寫，由共用顯示相容規則處理。映射檔僅有來源／欄位／選項ID，不含題目全文、答案或學生資料。
