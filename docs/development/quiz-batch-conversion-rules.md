## 1. 批次的單位與啟動順序

### 效率接續共識（2026-11-21）

總帳只由程式彙整既有收據並增量更新，缺證據記 unknown，不人工填通過，也不把未連結的歷史證據當失效。`automation/build-quiz-conversion-ledger.py` 先核來源身分、候選 SHA 與收據參照；候選契約標籤不代替原題角色分類，隔離資料、行為重用、媒體、正式 OAuth 與啟用分欄記錄。輸出留 repo 外。優先從已驗候選找完整可交付者，再批次補相同群缺口，不只追求新增候選數。

同規則／角色／adapter 與行為契約一次處理整組可用來源，不按兩三題開新分支；行為指紋只包含真正受影響的程式與契約依賴，來源 guard／數字變更另走資料檢查。媒體按 hash 去重，已就緒群合成一份 release manifest，避免每幾題發布一次。每批一份固定格式、原則30行內的公開收據，交接只加一行連結；詳細證據留私有，不為整理舊長文阻塞主線。

資料檢查失敗率超過10%或同因第三次出現時，先停受影響群診斷／一般化；其他群繼續，不自動找 Claude。共用呈現／序列化／判分／函式變更獨立處理；授權或揭答隔離失敗阻擋相關發布，週剩餘小於等於15%才停止整個長線。每批分記題數、資料處理時間與發布成本。缺介面與未分類者保留原因及待辦，不因題數少刪減範圍；新 adapter 集中補一次並記涵蓋數與估計／實際成本。Claude 僅限未解語意／答案疑義或高影響新共用契約，不做例行二審。

以「既有轉換規則＋作答契約版本＋呈現分支」分組，不以來源 ID、書商名稱或每兩三題作一個新介面。不同科目、數字、字詞、圖片或教材頁，若未改變行為，就沿同一規則批次處理。書商題型名稱只作線索，須同讀原題、原題型及已固定來源要求；不能由答案反推介面。

1. 讀取來源／固定複核、不可變版本、既有轉換器及本索引；核實目標入口實際具備的能力。
2. 來源要求已明確且符合規則者，直接程式擷取、轉換、產生解析／教材綁定及資料收據。已有固定解析、重點與配題就沿用，不為換封裝重新生成或送模型。
3. 逐筆跑下節的資料檢查，將失敗來源與具體原因放入例外佇列。其餘來源持續批次轉化。
4. 依驗收證據鍵查找可沿用的代表題收據。有效就沿用；缺少時只驗真正新增的呈現分支，不重做已接受的試用。
5. 一個完整批次交付候選、逐筆資料結果、沿用的介面收據及例外清單。批次大小由資源／API 限制決定；拆成多次傳送不會重置介面驗收。

「試用已接受」「正式程式具備」「來源資料已通過」「已發布」分開記錄。八種試用已接受其操作方向，不代表新版 drawing 契約已正式接線。待接線類集中補 adapter 一次，接好才批次轉化；不能以空白畫板、普通文字欄或計算紙冒充專用作答介面。

## 3. 每筆都做的資料檢查（以程式執行）

這些檢查不因沿用介面而省略，也不需要每筆找 Claude。結果須來自實際檢查輸出，不能手填一串 true 代替檢查。

- 原件／題型／固定複核版本及 SHA；題幹、共同材料、選項、必要樣式、圖與音訊完整。
- 每個原作答位置的角色、欄位 ID、型別、單位與答案映射；原輸入、人工過程及教師例解的位置不可混淆。
- 現行 validator、來源 guard／真實 copy_self 綁定、完整欄位覆蓋與封裝限制。新來源需重算自己的綁定指紋，不沿用其他題的 source guard。
- 原鍵保持；獨立可計算者用程式核算，等價答案與配對照現行契約，開放例答不得偽裝成唯一正解。無法由可靠資料定案才升級疑義。
- 固定解析、學習重點、教材版本／頁碼及配題狀態。已有可靠複核就沿用；無可靠對照如實標明，不硬配、不重做整題 AI 分析。
- 新媒體逐資產核 bytes／SHA／MIME／私有映射／正式授權供圖；既有同 hash 且供圖契約未變者沿用，毋須重新上傳或重跑登錄。
- 批次匯入的逐筆等值讀回、不可變版本及保護資料摘要。新增內容不得沿用別份候選 SHA 的資料收據。

來源文字、數字或圖不同，會產生新的**資料收據**；這不會自動使相同介面的**行為收據**失效。

選答依學生實際要完成的作答判定。只要學生從固定選項選一個答案，就用同一種單選；書商的圈選、打勾、貼圖或圖案規律等名目沿用同一選擇題流程。多欄圈選、是非、符號和比較須逐欄綁定原位置。單選比對原選項次序、顯示內容與原鍵 ID。原題有明示勾選指示及選項標籤時，單列的空勾選框或完整選項圖片旁的空勾選框可按紙本操作提示處理。題意中的方框必須保留。選項圖的雜湊不同時，核對候選檔案雜湊及同尺寸完整 RGBA 像素後才能對帳，圖片順序仍須一致。純文字且有完整連續標籤的最重／最輕圈選，教師鍵、固定複核與換算結果一致才建立候選。共用程式見 `automation/lib/quiz_choice_source_binding.py`。

教師原答案以圖表示時，先按原卷順序列出選項。原答案圖的 SHA 若唯一吻合一個原選項，以該位置綁定正解；原卷規律可獨立驗算時一併核對。若與舊複核位置不同，保留原紀錄，另附原件 SHA、選項位置與驗算作為更正證據。圖像有裁切、翻轉、重複，或答案檔同時含多個選項時，須有足以區分正解位置的原卷證據才建立候選。

Word 原件的圖片依每次出現的位置還原裁切與水平翻轉，再按原卷選項次序輸出獨立圖檔。同一個內嵌圖出現兩次時，逐次查核裁切與方向。複合原圖中的題幹示意與選項分開保留，裁掉選項外的括號、編號、分隔線和勾記。記錄內嵌圖 SHA、Word 裁切與翻轉、原圖裁切範圍、輸出 SHA 及教師鍵對應。依實際顯示像素核對教師答案圖。線稿尺寸不同時，須核對長寬比與線條，取得唯一配對，再用原題規律驗算。位置、方向或圖形對應仍無法確認時列例外。共用程式見 `automation/lib/quiz_graphic_choice_layout.py`。

原題將單選選項合在同一張圖時，依原卷的編號或明示位置裁成各自獨立的選項圖。裁掉編號、紙本勾選框及分隔線，保留物件、刻度和解題所需的圖形資料。選項上的重量或名稱若從圖中分離，另以原值附在同一選項下；題幹用的共用圖沿原位置保留。逐題記錄原圖 SHA、裁切範圍、原卷次序及教師鍵到選項 ID 的對照。位置或答案對應未定時列例外。驗收時用原卷順序比對；正式自組卷預設會亂序，要求學生看到固定原序的批次，須另驗組卷時的選項順序。

原卷只要求勾選一個答案時，直接按單選批次處理。紙本勾記以原標號或原選項文字對應正解，例如教師答案「②ˇ」要與固定複核的「②方框填 v」核對位置，再按原序轉成選項 ID。有圖的題目沿用同一規則。原卷放在選項內的文字和圖留在該選項，位於選項區之前的共用圖依原圖文順序留在題幹。可獨立驗算的數值須與原鍵相符。教師答案與複核位置不同、看不出勾選框或圖片的歸屬，或須同時標不同符號的題目另行分流。

原卷用一張圖呈現連續圈號，並要求勾選或圈出符合條件的所有項目時，可沿用 `prepare-grade3-science-native-media.py` 的 `visual_grid_selection`。原圖留在題幹，作答區按原圖順序列出圈號，以一個 `fields-v1` 集合判分。先核對原 Word 內嵌圖及網頁圖的 SHA，逐圖記下實際有內容的選項順序。逐題比對教師 Word 的圈號欄位、匯出鍵、固定答案與固定作答位置。只有紙本空白框的格子不產生選項。原圖序號有歧義、教師鍵缺失或多種符號各有不同意義時另行分流。抽驗須核對正式題圖、選項位置、教材往返保留作答及集合判分。

續批先以總帳未上線的來源 ID 建立本輪輸入。若舊 dry-run 曾通過且仍無正式發布收據，仍納入本輪檢核。適用 `visual_grid_selection` 的來源先確認逐圖核過選項序號和教師鍵，跑完後比對來源 ID 清冊，確保每筆都有通過或例外結果。

一張共用圖有多個圈號，每個圈號都能從同一組代號獨立選一個答案時，可用 `visual_grid_matching`。先按原圖核對兩側端點及代號順序，逐位置比對教師 Word、書商鍵和固定複核。保留共用原圖，每個圈號用一個單選小題獨立判分；同一選項可重複使用。原圖已印文字可帶入小題，需由學生觀察的風向或風力留在圖中。原文人數、圖中端點或教師鍵互相矛盾時列例外。代表題須從正式畫面核對排序及共用圖供圖，再驗教材往返保留選答。

共用圖題組的書商分類標為多選時，若每小題在原卷只有一個答案，而且教師 Word、書商鍵和固定複核位置一致，使用 `reviewed_shared_single_choices` 逐題轉單選。保留共用圖、材料與小題順序，逐項核對 Word 選項文字。選項另起一行且各印有空白勾選框時，可移除框符號，保留對應選項。原圖和題意無法唯一對應答案時列例外。

同一題組若混用圈號、注音勾選或圖上方向框，可用 `reviewed_mixed_single_choices`。逐小題核對紙本代號、教師 Word、書商鍵及固定複核位置。注音與圈號選項保留原順序，圖上空格改成具名單選。只供末題作答的圖須留在末題，題組共用圖留在共用材料。代表題抽驗應涵蓋小題內的私有原圖及教材往返。

純文字題組若要求從共用代號表選分類，可用 `reviewed_text_classification`。保留原材料，將代號對應的名稱依原表順序做成選項。教師 Word 依原序逐小題核對書商鍵和固定複核位置。原題有一個以上正解的分類題組保留複選，每個小題對照自己的答案集合，各自判分。

純文字題組的小題各有自己的圈號或注音選項時，可用 `reviewed_text_choices`。共用材料與小題分開。逐小題從教師 Word 核對勾選位置與答案集合，再比對本題的書商鍵及固定複核。保留原選項順序，依各小題的原鍵判定單選或複選。

同一組物品須分別標最重和最輕時，保留一題多位置標記。按紙本原序把每張圖和重量綁到自己的欄位，每格可拖曳原符號，或先點符號再點空格，也可清除。初始不預選，學生開始作答後才帶入其他欄位的留白。漏標或多標照原值儲存，整題仍依既有 `fields-v1` 判分。揭答後顯示對應的核對結果，正確留白維持空格。圖卡呈現只對核過來源指紋的題目啟用。

數值與單位的原鍵依完整片段擷取。明示單位、公斤／公克、時／分保留原順序，同單位等值分數保留原寫法及替代值。多小題的「答」行須逐段綁定原題可見標號。答案圖、原圖專有標號、異形表與巢狀結構須先核對原位置；跨單位或成組替代值須取得確定的單位與配對映射。教師鍵與固定複核不一致時列出差異。總帳可用 `--isolated-equivalent-readback` 連結相同 schema、函式及候選 SHA 的隔離讀回，與正式供圖、行為重用及 OAuth 各自記錄。

## 4. 代表題驗收與證據重用

### 證據鍵

沿用必須能核對：`rule_id + rule_version + adapter/呈現分支 + 相關 JS/CSS 指紋 + 序列化/後端契約版本 + 已驗入口 + 螢幕級距`。記原收據路徑、代表來源、實際測過的操作及證據時間。不同題幹的 candidate SHA 不放入共用行為鍵；另以逐題資料收據連結來源與該鍵。

實際分支由作答角色及工具能力決定，不因來源 ID、每批起訖或不同書商重新命名。guard 更新只證明此來源可套模板；不能把 guard 當行為證據，也不能因每題 guard 不同就重跑相同全流程。

### 何時驗什麼

一般題庫與考古題以共用規則由程式批次轉換時，正式網站的人工驗收每批抽 **3%**。需逐題人工轉換的部分沿用 **5%**。兩者均依整批原始來源題數無條件進位，至少 1 筆。樣本優先涵蓋較容易出現顯示或操作問題的題面，再抽其餘題目。用專用帳號實測樣本的顯示、課本開頁與返回保留作答、送答、判分及重新開啟後的回顧。發現問題時記錄並視影響範圍調整抽驗。逐題程式檢查、課本原頁與正式對照、等值讀回、啟用後全數讀回及正式資料庫授權流程照常執行。

新增教材或以新 ID 合併書冊時，應按原件裝訂核對翻頁方向。固定批次中有原件方向紀錄時，先比對教材 ID 的正式閱讀器設定，再在正式 OAuth 抽驗確認閱讀器使用該方向。

| 變更／情況 | 必須驗 | 可以沿用，不得例行重跑 |
| --- | --- | --- |
| 規則、adapter、呈現分支、前後端契約都相同，僅新增同類來源 | 全筆資料檢查、批次等值讀回；整卷／整科發布時依已有關卡做入口 smoke | 相同代表題的完整保存、重試、接回、回顧及 Claude 意見；不為每批再做 5–10 題小樣。 |
| 同規則的來源出現新的長度、圖量、單位或題組邊界，超出已驗範圍 | 只驗新增邊界的版面／對位，建立可沿用的分支收據 | 未受影響的儲存、權限、葉片或所有其他題型全套。 |
| 共用 renderer、工具互動或相關 CSS 改變 | 跑受影響規則／分支的既有代表案例與必要邊界 | 未受影響模組的逐題全套；不重送全部內容給模型。 |
| 序列化、判分、揭答、授權、DB 函式或來源 adapter 改變 | 受影響契約的保存、冪等、接回、揭答前後、跨人拒絕、個人／夥伴／完整回顧等完整回歸 | 無關內容的再解題、未變媒體的再上傳。SQL 與發布規則照舊。 |
| 內容／答案／解析換版 | 新 SHA 的資料核對及相應判分／揭答差異；UI 文字若超出既驗邊界才加局部畫面驗證 | 不能以「換版」為由重做沒有變動的共用互動全套。 |

一個新分支通常一題代表；若一題無法包含明確不同的分支，才加最少代表案例並註明缺哪個分支。新行為首次完整驗收覆蓋原題→操作→同次保存→重試／重載→個人／夥伴回顧及必要揭答隔離；桌機／手機及其他已知風險級距只對代表案例驗。表格、長字、讀數免過程、混合文字等已驗分支，不因下一題又有相同情況而重驗。

正式 OAuth、隔離真 SQL、真人帳號、實體手機與本機試用各自標範圍，不互相冒充。既有發布安全關卡、整科門檻及必要正式 smoke 不取消，但每次 smoke 也不重做所有來源的完整 UI。

## 5. 真正例外與 Claude 使用界線

| 例外代碼 | 情況 | 處理 |
| --- | --- | --- |
| SOURCE_AMBIGUOUS | 原件缺字、圖文邊界／標記／作答角色仍無法確定 | 先查原件，整理最小未解範圍；需要語意判斷才請 Claude。 |
| ANSWER_CONFLICT | 原鍵、獨立解題或可靠資料矛盾，等價答案範圍不能定案 | 保留原鍵，集中同一爭點與相關原頁供獨立複核；實質分歧才用 AGY。 |
| CONTRACT_GAP | 已定案操作尚無 adapter，或原題確有未支援的新行為／保存要求 | 集中補共用分支一次；新契約才做針對性程式複核與完整代表驗收，不逐題補丁。 |
| DATA_CHECK_FAILED | 格數／ID／SHA／範圍／欄位／配頁／媒體資料檢查失敗 | 程式診斷及來源核對，修完重驗受影響資料；不自動找 Claude。 |
| EVIDENCE_INVALID | 找不到可沿用收據或行為鍵已變 | 補缺少的代表驗證；不等同於題意有疑義，不自動找 Claude。 |
| MEDIA_PENDING | 新素材未完成私有鏈、格式或授權驗證 | 依既有媒體流程逐資產補齊；不讓 Claude 重新解題或重審 renderer。 |

Claude **不是固定生產步驟，也不是發布前固定再審一輪**。新共用契約的高影響程式審查或未解來源／答案疑義，才集中送一次最小證據包，明列問題、讀取範圍、定案條件與已知限制。純標籤、頁碼、固定規則下的資料修正，Codex 依來源及程式檢查處理。若先前意見已解決且沒有新爭點，記採納／不採納理由即可，不為取得「二審無問題」反覆送審。

一次例外解除後，將一般化規則、適用條件及代表證據回填索引／adapter，讓後續同類來源走批次，不再把相同原因列成新例外。發布可用與否仍以實際證據判斷，不用模型多數票。

## 6. 批次交付與停止條件

每批只需一份總收據，至少包含：規則及版本、來源／候選 SHA 清冊、逐筆資料結果、各分支沿用的代表收據及有效性、真正新增的驗證與原因、例外來源／原因／下一步、候選／已驗／待接線／已上線分開的計數。原題、答案、學生資料與私有輸出留公開 repo 外。

使用者目前授權：三、六年級目標不變，四、九年級只各科考古題。使用者於2026-11-21依新SOP恢復長線，其後又指示本批告一段落即暫停；六筆原生表格收尾後保持暫停，待明確恢復再續。恢復時按此索引分流現有待辦，沿用已接受試用及已完成媒體／核准SQL的證據。正式資料庫函式與發布仍遵守既有核准及整科關卡。週剩餘用量小於等於15%時亦須依既有規則保存、清理並暫停。

## 可續跑的批次執行器（2026-11-23）

凍結程式轉換批次前，固定批次包須填 `"samplingMode": "programmatic"`，由程式按來源數計算 3% 樣本。只有執行清單而沒有固定批次包時，在清單填同一欄位。逐題人工轉換使用 `"samplingMode": "standard"`，既有未填欄位的固定批次沿用 5% 及其收據。

凍結候選之後，使用 `node automation/quiz-batch-runner.mjs <私有清單> [截止階段] [恢復收據]` 依序執行媒體、教材、正式驗收及啟用等清單階段。每階段宣告結構化命令、輸入、輸出與收據檢查。既有專案操作由階段命令負責，執行器負責調度和證據完整性。

清單及逐階段狀態存於儲存庫外，以清單 SHA 分開；已完成階段只有輸入與輸出雜湊、收據檢查均相符才跳過。相同批次用排他鎖避免並行。寫入失敗或中斷須先讀回，經綁定批次、階段與目前輸入的恢復收據才可重試或採認已完成的遠端結果；歷次失敗紀錄保留。逐題原件與教師鍵、課本原頁及正式對照、依批次比例正式抽驗和啟用後讀回仍依既有關卡執行。


### 參數化清單與寫入後核對（2026-11-23）

先以 `automation/lib/quiz-batch-plan.mjs` 核固定候選及來源雜湊；題數、欄位數、抽樣數、樣本答案與課本頁碼從同一清單推導。`prepare-quiz-practice-batch.mjs` 產生固定 SQL 並跑正式快照隔離驗證；`create-quiz-practice-manifest.mjs` 推導收據 checks，將事前寫入意圖列為階段 input，再交 `quiz-batch-runner.mjs`。練習卷轉接器的已驗範圍已擴為每來源一個共用材料 block、多個獨立 fields 小題，以及數值／一般單選／複選；仍限本批無題目媒體的既有契約，不把它冒稱通用匯入器。

`verify-quiz-practice-batch.cjs` 沿工作瀏覽器租約及專用帳號抽驗，重試先讀現有作答，完全一致才沿用，其他狀態停止該筆而不覆寫。runner 必核實際 OAuth 收據的批次 SHA、題目及抽驗數量。`apply-quiz-practice-batch.py` 對照事前固定意圖，回應不明先完整讀回版本、材料、欄位及教材，不盲重送。Worker 轉接器使用 `lib/quiz-worker-write.mjs` 的事前固定與完整檔案／索引／設定比對；傳輸仍須驗實際帳號與免費方案，模擬測試不能冒稱正式供圖。

每批記來源數、作答欄位、媒體數、準備與工具開發範圍、實際階段時間、手改及恢復次數；缺基準就標缺資料，不能把網路等待當人工工時，或用無圖批次推論媒體批次的加速。程式與該批上線收據同一 PR。詳[25 筆實跑收據](quiz-batch-parameterized25-20261123.md)。


### 跨頁綁定、固定收據與可比較計時（2026-11-23）

課本頁別名 `printed` 必須屬於該圖完整 `printedPages`。同一印刷頁只對一個圖 ID；同 ID 可以拆列 111／112 等跨頁，但陣列與 SHA 必須一致。所有引用頁都須在 verified 圖的印刷頁陣列內，不用單頁假設比對正式資料。

`packet.timing` 可在凍結前提供 `mode: development | production` 與實際 `selectionStartedAt`；共用工具將清單通過、隔離完成、OAuth 起訖與入口完成寫在儲存庫外獨立的 `prefix-timing/`，每事件保留第一次值。不把變動時間寫入凍結的 plan／isolated／OAuth 收據，不回填舊批次推估時間。OAuth 重驗先核既存答案，保留首份正式收據，另存重驗紀錄；不能讓「已存沿用」觀察值改變原收據雜湊。抽樣數由來源數推導，樣本依清單風險選取，不能冒稱隨機抽樣。詳[15 筆實跑及 Claude 共識](quiz-expression15-release-20261123.md)。


### 筆跡參數及原作答要求（2026-11-23）

每來源一題、無題目媒體的數值題可用同一批次轉接器保存既有 expression 或 sketch 契約。原題同時要求橫式與直式時，兩項均保留在題面及筆跡作答區，逐來源記原過程位置到 w 的映射；只自動判分答數欄，不能把計算過程說成已被系統批改。教師直式圖若以原生文字重建，須有原圖、數值及逐步驗算，標明重建來源，並驗位值與手機完整可讀。真正題意圖不能套用此做法刪掉。

prepare 將樣本的 sampleExpected 固定在 plan，其他語言轉接及正式瀏覽器均讀同一份。原生筆跡沿既有格式驗證，樣本須以實際畫板輸入、開課本返回、送出及重載核全部點與顏色。跨頁以完整 printedPages 標題核頁；切頁須換到不同圖 ID。新邊界的補充收據以批次 SHA 與附件 SHA 綁定 read-only gate，再接啟用；資料／圖變動即停止，不用人工把 true 當證據。詳[21 筆實跑](quiz-vertical21-release-20261123.md)。


### 文字表格的連線端點映射（2026-11-23）

`automation/lib/quiz-matching-table.mjs` 只接原表格五欄「左端點／點／空白／點／右端點」，所有端點須完整且有唯一原標記，逐列核教師原鍵及固定複核位置。可換成公克的值另外獨立驗算；量感端點如實標依原鍵與教材核對。只移除走線點與紙本操作標記，保留完整左右內容及原序，不能從答案補出缺失選項。圖片、非空走線區、多圖或混合角色另分流。

候選以相同原右端點 ID 存 fields-v1，既有 matching 介面沿來源指紋顯示連線板；不擅自加一對一限制。發布新來源索引後才正式抽驗；5% 樣本操作真實連線板、開課本返回保留配對、送答及重開。來源索引與收據同批，main 發布必須先合併者，其正式收據直接補同 PR 留言，避免另開純收據 PR。詳[本批](quiz-matching5-release-20261123.md)。

### 向量圖內的完整文字端點（2026-11-24）

### 計算加整除勾選的混合來源（2026-11-24）

`automation/lib/quiz-division-selection.mjs` 只接完整文字的逐式商／餘數空格，以及整除勾選要求。逐式核原教師兩個數字、勾選記號、固定複核位置，再獨立驗算商、餘數和零餘數集合；原題號不連續、額外未映射文字、原鍵不符都拒絕。教師有示範圖時，先核圖才接受文字原鍵，沒有要求的直式過程不擅自新增作答要求。

每來源保留一個共用材料 block，每式一個獨立計算題，另有一個原算式複選題。選項沿原卷順序，不把整個來源合成單一全對／全錯。批次轉接器支援一個來源 block 多個 fields 小題，數值或複選可無過程欄，既有算式／筆跡契約保持。隔離情境按原序完成整份來源，逐題輪流製造錯誤，確認其他小題仍各自判分；不能跳過正式函式的 question_order 守衛。

抽樣以來源數及適用比例向上取整，資料及教材讀回仍涵蓋全部小題。正式複選抽驗要核每個 checkbox；已存原欄位可能是停用輸入，不保證走預覽列，詳[已存作答驗收診斷](quiz-saved-fields-verification.md)。來源數、原生小題數和作答位置分開記錄。


### 統計表、重量與原文字圈選共用規則（2026-11-24）

`quiz-statistics-table.mjs` 只以原題已知格解列欄合計，再核教師完整表及固定複核；原表仍保留空格，不用教師完整表代填材料。明確比較軸與範圍後求極值、差及合計，條件不足、並列或原鍵不合即分流。`quiz-statistics-contract.mjs` 只記來源位置與運算、不記數字答案；宣告 SHA 固定在目視核對時，禁止重跑時重算後與自己比對。答案圖有無須和宣告雙向一致，圖中完整教師表先核圖再接受，新增位置標明教師圖鍵／計算來源，不冒稱固定複核原有該位置。

統計來源的兩個無序年級格可轉成一個完整集合，位置映射保留多對一，原序、原材料、小題判分及來源數不變。原生欄位數、來源位置數、小題數分開記錄。重量文字轉接器只核完整 EMF 或固定 SHA 的已目視 WMF 轉錄；換算後每個左端點須恰有一個等值右端點，未給的一對一限制不擅加。

`quiz-text-circling.mjs` 以原文字選項作完整 domain，解析不到的字先拒絕；分數保留原分子／分母，用整數判相等或大小；重量統一換公克，相同重量須只有一組；之間的端點有選項但語意未明時拒絕；可能餘數依原十幾／二十幾範圍枚舉，不只套小於除數口訣。先獨立算集合，再對教師原文及固定鍵。每欄超過八選項、總數不超過十六時，依原序平衡拆成兩組，兩組共同構成原小題完整答案，空組可明選都不選，不截掉選項。

正式 OAuth 按來源數及適用比例向上取整；程序讀回涵蓋全部題目與教材。分數另核共用 renderer 在 1280／390／320px 的原公式與勾選、無溢出，不把隔離預覽冒稱額外正式 OAuth。`capture-quiz-practice-fields.cjs` 由固定 packet 綁定批次和樣本，首份 UI proof 已存在只核 SHA 沿用，不能補拍覆寫原收據。


### 分數文字、價目表與等值送答（2026-11-24）

`quiz-fraction-text.mjs` 保留原讀寫題，未印選項的讀法與人名用既有 text 欄，不造選項。從原等分／杯數／分子分母計算後核教師原文及固定位置；主要參考答案保留原卷分子分母，約分只作等值判分佐證，不能讓三上同分母題只顯示未教的約分。`quiz-text-source.mjs` 共用原段落／小題映射及原教師鍵；不把 text 任意套成數值。

### 圖像連線的同版型裁圖準備（2026-11-24）

### 三年級自然原生文字表格

使用 `automation/prepare-grade3-science-native-tables.py` 接收從正式來源 Word 擷取並附指紋的題幹、表格、解答及固定複核。只轉原列欄完整、無合併儲存格及無嵌圖的表格。保留共用段落與原表格的列、欄、儲存格順序。是非與單選小題獨立判分，勾選題保留原選項與多選判分方式。數值配合題沿用原表各列和代號順序，逐列核對教師 Word、書商資料及固定複核鍵，再接教材頁碼。
