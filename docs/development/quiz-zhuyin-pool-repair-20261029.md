## 來源與建池防護

原光碟字型逐字渲染核對，新增 `automation/lib/quiz_chinese_font_readings.json` 的標準注音對照，擴充 `quiz_chinese_fonts.py`。未知字型／字碼繼續拒絕轉換，不使用一般字典猜音。

`automation/quiz-all-subjects/verify-chinese-fonts.py` 回讀原 DOCX，比較候選的文字與實際顯示 layout，並拒絕純注音轉換後的重複選項。`build-pool.mjs` 在覆寫產出之前呼叫此檢查。必要的原生 Word 抽取程式已納入 `automation/lib/quiz_native_docx_content.py`，不依賴 ignored 輸出目錄裡的程式；執行仍需 Python 3.10 以上、`lxml`（可用 `py -3 -m pip install lxml` 安裝）及本機私有來源，缺資料／工具時停止，不能跳過。原題與字型不隨 Git 分發。

同步修正兩份本機國語來源目錄與私有題池產出，備份原始與中間資料，保留 2,906 題總數與本次所有穩定題號、group_key、來源關聯；新增轉換覆核資訊，避免舊目錄再次匯入。本輪沒有用整包舊部署程式重裝正式函式。

## 驗證與修復過程

1. 全部 905 題國語來源逐一掃描，其中 110 題使用純注音字型，14 題已在前次固定卷修復。本批修正其餘 96 題。905 題的被引用樣式及 basedOn 繼承另行掃描，沒有發現僅靠繼承而漏轉的純注音區段。
2. 第一輪套用後的獨立覆核抓到 11 個轉錄讀音需要再修正，涉及 11 題、14 個欄位；其中 1 份既有卷包含 1 個相關欄位。依放大原字形再次核對，並比對同讀音／同向量字形的一致性，覆核與中間版本均保留，沒有把初輪當作最終驗收。
3. 最終 211 個注音一字形的同音／同輪廓雙向一致性通過，注音二、三的 4 個字碼另以原字形核對。905 題來源語意及 layout 驗證通過，轉換後沒有重複選項；舊 96 題漏轉候選確實會被新檢查拒絕。
4. 7 項 Python 語意回歸通過，包含一般國字不誤轉、未知字碼拒絕、原干擾音、第二／第三字型、輕聲與易混聲調。96 題及兩份修正版通過現行 JS 文件驗證，建池腳本語法通過。
5. 兩輪修復均先在正式 PostgreSQL 交易內執行後回滾，通過候選一致、資料保護與原帳號 resume 後才提交。SQL 第一輪曾遇記錄變數名稱與表別名衝突，交易失敗未提交，修正後重測通過。
6. 最終提交後獨立抓回正式 96 題與版本，比對候選完全一致，原始版本與全部 7 筆舊答案逐列相等。兩個原帳號以正式 resume 核對：5 題卷保持 5 題已答、10 題卷保持 2 題已答，選項順序不變、修正版文字正確、學生投影沒有正解欄位。測試在回滾交易內，不新增學生答案或獎勵。

這是正式 SQL／API 與候選來源驗證；本輪沒有宣稱已以 Google 登入瀏覽器人工實答。既有頁面重新整理後讀取新版本；無須重做已答題目。
