# 未配到可靠課本的題庫來源

國語本批有 43 個來源找不到可靠課本對照。原本的 `quiz_pool_study_sources` 要求課本與頁碼皆非空值，因此正式回滾驗證在匯入前拒絕這些來源；沒有正式新增或啟用本批題目。

`supabase/quiz-pool-study-unmatched.sql` 讓這類來源儲存固定解析、學習重點與複核紀錄，並於新組卷綁定教材時保留這些內容。缺課本者須明示 `no_reliable_match` 與非空白理由，課本、主頁都須空值，參考頁須空陣列。已有課本者仍須完整有效的頁碼。學生作答前不取得解析；作答後可讀固定解析，沒有可靠對照的題目不出現假頁碼。

這份遷移只放寬兩欄的非空限制、以完整狀態限制取代舊參考頁限制，並更新一個新組卷教材綁定函式。保留 RLS、ACL、來源不可變觸發器與精確題目比對；不更新既有來源、固定試卷、作答或已綁定教材。函式及舊限制須符合已讀回的正式指紋，重複或未知狀態會拒絕執行。

本機驗證：

- 原生開放自評與既有配題回歸，加上新增缺課本情境，合計 12 項測試通過。
- 43 個實際候選來源全數通過正式相同欄位限制與實際綁定觸發器；固定解析、學習重點逐項相同，43 個課本欄位為空值、參考頁為空陣列。
- 驗證缺頁碼、缺理由、空白理由、零頁碼、含空值的頁碼陣列皆遭拒絕；既有固定教材、匿名／一般帳號直接存取限制保持。

**尚未套用正式庫。** 這是開放自評 SQL 之外的新遷移，須另取得使用者明確同意；同意後依 PR 進 main、重讀指紋、正式套用、產生 production snapshot 並執行 live check，再繼續完整媒體授權、停用匯入與整科驗收。
