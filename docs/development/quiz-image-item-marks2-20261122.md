# 最重與最輕拖曳標記驗證收據

- 海鮮與貓咪兩題沿用一題多位置標記。7 張圖按原卷順序對應 7 個物品欄位。各物品旁只有一個標記空格，保留拖曳、點選、鍵盤及清除操作。初始全空，第一個標記後其餘空格隨作答記為留白。作答沿用既有欄位封裝與判分。
- 兩題的教師原鍵、固定複核與重量換算一致。隔離資料庫逐題等值讀回通過，14 個判分與格式案例通過，含漏標、多標、全留白及非法封包。瀏覽器驗證含滑鼠拖曳、點選、鍵盤、清除、未揭答／揭答回顧與小隊媒體命名空間。
- 正式庫唯讀 dry-run 僅缺 7 張圖的媒體登錄。私有總帳 v48 累計 349 題上線。本次只整合程式及建立候選，未部署網站、匯入或啟用題目。
