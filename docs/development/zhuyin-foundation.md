2026-10-06：三年級已接 Google 課程身分，依使用者指定在學期共用導覽列加入中打入口，位置比照六年級。使用既有12關、90%／95%連續兩組且不限速度，成果與英打分開，過一大關長一葉；不增加第06週課程內容。下方三年級尚未開放敘述屬舊紀錄，以本更新為準。

六年級先行，使用 Google 身分與現有基礎練習服務；三年級維持尚未開放。中打獨立於週次作業，也不要求先通過英打。每一大關六小關，保留通過小關的雲端接續與重練。

## 判分與保存

- 前五小關正確率至少 90%；綜合小關至少 95%，同一次練習連續完成兩組不同題目。重開頁面保留通過小關，不沿用未完成的連續確認次數。
- 第 1–6 關：正確按鍵 ÷（正確按鍵＋錯鍵）。速度為正確鍵／有效分鐘。
- 第 7–12 關：「檢查正確率」＝已完成題目的字元數 ÷（已完成字元數＋送出檢查的差異數）。差異採字元插入／刪除／替換的最少步數；相同錯誤內容連按檢查不重複計錯。選字、組字和送出前修改本身不扣分。
- 中文速度為完成題目字元／有效分鐘，包含標點；不是原始敲鍵速度。暫停時間排除，目前中打不設速度門檻；英打門檻不變。
- 隨機題目每次重新生成，每行與前次對應行不同。不是承諾每個詞永不重複；小詞庫會重複詞語，以不同組合練習。
- 保存失敗停留在待儲存狀態，重試沿用事件 UUID，不能假裝過關。重練不寫入新成果，不倒退進度。
- 中打每大關一片葉，十二關十二葉。教師可單獨重置某學生某關；不影響英打、其他已存關卡或週次作業。後續同系列關卡須補過重置關才可再次進入。
- 資料只進 `typing_foundation_*`，不寫 `student_progress`，不使用 localStorage 儲存進度。成績權重仍由教師另外決定。

## 技術與相容性

- 課程：`shared/zhuyin-foundation-curriculum.mjs`；畫面控制：`shared/zhuyin-foundation-app.js`；入口：`grade6/115-1/zhuyin-foundation.html`。
- 使用 `compositionstart`／`compositionend` 防止組字中判分；Enter、空白與方向鍵交給輸入法。Tab 可移到檢查按鈕。禁止貼上與拖放，並非防作弊保證。
- SQL 新增 track 與速度單位。舊版 list/admin_list 預設仍回傳英打；新努力樹與後台 opt-in `include_zhuyin`，避免新雲端資料讓尚未更新的英打頁損壞。
- 難度目前集中在課程資料、前端正確率與 SQL 規則；日後更改必須同步並更新測試，不可只調畫面文字。

## 參考與驗證邊界

- [Microsoft 繁體中文輸入法](https://support.microsoft.com/zh-tw/windows/hardware/input-devices/microsoft-traditional-chinese-ime)：以微軟注音作為操作說明基準；其他標準注音配置仍可練，候選順序與操作依版本設定而異。
- [MDN compositionend](https://developer.mozilla.org/en-US/docs/Web/API/Element/compositionend_event)：組字結束後才允許明確送出檢查。
- 自動化以合成帳號／RPC 與瀏覽器組字事件驗證，不代表已實測 Windows 原生微軟注音候選視窗。正式上課前仍需教師用測試學生帳號實際驗收。
- 本次雲端部署需明確同意；部署與正式發布狀態另見驗證紀錄，不以本文件表示已上線。
