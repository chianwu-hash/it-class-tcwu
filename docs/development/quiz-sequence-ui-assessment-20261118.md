## 原建議（後續已核准）

- 每段文字一張卡片，依序排列，保留句子閱讀大小、清楚的目前位置與拖曳把手。拖曳完成後可直接讀成順序連貫的內容。
- 手機與鍵盤提供上移／下移替代，不以拖曳作為唯一操作。原選項代號可作較小的來源標記，不能與目前位置混淆。
- 沿用sequence欄位、原選項ID陣列、判分與一次送出；不增加第二層確認或另建作答流程。既有答案依原陣列顯示，不重新亂序覆蓋已保存順序。
- 分清未操作與真正作答：初始卡片排列不得在未互動時被當成已填答案；不預設正確順序。小題／句子不能再與其操作區分離，也不需在下方重複列一次相同選項。
- 先以回報原題做獨立示範，再驗個人、整卷回顧與夥伴；真正跨多欄排序及圖片／表格選項須另核原件，不能依排序字樣直接改型。
