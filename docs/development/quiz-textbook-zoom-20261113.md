# 共用課本閱讀器：預設80%、最小20%

考古卷先建立共用燈箱時沿用100%下限；課本閱讀器接用既有實體，後續初始化參數不生效。一般題庫雖可縮至20%，課本首次開啟仍固定100%。

現在由共用 `quiz-textbook-reader.mjs` 在每次開啟時指定80%初始倍率、20%下限與10%按鈕步幅。燈箱依當次檢視選項套用，不受入口初始化順序影響；關閉後一般題圖恢復原本設定。按「適合寬度」仍為100%。首次80%時修正頁首定位，避免縮小後空出多餘上方空白。

同一題、同一課本頁的倍率和平移優先從當頁記憶恢復；前後頁、頁碼選單、完整拉頁、返回題目、選答與焦點保留原契約。記憶僅在當次頁面生命週期，不新增跨登入或跨重新整理的持久儲存。

驗證：

- 修正前以實際一般與考古入口、1280／390合成資料重現：一般初始100%／最低20%，考古初始100%／最低100%。
- 修正後83項桌機／手機檢查通過：兩入口首次80%、按鈕／滾輪／可信任雙指事件最低20%、適合寬度100%、10%步幅、實際滑鼠平移、翻頁及重開位置恢復、79–80完整拉頁、選答保留、Esc／焦點及登出清圖。一般考古題圖的原100%設定未被課本選項污染。
