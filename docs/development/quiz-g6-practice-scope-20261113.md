# 六年級自然、英語期末範圍分類修正

六年級自組卷預設「期末範圍」，但範圍分類只有三年級規則，造成六年級單元被當成未知而隱藏，必須切到「全部」才能選。新增115上南一六年級自然、康軒六年級英語的已核分類：1、2單元期中；3、4單元期末。期末老師卷也可顯示正確分類。

- 只接受確定的course ID，並核對學年度、年級、上學期、出版社及科目；其他教材維持未知，不因標題猜範圍。
- 沿用既有shared模組、範圍切換、課程目錄及navbar；分類只影響呈現，不修改授權、作答、進度、RLS或題庫開放狀態。
- 6項程式測試通過，涵蓋原有三年級、固定版本教師卷、四／九年級原有來源隔離，以及新六年級前後／跨範圍／錯版本拒配。
- 實際瀏覽器1280、390寬度共27項檢查通過：六年級老師卷、自組自然及英語預設3／4、期中及全部切換、隱藏勾選清空、登出清空、無正式送答／刪卷呼叫及無橫向溢出。使用本機合成身分及資料，不冒稱真人學生OAuth驗證。
- quiz:build／quiz:check 21產物通過。更新16入口的版本資訊及assets manifest，四個年級共用同一個已核模組；沒有改版型或樣式。
- 私有驗證截圖與收據在F:/AI-Work/grade6-priority-20261112/scope-ui。前一輪UI測試因分頁隱藏導致click的穩定性等待逾時；啟用本輪精確分頁後以真實點擊完整通過，沒有修改產品程式來繞過檢查。
