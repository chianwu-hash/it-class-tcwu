# 閱讀題組：文章與小題對照（2026-11-16）

原呈現把六個小題集中在文章末端，答題欄只剩編號；勾選文字又遠小於單選。現在每個小題完整題文放在自己的選項上方。個人桌機寬度至少1100px時，文章與作答區左右並列，文章可獨立捲動並停留；較窄畫面文章置頂且最高半個視窗，可捲動讀完。文章、教材時間及用語補充完整保留。

`quiz-reading-presentation.mjs`只做學生呈現：先經既有選項／重複內容投影，再要求閱讀理解標題、連續小題編號、欄位編號與數量完全相符。只有single／set混合題組可套用；多行不明題尾、圖表無法無損切分、音訊及欄位不明者原樣保留，不猜對應、不刪原資料。小題圖文切片保留原格式及文章圖片；已辨識的紙本打勾叉指令由實際欄位的勾選／單選提示取代。個人、教師完整回顧與夥伴共用小題對應；左右對照與文章限高只套個人頁，未重作夥伴外層。

保留原欄位／選項ID、型別、選項內容、答案、fields-v1資料與既有作答；仍是原外層一次送出，沒有逐小題提交或新增判分。沒有SQL、正式資料寫入或AI重送。
