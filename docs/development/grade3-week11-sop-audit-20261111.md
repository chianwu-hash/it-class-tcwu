# 第11週週卡修正與SOP補查

2026-11-11，使用者指出第11週沒有本週徽章、第10週仍標本週，要求修正並回查SOP及其他漏項。本批沿用使用者自行驗收後發布、免Claude複核的指示，Codex唯一寫入者。來源為最新 `origin/main 04aa0aa` 的新工作樹，未修改主工作區。

## 已確認的遺漏與原因

1. **已有要求卻漏做**：`lesson-to-web-sop.md` 第9.2節原本就要求移除上一週「本週最新」；`dev-sop.md` 第1.0節要求最新週標記。第11週只設 `data-latest-week="true"`，第10週可見「本週」徽章未移，當時瀏覽器測試只斷言資料屬性及隱藏，未檢查徽章文字或首頁桌手機畫面。完整檔案樹／SHA只能證明發布內容一致，不能證明內容正確。
2. **驗收證據不足**：三處同步的原始證據只有合成首頁／navbar隱藏，未找到第11週以真正教師後台切換的紀錄；不能據此勾選正式後台驗收。此次已核對可見教師帳號與程式白名單相符，實際隱藏／顯示第11週，首頁卡及navbar同步、恢復成功，舊學期可見性不變。沒有改學生進度。
3. **驗收動作漏測**：原六關測試有檢查魔王慶祝文字，重練測試直接移除overlay，未實點努力樹按鈕及返回。此次補成真正點擊既有努力樹頁與返回來源頁；樹頁使用合成匿名身分，避免觸發真學生升級／已讀。
4. **SOP內容過時**：頂部雖有2026-10-06轉換說明，數個現行三年級條目仍寫課堂身分卡、`guest_progress`、不支援努力樹；檢查表獎勵仍泛寫N−1葉。已修正現行條目、將舊初始化標為歷史樣板，補明 `five-then-flower`。歷史身分卡分支本身保留。
5. **首頁摘要未跟進**：第11週摘要漏列後加的Ctrl＋Z；第10週停課文字仍稱「本週」。本批同步摘要與明確歷史週次，不變動舊活動。
