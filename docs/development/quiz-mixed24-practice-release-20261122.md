# 三年級混合題 24 組上線與課本對照驗收

正式練習卷「三年級數學：磅秤、分數與交通表格」保留 24 組的共用材料、57 小題原順序及獨立判分。批次候選的隔離驗證涵蓋 108 個作答位置與 132 組正誤情境。

| 檢查 | 結果 |
| --- | --- |
| 題圖按 SHA 對帳 | 34 張。沿用 20 個 Drive 檔案及 Worker 索引，新增 14 個私有檔案及索引。 |
| 正式供圖與登錄 | 34 張實際供圖的 SHA、MIME 和位元組數一致。新增 31 筆私有媒體登錄，沿用既有 3 筆，全部讀回一致。 |
| 課本必經關卡 | 57 小題逐題核對翰林三年級上學期原頁與正式對照，共掛 15 張相關印刷頁。48 小題直接對應課本方法或原型，9 小題連到相關觀念。 |
| 正式 OAuth 抽驗 | 依 24 筆抽 2 題。九宮格分區開第 121 頁，集集支線時刻表開第 134 頁。兩題在桌機、手機都能翻頁、回本題頁、返回原題、保留欄位作答，送出判分及重載讀回皆過。 |
| 上線後讀回 | 正式練習庫可找到這份卷，57 小題的順序、題幹、答案、共用材料和課本對照讀回一致。 |
| 總帳 v57 | 已上線原始題目來源從 360 筆增至 384 筆。其餘 108 筆混合題維持分流。 |

正式資料庫函式、權限與網站程式維持現行版本。這份卷可用已在隔離驗證的回復步驟關閉並取消顯示。
