# 六年級課程頁固定視覺風格

2026-11-11 使用者定案：三、六年級每週各自維持原有風格，不互相套版。六年級以 `grade6/115-1/week09.html`／`.css` 為固定視覺基準，參照已修復的第10週與 `grade6-week10-web-20261106.md`「恢復原有六年級風格」，不能沿用已淘汰的淺綠簡化版本。

## 每週必留元素

- Noto Sans TC 400／700／900，醒目粗標題及適合高年級的清楚資訊層級。
- 紫／靛／藍綠漸層頁首、黃色標題重點、半透明重點卡；六年級不改成三年級的青綠小小兵頁首。
- 白底24px圓角任務卡、4px彩色邊框、柔和陰影、圓形編號／圖示、粗體標題。主區段依教學活動用淺藍、紫、橘、綠分色，維持明確實心按鈕及焦點。
- 適量可愛圖示與插畫、清楚步驟及同頁放大圖卡，不退化成純文字長頁，也不把裝飾加到干擾操作。
- 大型任務需要收合時沿用原生details、預設展開及原互動規範；圖示／樣式不能取代文字、授權、保存與完成提示。

## 每週資訊圖卡

依[每週資訊圖卡規範](weekly-infographic-sop.md)必做，沿用第09週 `images/week09/week09-infographic-v2.webp` 與第10週正式style2圖卡的活潑水彩／粉彩筆觸、深藍粗圓字、紫／藍綠／橘／天藍分色、白色圓角分區及高年級兒童插畫。生圖時實際上傳同年級既有圖作風格參考，不只在prompt寫「沿用風格」。不複製舊週文字、活動、時間或班級範例。

三年級可共用產製流程，不能因此改成這套六年級圖卡風格；六年級也不能套三年級低年級圖卡。沒有使用者指定的新方向或具體教學需求，不自行換主色、圖示系統或整體版型；必要差異寫入本週契約。

## 必做驗收

每週列出固定視覺基準、同學期參考、保留元素及必要差異。用同一瀏覽器、1280px桌機與390px手機對照參考頁／新頁的頁首、任務標題、按鈕與圖卡；實際檢查圖示字型、4px彩框、900字重、分色、無重疊／水平溢出，不只查class或CSS import。圖卡逐字／逐圖核對、Cloudinary回讀及燈箱縮放／拖曳／關閉／焦點恢復另驗。尊重減少動態效果，裝飾圖示aria-hidden，關鍵資訊保留文字。建置來源與產物同步，功能驗收仍照原契約。
