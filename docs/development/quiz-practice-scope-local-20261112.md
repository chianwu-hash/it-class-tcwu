# 考試範圍收納：僅本地驗證

2026-11-12，使用者授權實作及本地驗證，明確要求先不要發布。本分支從origin/main db8b895建立，不修改主工作區、不接續其他對話的題庫工作，沒有PR、遠端推送、部署或正式資料庫操作。

## 行為

- 選卷頁預設「期末範圍・期中考後」，可切換「期中範圍」「全部」；教師卷、考古卷、我的自組卷共用選擇，錯題保留原本人清單。九年級採第1／2次段考用語。
- 已開始但尚未完成的卷仍顯示接續入口，不因範圍或科目篩選失去連結。舊卷只改呈現收納，不刪除、不重置、不回寫範圍到固定版本或學生紀錄。
- 考古卷依原考次收納，保留原學年度、出版社、整份卷、原連結及enabled限制。期末考古卷標示「依原卷範圍」，不聲稱必定只含期中後教材。明確mixed資料標示含期中前內容，兩範圍都可找到。
- 未能確認的卷放入「範圍待核對」可展開區，保留入口。不能用標題含「期末」就硬分類。
- 自組卷只顯示所選範圍已核單元，切換後不殘留隱藏勾選；沒有已核範圍時提示切換「全部」。組卷仍只傳既有units等參數，沒有新增API權限或改判分。

## 分類資料與限制

明確catalog.practice_scope（before／after／mixed）可作呈現依據。考古卷沿既有exam=1／2與sourceYear。已核單元邊界目前只加入115上翰林三年級數學1–5／6–9及自然1–2／3–4；課程id與年級／學年度／書商矛盾時拒絕套用。其餘年級科目須補經核定的課程邊界或明確metadata，目前保留待核對／全部入口，不從單元數猜切半。

這是前端收納與篩選，不建立或啟用期末試卷，也不改後端名冊、可見性、RLS、作答、獎勵或私有教材授權。
