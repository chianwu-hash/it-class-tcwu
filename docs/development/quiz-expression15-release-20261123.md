# 算式與單位 15 筆上線及效率共識修正

沿前批參數化工具，完成除法、公斤／公克換算與原式六格共 15 筆、34 個作答欄位。來源與教師鍵 SHA、獨立驗算、49 組全對／逐欄錯答及保存等值讀回通過。原式六格保留原題位置和原鍵，算式與答案一起保存。

15 題逐題核課本原頁及正式對照，10 個印刷頁碼的既有供圖 SHA 通過；第 111／112 頁為同圖跨頁，SQL 查完整 printedPages 陣列。正式 OAuth 按 5% 抽 1 題六格題，桌機／手機開第83頁、切84頁、返回保留六欄及算式，判分與重開通過。整批老師練習卷上架後，15 題全文、答案、材料、順序及教材逐題讀回一致，學生正式入口可見。總帳 v61 為 708 筆列管來源已上線 440 筆、剩 268 筆。

與 Claude 兩輪唯讀討論後，由 Codex 查實並採納：

- 共用載入器核 printed 必屬於自己的 printedPages；同頁只能對一個圖 ID，同 ID 拆列須保持頁碼陣列與 SHA 一致。跨頁正反例測試通過；這批實際資料全部符合，無已上線誤綁。
- 時間只放獨立、首次寫入後保留的 timing 紀錄，避免改動 runner 會核 SHA 的凍結收據。後續統一記選來源、清單通過、隔離完成、OAuth 起訖與正式入口，標明 development／production；舊批次不回推。
- OAuth 重驗保留第一次正式收據，另存查核紀錄。正式重跑本批樣本，保存答案未重送，原收據 SHA 不變。10 項共用自動測試通過。

抽樣數由程式計算，樣本依凍結清單挑選高風險題；不宣稱程式隨機抽題。Python 與 JavaScript 的答案推導目前在受限契約內一致，下一次擴充題型才集中至 plan，這輪不順便擴大支援。

本批成功來源處理開始至入口驗證為 171.934 秒，不含初稿腳本準備及兩次來源解析 debug；其中 runner gate／啟用／SQL 讀回 28.241 秒。前批 25 筆紀錄含工具開發，兩批起點不同，不能換算加速倍數。目前只能確認共用腳本逐批改題號／答案／頁碼為 0、正式寫入故障恢復為 0，以及三階段重跑均跳過。主動人工工時未記錄。
