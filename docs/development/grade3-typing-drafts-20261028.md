# 三年級所有週次打字草稿

日期：2026-10-28。

115-1 第 02～09 週的全部九個打字活動（包含第 02 週信箱任務）啟用手動「儲存草稿／回復上次草稿」。第 01 週沒有中英打活動，維持免登入規則。舊學期十個既有打字活動保留原本的草稿設定；全三年級共十九個週次活動皆已啟用。

學生需先登入學校 Google 帳號並通過本人名冊核對。離開前按「儲存草稿」，看到成功訊息後再離開；下次登入同帳號，主動按「回復上次草稿」。已有輸入內容時先確認覆蓋。只回復輸入文字，不把草稿當成過關；隨機數字練習仍需核對當次題目，信箱投遞順序需重新操作。

共用模組契約：

- `draftOptions: { enabled: true, getSession: () => auth.getDraftSession?.() }`。115-1 的 Google 課程進度 adapter 需明確提供通過本人核對的草稿 session。舊學期一般 Google 模式仍使用原本 session。
- 草稿 session 與 `currentSession` 分離，避免啟用草稿後，正式進度誤走一般 `student_progress` REST 分支。三年級正式成果仍由既有 `save_grade3_progress` RPC 保存。
- 草稿沿用本人核對時的登入 session，依 auth 事件更新 token；每次儲存與回復不再呼叫 SDK 的登入狀態讀取／更新流程。
- 草稿僅寫入既有 `typing_drafts`，包含本人、課程、週次、活動與關卡篩選；115-1 不使用省略 `course_id` 的舊 schema 相容退路。無資料庫結構變更。
- 換帳號或登出立即失效草稿狀態，延遲回應不得回填；草稿失敗不阻擋正式過關保存。輸入框已有文字時須確認覆蓋，過關保存成功後清除該關草稿。
- 回復後發出 `input` 事件。特殊多欄位介面可提供 `draftOptions.onRestore(level, text)`，將共用輸入值同步回實際欄位；不得在 callback 另寫進度。
- 不加入自動存檔、定時輪詢、切回分頁存檔或瀏覽器儲存空間進度。頁面控制器與共用模組的版本查詢字串同步更新。

驗證工具：`automation/tests/grade3-typing-drafts-browser.cjs`。使用已取得租約的 AI 工作瀏覽器，經 `D:/ai-browser/run-background.cjs` 執行，環境需提供精確 `DRAFT_TEST_TARGET` 與本機測試站 `DRAFT_TEST_BASE`（預設 `http://127.0.0.1:3043`）。登入、名冊 RPC、草稿 REST 與正式進度均使用合成資料，不寫真實學生成果；結果與畫面置於忽略的 `tmp/grade3-typing-drafts-qa/`。

本機驗證已通過：十九個週次活動設定盤點；九個現學期活動逐頁儲存與重整回復；信箱欄位同步；舊學期一般 Google 流程相容；第 09 週最後一關多行英語草稿；覆蓋確認的取消與同意；草稿／進度失敗與重試；正式 `save_grade3_progress` RPC 參數與成功後草稿清除；未登入／名冊核對失敗拒絕；token 更新、切回分頁不自動保存；延遲草稿回應遇身分失效不回填；1280／390px 無水平溢出且已檢視畫面。修改的模組語法與 UTF-8 字元檢查皆通過。

已依使用者確認隨找字小幫手正式發布；正式主網址檔案摘要與合成帳號的草稿／進度流程通過。2026-10-29 與找字小幫手獨立整理提交，識別與推送結果以 Git 紀錄為準。沒有真實學生寫入或新的 OAuth 驗收，原生中文輸入法仍待實機確認。詳見 `grade3-typing-helper-release-20261028.md`。
