日期：2026-11-01。狀態：Codex 初步提案與 Claude 回饋後的建議，尚未由使用者核定實作。

## 目標與界線

使用者要求先由 Codex 提出看法，再請 Claude 討論打字基礎、考前練功坊等功能的教師管理機制，重點為個別學生學習紀錄。這次只盤點、討論及保存結果，未修改產品程式、資料庫、學生紀錄或部署。

Codex 是唯一寫入者；Claude 只用 Read／Glob／Grep，不可修改、shell、網路、憑證、正式資料或另叫代理。工作樹有大量既有異動，不納入本次範圍。

## 已核對的現況

- `admin-typing-foundation.html`、`shared/admin-typing-foundation.js` 已有課程選擇、逐關進度、過關時間、最佳達標速度、CSV、revision 防護的單關重置。缺口是班級座號／學生整合入口與事件明細，不是全部後台從零做。
- `typing_foundation_progress` 是目前成果；`typing_foundation_events` 保存送出結果、正確率、速度、耗時與版本；`typing_foundation_resets` 保存教師重置歷史。現有 `admin_list` 只提供摘要，事件與稽核明細仍需教師查詢路徑。
- 中打課程前段為注音鍵位，後段 `mode='ime'` 是中文輸入；SQL 有 `keys_per_minute` 與 `characters_per_minute`，不能全稱注音或宣稱沒有中打速度。英打使用 WPM，三種單位分開呈現。中打速度僅記錄。
- 已通關自由重練不一定走保存流程；事件耗時不等於完整學習時數，未記錄的活動無法回推。
- `admin-quiz.html` 是題庫備課及場次管理；`shared/quiz-sessions.mjs` 的場次監看主要列已答／總題數。現有 `monitor` 限場次擁有者，不能直接提供教師查看所有學生自組卷的功能。
- `quiz_attempts` 每學生每場次唯一，`quiz_answers` 每次作答每題唯一。相同請求可重試，不同答案衝突，故同卷同題沒有重答序列。原答案、正誤、時間與固定版本可供教師明細查詢，但需專用權限路徑。
- `quiz_generated_papers.config` 保存延伸卷來源題資訊。延伸卷是同知識點不同題，不是原題重做；可呈現關聯及各次表現，不直接推論熟練度。
- 學生刪除自組卷是列表軟刪除，SQL 保留版本與作答。教師頁應說明隱藏狀態與統計口徑，不能當成沒有練過。
- 本機缺少交接紀錄提及的已上線題目回報模組；因此回報功能須查目前完整發布來源，不可斷言尚未實作或另做重複系統。

## 建議範圍與優先順序

| 優先 | 功能 | 教師實際操作與用途 |
|---|---|---|
| P0 | 年度名冊與身分對應 | 選學年度／課程／班級，依座號點學生。以可信帳號對應各資料來源；不能用姓名自動合併舊身分卡與 Google 成果。未對應與查詢失敗分開顯示。 |
| P0 | 個別學生學習檔案 | 同頁分區呈現週次成果、英打／中打基礎、練功坊；可看最後有紀錄時間與來源明細，不合成跨活動總分。 |
| P0 | 打字明細 | 各關目前小關、完成狀態、門檻、時間及速度單位；展開看已保存事件的正確率／速度／未過原因可得欄位，重置前後版本分開。沒有紀錄則明示，不猜測學生是否練習。 |
| P0 | 練功坊單卷明細 | 試卷／科目／單元、已答與總題數、已答正確數、是否全卷完成；展開原答案、正解與解析，標明題目版本。未完成卷不能用總題數算成正式零分。 |
| P1 | 班級待關注視圖 | 以完整名冊看尚無紀錄、已開始未完成、最近有未通過事件；每項可展開依據，教師自行判斷是否需協助。自由閱讀不列缺交。 |
| P1 | 延伸卷關聯與匯出 | 原錯題連到同知識點延伸卷；依班級／學生／日期匯出，標明單位、分母、範圍及資料時間。 |
| P1 | 題目回報管理銜接 | 先核對正式發布中的既有回報機制，再補教師處理入口、狀態與版本連結。 |
| P2 | 教學分析及管理設定 | 知識點／題目錯誤分布、指定練習與班級開放管理、門檻及成績權重；分別訂契約，避免以顯示設定冒充伺服器權限或改動既有成績。 |

第一版建議維持唯讀，重置導回既有後台。新頁不另做改分、代答、補發成果或批次清除。努力樹可作成果來源的附加查詢，但不當作能力或努力排名。

## 實作前提與驗收方向

- 新增教師限定的摘要／事件／試卷明細查詢；伺服器核對教師、年度與允許範圍，不重用僅限本人資料的學生端 RPC，也不將教師身分冒充學生。
- 伺服器端篩選及穩定分頁；先摘要再按需載入明細，無逐學生 N+1、全校題目展開或高頻輪詢。實際索引與查詢計畫須另查，不依本機 SQL 搜尋就推論正式庫缺索引。
- 明確分開沒有紀錄、帳號未對應、未完成、未開放及載入失敗；正確率顯示分母與完成狀態。最近活動時間只稱「最後有紀錄時間」。
- 英打／注音按鍵／中文輸入不混畫速度曲線；同類關卡、同門檻與同版本才有合理比較基礎。
- 驗收涵蓋未登入／非教師拒絕、跨年度身分、名冊有但無紀錄、超過一頁、未完成試卷、重置舊版本、軟刪除卷、延伸卷關聯及部分來源失敗；查閱過程不改學習資料。
- 主工作樹與正式站並非必然一致；實作前核對最新完整正式發布來源及實際 schema，不從較舊 main 整包覆蓋。

## AGY 第三方評議（2026-11-01）

使用者要求意見分歧再問 AGY CLI。由 Codex 提供雙方論點、已核對事實及未知範圍，AGY 不讀主專案、不用工具、不接觸學生資料。模型為實際可用清單中的 `gemini-4-argon-medium`，CLI 1.4.12。

AGY 支持「逐題明細屬第一版核心需求」，但建議分成兩個可獨立驗收的工程階段：

1. 名冊對應、學生摘要、試卷列表與打字事件。
2. 點開特定試卷才載入逐題明細，兩階段同屬第一版目標。

最小明細包含題號、題幹與必要材料、學生原答、正解、正誤、解析、版本、已保存作答時間及試卷狀態；可切換全卷／只看錯題，包含未完成卷，未答明標未答。非選擇題須核對實際型別，不能因第一版而默默漏列。跨卷圖表、雷達圖與全班對照可延後。
