# 考古題轉線上題庫：實作經驗與下次作業指南

記錄日期：2026-10-29。根據三年級自然考古題的實際上線經驗整理；本文件是可重用方法，[本次發布紀錄](past-exam-production-20261029.md) 保存部署、版本及驗證證據。功能程式提交為 `cb69adb`，分支 `codex/past-exam-production`。

## 1. 先確認來源，再選一份小樣

先讀 manifest，確認學年、學期、年級、科目、評量次別、出版社、檔案格式及版本，建立試卷與官方解答的一對一配對。下載完成不等於可轉題：仍須檢查 PDF／文件是否開得啟、頁面完整、試卷和解答是否同版。

先目視原頁，再挑 5–10 題，至少涵蓋文字、必要圖表及共同題幹。小樣逐題核對後，再補完同一卷。這次完成的是單份自然試卷；其餘試卷沒有因本次上線而自動完成轉換。

每題至少保留：穩定題號、原章節與題號、原題型、原配分、原題文／選項、共同題幹關係、試卷頁、解答頁、官方原記號、來源版本、檔案 SHA-256、校對結果及疑義理由。中立題庫是可追溯的轉換來源，不直接視為網站現有 schema。

原文、選項與代碼須忠實保留；文字抽取與 AI 轉錄只是草稿。圖表對照題尤其要核對圖中的 A／B／數字和答案代碼，不可只看文字是否通順。缺字、矛盾或看不清楚時標記待確認，不猜補。

## 2. 以最小圖片保留題意

能用文字重現的內容使用文字；只裁答題必要的圖表。共同圖表建立單一媒體來源，官方答案圖另列，避免把答案裁進題圖。檢查裁切邊界、解析度、標號、方向與圖片對應題號；保留圖片尺寸、SHA-256 與來源頁。

本次使用 8 張必要題圖與 1 張官方畫圖參考圖。正式上傳後逐張下載核對雜湊；原卷與完整解答沒有公開上傳。圖片的「內容雜湊識別」和「網站可存取位置」分開處理，正式 URL 由媒體層提供。

## 3. 題型應保留原作答意義

| 原題作答方式 | 本次已實現 | 判定重點 |
| --- | --- | --- |
| 是非 | O／X 單選 | 答案是布林值；UI 只顯示一份 O／X，不把選項代碼與文字重複印出 |
| 選擇 | 單選 | 儲存穩定選項 ID，不能依畫面位置判分 |
| 圖號／代碼填答 | 代碼選取 | 保留原 A–D 等代碼與圖文對應 |
| 排序 | 完整序列 | 須為合法、完整、不重複的序列；順序有意義，並提供鍵盤／按鈕操作 |
| 多項填答 | 集合 | 驗證代碼合法與不重複；相同集合不同送出順序仍視為相同答案 |
| 標示／畫箭頭 | 圖上點選及箭頭、自核對 | 綁定圖 SHA 與正規化座標；不宣稱自動判斷畫圖正誤 |
| 官方答案有疑義 | 保留題號與問題清單，暫停作答／計分 | 不把 null 當錯誤、零分答案或自動答對 |

上述是本次實作範圍，不代表已支援一般自由文字申論、任意手寫辨識或自動畫圖評分。新增題型前，先定義輸入、合法值、計分與揭答時機，再做元件。

本次原卷共 67 小題／100 分；轉為 40 題組、64 作答欄位，其中 63 自動欄位共 92 分、畫圖自核對 4 分，3 疑義題共 4 分暫停。題組數、欄位數、配分不能混為一個指標。

## 4. 先查既有契約，再寫轉接

開發前閱讀專案規範及同型頁的實際 auth、進度、揭答、媒體與獎勵流程。這次以 `initQuizModule({mode:'past-exam'})` 明確分流，沿用共用 Google／名冊驗證、navbar、authenticated transport、內容 renderer、媒體權限、燈箱與 rewards 入口。保留已驗收的作答方式，使用網站既有主題 token；CSS 限定在作答區域，避免影響導覽列。

不要為了接非選題而修改所有舊題的格式。這次以私有 `quiz_past_*` 資料模型接中立題庫，保留 schema 1 與原 `quiz_action`；只有 rewards 與 media 的整合點使用包裝，並保存原定義。這是本專案此次的實作決定，不是其他專案可直接照貼的通用 SQL。

教師預覽與學生作答分開授權。教師需看來源頁、版本、官方答案、疑義與圖片；學生回應只給白名單欄位，未提交前不含答案、私有來源或官方參考圖。登出／換人要清空圖文、撤銷媒體 scope，晚到的非同步回應也不能把上一人的內容畫回去。

## 5. 重作、達標與給葉必須由後端一起保障

本次規則：單次完整作答的自動計分達 60% 才合格；不得把多次答對題目累積成一份及格作答。畫圖仍需完成標示與自核對，但不算入自動分數。疑義題不進分母。以原配分加總，不使用答對題數比例；本卷 55／92 不合格、56／92 合格。

來源試卷學年與目前學習學年分開：本卷來源為 114 上，學習紀錄屬 115 上。每次作答使用獨立 attempt 並釘選不可變內容版本；重作新增紀錄，不覆蓋上一筆答案。獎勵唯一鍵為「學生＋學習學年度／學期＋穩定原卷 ID」，不能用內容版本作唯一鍵，否則改版可能重領。

題組驗證、送答收據、答案、整卷完成及首次葉片寫入同一交易。先驗證整組合法才寫入，任一環節失敗整組回滾。相同 request_id 與相同正規化答案可安全重送；成功回應在網路遺失時，前端重用原封包，而非產生新的一筆。再次高分不多給葉，後續低分也不收回已領葉。

「看題時間」由後端 view 記錄，不能接受前端自報的 elapsed。測試加速只在本機 fixture 或明確回滾的雲端測試交易中操作，不提供正式前端略過計時的開關。

## 7. 驗證要涵蓋資料、權限與真實操作

本次完整回歸為 66 項通過、零失敗／零略過（約 64.9 秒）。另做真 Supabase PostgreSQL 交易驗證後 rollback，並用正式 HTML／JS／CSS 搭配隔離身分與 RPC 驗收；這些證據不能冒稱真人 Google OAuth、實班多人並行或正式壓測已完成。

下次至少重做以下檢查：

1. 文字／圖表／共同題幹及各題型逐題對照官方解答，明確列出所有未計分原因。
2. 未登入、錯年級、他人 attempt、非擁有者教師與未提交參考圖都被拒絕；直接資料表權限也要查。
3. 非法一個欄位時整組不寫；題組及首次葉片失敗時回滾；相同答案重送不重記，變更答案的衝突重送被拒。
4. 跑完整「未達標→首次達標→再次達標」，核對各次成績及葉片 0→1→1，而非只測單題答對。
5. 檢查排序的鍵盤操作、手機圖文、選項標籤、無共同題幹版面、桌機／手機無橫向溢出，以及登出後圖片和晚回應清理。
6. 比對舊答案、舊版本、舊葉片及非預期函式，確認沒有因轉接而改寫；測試假資料不得留在正式站。

教師可人工確認原題與圖表、處理官方答案疑義；轉檔、雜湊、合法值、配分加總、成績門檻、冪等與權限測試可自動化。AI 轉錄與畫圖判讀仍需人工校對。沒有完整逐階段工時紀錄，不能將回歸測試時間當作整卷轉換工時；下份應另外記錄轉錄、裁圖、校對、整合與驗證用時。

## 8. 本次踩過的坑

- **O／X 重複與空材料框**：選項代碼加文字造成重複，空共同題幹仍占位。依實際題型渲染並在桌機／手機目視檢查。
- **網站主題被蓋掉**：作答 CSS 的載入順序覆蓋網站主題。調整主題順序與樣式範圍，不能只看單獨 prototype。
- **生成器／發布目錄混淆**：發布只使用已核對的完整基礎包加本次疊加檔，明確指定 cwd；不能從有其他未發布工作的主工作區整包部署。
- **PowerShell 不因 native exit 1 自動停止**：相依步驟檢查 `$LASTEXITCODE` 或分開呼叫，避免前一步失敗後仍繼續部署。中文透過 UTF-8 檔案與結構化 patch 傳遞。
- **受保護候選頁讀到 SSO**：使用已有帳號授權的 Vercel CLI 讀取實際檔案，不解除部署保護；`vercel curl` 後的 `--scope` 會被轉給 curl，不能照其他 Vercel 子命令用法追加。
- **favicon 與 API 誤列失敗**：測試 fixture 應如實回應不存在 favicon 的 404；靜態 SHA 比對排除執行式 API，不能把其 GET 405 當靜態檔遺失。
- **同網址選錯 CDP 分頁**：本機 client 用 URL 前綴找頁，不保證挑中最新 tab。新建唯一 QA query，先斷言精確 target；需要可見性時核對租約後啟用。背景等待可改固定間隔，不依賴隱藏分頁的動畫時鐘。
- **題目版本與領葉 ID 混用**：內容版本可新增，領葉仍依穩定原卷 ID 去重；不可用「改版」繞過一次給葉限制。

## 9. 下次發布與回復

本次從最新第四批 433 檔凍結包疊加 13 個 runtime 檔案，候選逐檔驗證後再 promote，正式 247 靜態檔比對一致。未來必須重新查當時最新正式基礎，不可把本次包永久當最新。

發布順序為：整理校對來源 → 本機轉接與相容驗證 → 私有媒體核對 → 新卷先 disabled 註冊 → 雲端交易 rollback 驗證 → 候選部署／檔案與操作驗收 → 正式切換／再驗收 → enabled。各階段要有可核對產物，不能靠自然語言宣稱完成。

回復先停用本卷，保留歷次作答與領葉帳本；必要時回復前端及被包裝的原函式，不刪學生資料。既有 quiz SQL 有 batch1→2→3→4 相依，本次考古題整合在其後；重裝舊 rewards／media 時要同步檢查包裝與備份。

下次開始時，先讀本指南及最新 `agent-handoff.md`，檢查目前正式版本、來源可得性、規格差異及授權範圍，再選一份小樣。這份指南本身不授權批次轉換、發布新卷或改學生資料。
