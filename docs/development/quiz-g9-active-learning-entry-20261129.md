# 九年級完成原卷後的主動練習入口

正式九年級已有 `learning.html`、本人完成原卷的清單及固定重點練習，但生成後的選卷頁沒有掛載舊學習摘要模組。該舊模組內的三年級連結條件，不能當成目前生成選卷頁已有入口的證據。

在九年級現有「考古題專區」標題下新增「完成原卷後，主動選學習重點再練習」，連到既有九年級頁面。沿用考古專區的登入、學生資格及分頁可見性，未新增RPC、權限、作答或判分流程；後端仍要求本人完成原卷才列出主動重點。教冊答前閱讀設定保持。

只新增九年級入口，既有三／四／六年級的選卷流程保持。經 `build-quiz-workshop.mjs` 更新產物及指紋，從乾淨main依發布腳本上線後，再由正式學生首頁→選卷頁→考古題專區→新連結→已完成原卷→重點實測。正式結果待回填，不以語法或生成檢查冒稱學生驗收。

回復可經PR移除此連結並重建產物，或依發布紀錄回到原基準部署；不改資料庫與已存作答。
