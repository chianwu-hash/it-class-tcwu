# 答案工具按鈕與浮動鍵盤（2026-11-18）

## 功能契約

- 注音、標點與數學符號沿用完整符號集，共用 `quiz-input-keyboard.mjs`／`.css`；`quiz-past-input.mjs` 保留原匯出入口。
- 工具按鈕使用 10px 間距、圓角、開啟狀態與鍵盤焦點框。開啟不再展開或撐寬答案格。
- 同時僅開一個浮動鍵盤，標題帶答案格名稱；提供「關閉 ×」、Esc、點擊外側及切換答案格收合。原實體鍵盤仍可用。
- 浮層沿可視視窗定位，避開原送出列；答案格被遮住或在視窗外時捲動至可見位置。不另增送答步驟。預設高度依完整按鍵內容決定，不能用固定380px截斷最後一排；不以隱藏捲軸掩蓋缺鍵。
- 輸入保留原游標、選取取代、字數上限、input 事件與原回應格式；刪除不拆開 Unicode 字元。粗指標裝置的注音／標點面板暫停原生鍵盤，關閉即恢復原 inputmode；數學保留 decimal 輸入。
- 換題、卸載或鎖定答案時清除面板與監聽器。已送答不加工具；無 SQL、題目、答案、權限、既有作答或外層介面變更。

## 驗收與限制

- 55 項相關 fields／閱讀題組／open／math 回歸通過，另有 4 項輸入輔助測試包含於其中；21 個建置產物檢查通過。
- 1880px 桌機及 390px 觸控模擬：原五格、textarea、數學符號共 6 組流程通過；間距、浮層邊界、答案格可見、原欄寬、一次送出的原五格封包、選取替換、刪除、上限、Esc／關閉／外側與生命週期均核對。瀏覽器無 pageerror。
- 本機使用實際第12題的安全投影及原共用 renderer，保存請求以記憶體替身驗收；沒有寫入使用者正式答案。觸控測試為 Chrome 模擬，沒有冒稱實體手機輸入法測試。
- 額外嘗試舊 `quiz-saved-work` 遷移重裝測試，被已套用快照的 baseline guard 拒絕；本次不改該 SQL 或弱化保護。這不計入前述 55 項通過數。
- 私有題目投影、瀏覽器截圖與幾何證據留在 repo 外。正式發布與回滾識別以 `agent-handoff.md` 收據為準。

## 預設完整鍵盤尺寸修正

使用者指出380px上限造成聲調與刪除鍵被截掉。改為自然內容高度，只保留實際可視視窗的最大邊界；移除固定捲軸預留空間，保留原按鍵尺寸與間距。較窄視窗將目標答案格捲到鍵盤上方時，暫用所需scroll margin，完成定位即恢復原樣，不改外層或已存答案。

本機1880×950、1280×800、390×844、320×740共12流程，逐鍵核對所有按鍵含聲調／刪除均在面板內，scrollHeight／scrollWidth沒有溢出，目標答案格與送出列不被遮住；原輸入、切換、關閉及一次送出封包通過。4項輸入回歸與21個建置產物通過。極短視窗／大幅放大仍保留可視邊界的安全退路，不宣稱任何任意縮放下皆可同時容納完整鍵盤與全部外層內容。
