# 選擇題誤呈現填空與注音鍵盤排版修正

## 問題與處理

六上國語部分單一選擇題在既有固定題庫中是 `fields`／單一文字欄，圈號選項整列被當成欄位標籤；學生因此看到填空及注音鍵盤。新增狹義呈現相容層：只接受 `kg6ch_`、題首明示選擇題、單一文字欄、完整連續圈號選項、題尾與標籤吻合且沒有圖片／表格的格式。顯示既有選項按鈕，保留圈號、原欄位 ID、`fields-v1` 答案封裝。只從題幹與選項判斷，不讀答案、不用 AI 即時猜題型。

原固定資料、題組、版本與作答紀錄保持；不重新匯入、不修改正式資料庫。活動作答畫面去掉重複選項及不適用的填空指示，整卷檢視保留原題。無法確認的格式沿原流程，不能推定所有文字欄皆為選擇題。後續來源轉換仍應直接輸出正確的選擇欄；驗收須對照原題型及實際操作，不只檢查 schema 可渲染。

真正填注音仍沿用現有輸入輔助：預設收合、完整鍵盤、不暗示正解。單欄滿寬；多欄開啟鍵盤時跨欄，鍵盤及文字輸入最大 560px，按鍵最小 44px，隨畫面自動換欄。
