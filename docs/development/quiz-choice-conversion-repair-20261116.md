# 是非與選擇題共用轉換修正（2026-11-16）

使用者回報兩類缺陷：是非按鈕把 A／B、O／X、○／×及文字疊在一起；選擇題完整內容仍在題幹，按鈕只有代號。修正採程式優先，不將整庫重新送AI。

## 實作與既有資料

- 新增 `shared/quiz-choice-conversion.mjs`，同一純函式供新題建池、批次工具與舊題相容呈現使用；依原文的大小題、完整圈號序列或共用詞庫拆分，保留每個欄位／選項ID及原答案封裝。無法定位時回傳待核原因，不猜選項。圖像隨原選項移動，未綁定行內位置的音訊留在原題幹。
- 共用是非規則支援已核對的複合標示及與純文字完全一致的原生段落；原有一般A／B、真正數字答案、圖例、圖文及額外語意不硬套是非。中文只呈現○正確／×不正確，英文T／F保留。
- 個人作答、完整回顧、錯題檢視、教師預覽與夥伴一般選擇／共同回顧／答案摘要接同一呈現規則。夥伴仍提交原零起算索引；原始題庫及既有作答不寫回、不重匯、不重新啟用，無資料庫函式、RLS、權限或媒體註冊變更。舊卷重新載入即可使用相容層。
- 新增離線 `automation/convert-choice-content.mjs`：保留原檔、輸入SHA與變更清單；`--check` 檢查尚未轉換、未知映射及不支援的輸入格式，失敗非零退出。既有通用建池也接相同轉換。SOP、製作指南及任務範本已改為程式優先，只有實質疑義才送最小必要題組給AI。
