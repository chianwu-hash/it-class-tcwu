# 選卷頁整理與主題角色選擇

日期：2026-10-28。使用者已授權依討論方案實作，先本機測試、通過後上線；新增自組卷主題與角色選擇。

## 完成內容

- 自組卷設定預設收起，按「＋我要自組卷」展開；同頁收起保留設定，切換帳號清空。刷新不自行展開，生成中防止重送或收起丟失狀態。
- 清單改為「老師準備的卷／我的自組卷／我的錯題」三個可鍵盤操作的分頁，一次只顯示目前清單，保留紫藍分區。錯題保留原本的科目、單元與分頁篩選。
- 有已開始但未完成的卷時，上方顯示「接著完成這份練習」。既有資料沒有最後作答時間，所以不宣稱這份就是最近作答的卷。
- 縮小橫幅；卡片以範圍、題數、難度和進度為主，完整卷名仍可讀，配比與刪除操作放入「試卷詳情」；補題提醒留在外面。
- 組卷後顯示已儲存成功卡，提供開始作答、查看我的自組卷、再組一份。立即刷新個人清單，不自動開始或切分頁。
- 主題／角色從伺服器既有 22 組固定配對取得。全不選：完全隨機；只選主題：該主題內隨機；指定角色：必須屬於所選主題。切換主題清掉先前角色。不能自由輸入，既有卷不改名。
- 後端驗證選擇並保存於原組卷設定，重送維持同一卷、同一名稱；更換選擇卻沿用相同請求識別時拒絕衝突。命名流水號與儲存後鎖名規則不變；延伸卷繼續隨機命名。
