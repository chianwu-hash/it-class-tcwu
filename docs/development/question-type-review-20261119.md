## 採納的意見

- 取消複選最後一項不能自動替學生選「都不選」。
- 一般模板欄也應去除多餘內距，依實際文字向右伸展。
- 連線取消須同步清待選；Esc應完整取消拖曳。
- 排序初始順序可由學生明確確認，不能靠先移再移回。
- 閱讀圖例與對話框原生關閉生命週期需要補驗。
- 鍵盤操作焦點須保留；產生樣式與快取版本須重新建置並核對。
