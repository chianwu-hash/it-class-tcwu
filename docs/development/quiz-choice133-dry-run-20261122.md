同一題可卡多項。73 題缺正式媒體登錄，其中 67 題只卡這一項，涉及 196 個不同媒體網址。9 題的答案證據缺口或衝突保留在私有例外清單。

共用規則釐清 3 題的紙本勾選框，另以候選檔案 SHA 和完整像素對帳 14 題的選項圖片。沿用已有逐欄證據的多欄選答、比較、是非及符號題。3 題純文字最重／最輕題依原選項順序建立新候選，以教師鍵、固定複核及換算交叉核對，均通過 dry-run。

總帳及清冊更新至 v32。35 題列待正式 OAuth，現有 221 題上線。本次只有正式庫唯讀核對，候選、逐題診斷、隔離讀回及例外清單均存於私有工作目錄。
