## 答對與答錯的動畫及鼓勵語（2026-10-25）

使用者要求兩種結果皆有動畫與阿德勒鼓勵語，已先在本機共用答題模組試作。沿用角落的紫色小角色，用原生SVG與CSS，不新增外部素材請求或生成圖片。

|---|---|---|

鼓勵語依題目位置在每種結果5句間輪替，回看同題維持相同句子；不以學生分數、速度或連錯推論能力、努力及實際解題方法。不用聰明／笨、勝負比較、責備、不實進步宣稱或保證下次答對。參考[Positive Discipline的鼓勵與稱讚區分](https://www.positivediscipline.com/articles/encouragement-what-does-it-mean-and-how-it-done/)中自我評估與鼓勵行動的方向；這些中文句子是本產品原創，不是阿德勒原文或名言。

動畫只在當題送答成功且後端允許揭答時播放一次，與文字及書商解析同步出現，不遮擋題目、不自動跳題、不播聲音。重整、回看和整卷檢視顯示靜態角色與鼓勵語；未達揭答條件不透過動畫或句子洩漏對錯。尊重 `prefers-reduced-motion`，減少動態時停用所有新增動畫，保留對錯文字及完整解析。書商解析內容未改寫。

採納的研究意見：現有頁首與重複進度占空間、選項短內容卻長直排、答錯解析綠底語意不清，以及下一題與次要動作的視覺層級不足。

沒有直接採用的建議：圖片不縮到原始像素以下不是通則，因為本案向量轉圖可能已放大3倍，應依圖中字的實際可讀性與比例判斷；解析固定65vh且獨立捲動也不是定案，須再比較整頁展開與側欄的兒童操作負擔。1366×768的螢幕不代表固定650px可用視窗，故直接以1366×650與768的CSS視窗驗證，不把工具列高度當普遍事實。

## 推薦方向（尚未經使用者定案）

- 精簡頂列約48～64px，合併重複題號與進度，讓題幹及附圖取得主要空間。滿版指善用可用視窗，不等同禁止捲動或強制進入FullScreen API。
- 桌機短答案優先2×2；長題附圖可左右分配，長中文選項與窄手機改一欄。文字不得為了塞一屏而縮小或省略。
- 初步採淺色背景、白色閱讀面、藍／琥珀／紫／粉選項；深色文字、A-D標號、明確選中框。可比較深色方案，但不直接複製競賽畫面。
- 可愛來自小角色、圓角與少量色彩；作答期間不持續跳動，尊重減少動態效果設定。不自行新增排行、速度計分、金幣或連勝規則。
- 保留「選擇可改選→送出→當題回饋→手動下一題」。答錯用暖橘或中性提示，並以文字／符號標示你的答案與正解，完整保留書商解析與圖表。最後一題先停留回饋。
- 真正改版時仍只照後端固定順序顯示選項，不能前端再洗牌；維持既有驗權、短效圖片網址、失敗回復與作答接回。

字級與尺寸是本案試作建議，不是已驗證的兒童成效標準；主要選項可取72～104px高度、桌機題幹約28～36px，再用真實長題／公式／圖表與縮放調整。[W3C 2.5.5的44×44 CSS px](https://www.w3.org/WAI/WCAG22/Understanding/target-size-enhanced)是AAA增強目標大小要求且有例外，不能說所有AA介面都一律要求44px。未採用UI/UX技能資料庫中未附實證的參與率百分比。

使用者已確認的是研究目標；上述配色、布局、角色和回饋面板仍是提案，未授權正式改版或部署。
