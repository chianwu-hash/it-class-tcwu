# 畫筆顏色與整筆橡皮擦

六種固定筆色（深綠、藍、紅、紫、橘、黑），文字、色點與選取框辨識；橡皮擦掃過筆畫刪除整筆，可復原。復原保留20步（包含畫筆、擦除、清空），不以白色遮蓋。收筆前不觸發會改動畫板高度的外層狀態更新，避免落筆座標跳動。

格式沿用drawing_v1 / version1與原strokes，僅增加可選colors陣列，長度必須等於筆畫數且限六個色碼。沒有colors的既有附件保留預設深綠及原雜湊，不補欄位重新計算舊附件。前端與Edge驗證器一致；canonical僅於輸入存在colors時保留。SQL既有服務端finalize可保存此JSON，沒有SQL／schema／資料權限變更。
