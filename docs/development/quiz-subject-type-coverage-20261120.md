3. 跨科圖文閱讀、圖表及混合題組：材料與小題同時可見，手機可返回材料。

## 仍須討論／不得誤判為已完成

- 數學原圖著色、畫線、量測與作圖：空白畫布不等於原題適配；必須有原底圖、位置及保存證據。
- 聽力題不能用文字轉錄取代原音檔，也不能把檔案下載成功當成播放操作已通過。
- 圖文閱讀排除規則造成部分多媒體題組無法並排；須確認完整材料、小題與控制項後逐項開放。
- 單一數位作答格式可對應多種書商題型；共用元件通過不等於每一原始題型已驗收。

## 本輪改善與驗收結果

- 後續八種介面各一題代表已由使用者試用接受，第7種維持描點／連線版。屬本機隔離試用；專用新介面尚待正式來源與各入口接線，不改下列正式覆蓋數，也不將八種視為全題庫完整涵蓋。規則見[長線SOP](quiz-conversion-operations-sop.md#本輪題型試用定案與長線接續2026-11-20)。
- 圖文閱讀：只對已有完整、精確來源投影的題組開放原材料與原作答控制項並排；70 筆新增支援（66 可用、4 保留），不改來源或答案。239 筆可識別閱讀題組中 238 使用閱讀介面，1 筆保留原連線操作。
- 手機沿用同一份文章 DOM，開啟材料、返回小題後保留輸入、焦點與捲動；計算過程與連線板仍依自己的完整操作契約呈現。
- 算式按鍵：鍵盤 Enter 可連續輸入，觸控後回輸入欄；刪除完整字元，不切斷代理對。沿原一次送答，不加自評流程。
- 聽力：原生音檔控制、重播、播放另一段時停止前段；情境銷毀後停止舊音檔。個人／考古卷／夥伴共用播放綁定，未改媒體授權。
- 一般題庫 272 個來源代表案例 × 4 寬度＝1,088 介面檢查；考古卷 83 個來源代表案例（涵蓋80組契約）×4＝332 檢查，均無整頁橫向溢出。使用原始私有媒體；圖片與音檔比對 SHA，沒有以替代圖列為原圖驗收。
- 一般題庫 438 筆含音檔紀錄（246可用）共282個不同音檔，全部以瀏覽器原生解碼；這不是逐段真人聽辨或逐題內容語意重審。
- 當前正式函式快照的獨立 PGlite：42 個啟用考古卷文件驗證、8 個作答契約的保存／同請求重試／接回／未揭答／跨人拒絕通過。一般算式／直式64候選重新通過原生保存；仍為19算式、45直式，不把候選當正式啟用。
- `npm run quiz:test` 11項、84項相關格式／保存／權限／介面單元測試、21個產物檢查通過；520個私有媒體檔SHA相符。測試組合有重疊，不相加成獨立題數。4個歷史測試檔未列本輪通過：2個缺歷史私有候選檔，2個以舊遷移搭配目前新格式fixture不相容；以當前快照42版本／8契約另驗，沒有改正式SQL迎合舊fixture。
- 本輪不讀取真人作答、不改名冊、不寫正式學生資料、不變更函式／RLS或媒體權限；瀏覽器採合成身分及本機隔離請求，未冒稱真人OAuth全鏈驗收。

## 重現清冊

`automation/audit-subject-type-coverage.mjs` 接收私有 `--pool`、`--courses`、`--source-types`、選用 `--past`／`--past-papers`，以 `--out` 指定聚合JSON。逐筆ID只用來對回，不輸出題文、答案、媒體URL或來源路徑；複合出版標籤不重複計題。原始資料與來源metadata的SHA留在本機私有證據。`automation/tests/quiz-subject-adaptations-browser.cjs` 可在登記租約的隔離fixture執行合成算式／原生音訊回歸，禁止拿正式頁面作送答測試。
