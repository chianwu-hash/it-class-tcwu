# 批次執行器與三年級數學 9 筆試跑

新增可續跑的批次執行器，將既有私有操作腳本接成固定階段。每階段核對輸入／輸出 SHA 與收據，已完成且證據一致才跳過。排他鎖防同批並行；失敗先讀回，再透過綁定階段、輸入與證據的恢復收據繼續。原失敗狀態保留於歷程。

本輪從既有 56 筆精確候選中選取 9 筆數值與單位題，原鍵與來源檔逐檔重核，保留既有 28 個欄位、答案可接受值與成組判分。以老師練習卷提供，完整題目與欄位皆沿用已核候選。

| 檢查 | 結果 |
| --- | --- |
| 隔離等值讀回 | 9 筆、28 作答位置、37 組全對與逐欄答錯情境通過。 |
| 題圖 | 14 張，SHA 對帳沿用 7 個 Drive 檔案及 Worker 索引，新增 7 個。 |
| 供圖與登錄 | 14 張供圖 SHA、MIME、大小一致，新增 14 筆私有媒體登錄，讀回全過。 |
| 課本 | 9 題逐題核對原頁及正式對照，共 7 張印刷頁。 |
| 正式 OAuth | 9 筆按 5% 抽 1 題，票價表題於桌機與手機開第 135 頁、翻至 136 頁、回本題頁與原題後兩欄作答仍保留。送出判分及重載讀回通過。 |
| 正式讀回 | 上線後 9 題內容、答案、原欄位、教材對照一致，正式練習庫可開卷。 |
| 續跑 | 已完成階段經雜湊與收據核對後跳過。Worker 寫入後回應讀回失敗，唯讀核實已完成後採認，保留恢復紀錄。 |
| 總帳 v59 | 708 筆列管來源已上線 400 筆，剩 308 筆。 |

兩項自動測試涵蓋正常續跑、輸入變動、收據變動、同批鎖、失敗阻擋和依讀回收據恢復。執行器首版負責共用調度與證據檢查，來源轉換、媒體及 SQL 的實際操作仍由清單宣告的既有腳本執行。試跑沒有足夠的同條件前後樣本可推估加速倍數。
