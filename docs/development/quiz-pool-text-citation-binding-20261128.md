# 自己組卷的已核文字引用繫結候選

## 問題與候選行為

九年級二段的教師卷已能準備「自寫解析＋已核教材名稱、章節、頁碼」文字學習包。自己組卷使用的 `quiz_pool_study_sources` 原約束卻只接受教材原頁連結，或明確的 `no_reliable_match`。已找到可靠教材的文字引用不能為了通過約束而偽裝成無可靠對照。

本候選讓新自組卷精確綁定已核文字引用，維持答後揭答。新增純資料形狀檢查 helper，擴充原 CHECK，並在既有組卷繫結函式補來源版本、課程年級、學年度及科目比對。原頁連結及明確無可靠對照的分支保留；不修改題池題目、原教師鍵、既有版本或作答，不上傳或註冊教冊原頁。

分支 `codex/g9-text-citation-binding-20261128` 從 2026-11-28 最新 `origin/main` 的 `9f4503f6` 建立獨立 worktree。這是候選 PR，尚未合併、套用正式資料庫、發布或做正式 OAuth。本案對函式變更的既有明示核准關卡仍保留；沒有以 repo 的新版可復原原則假定已取得本案核准。

## 文字引用資料契約

無原頁連結時，`book_id`、`primary_page` 為空，`reference_pages` 為空陣列，另使用以下明確狀態：

- `verified_text_citation_direct`：教材直接支持。
- `verified_text_citation_related`：相關觀念支持，另留推導理由。

`teacher_notes.text_citation` 固定保存 schema、課程 ID、年級、學年度、學期、教材標題、出版社、科目、來源版本與完整題目 SHA。`references` 為 1～20 筆，每筆含教材角色、PDF SHA、PDF 頁、教冊／課本印刷頁及章節。PDF頁必須是1～9999的JSON正整數；印刷頁可為同範圍的JSON正整數，或如`75-5`、`75-20`的補充頁字串。補充標籤限定ASCII數字、單一半形連字號，前段1～9999、後段1～999，兩段均無前導零；不接受純數字字串、空白、換行、額外符號或巢狀物件。文字不得空白，SHA 必須為 64 位小寫十六進位。完整題目 SHA 採 PostgreSQL `question::text` 的 UTF-8 SHA-256，不混用 JavaScript 另行排序序列化的指紋。

來源版本同時留在 `provenance.source_version`，且 `provenance.reviewed` 必須為布林 `true`。這只是資料輸入閘，不能代替逐題原件、教師鍵、教材原頁及 SHA 的實際核對。helper 不讀檔案、不接外部服務、不呼叫 AI，也不授權前端存取教師筆記。

新組卷仍須通過原有完整 JSONB 相等、可用題池、課程成員、課程啟用及教材連結檢查。文字引用分支另外要求：

1. 引用完整題目 SHA 與來源完整 JSONB 相符。
2. 引用來源版本與當前題池 `source_version` 相同。
3. 引用課程 ID 與來源課程相同，年級、學年度及科目與課程目錄相符。

學生只取得現有答後機制揭露的固定解析文字，不取得 `teacher_notes`、來源指紋或尚未揭答的解析。既有包與作答的固定繫結邏輯不變；啟用新來源不會補綁先前沒有學習包的自組卷。

## 交易與回復

兩份 SQL 均固定 LF；`.gitattributes` 避免 Windows checkout 改變函式指紋。安裝／回復先鎖定來源表，並核組卷函式、CHECK 與新增 helper 的完整指紋；未知並行修改拒絕執行。只允許已知舊版或本候選版，重裝與重複回復可用。回復完成前再核原繫結函式、原CHECK及helper已移除；任一不符即拋錯，整筆交易不提交。隔離測試刻意省略helper移除，確認回復後守衛會拒絕且交易回到候選版。

## 隔離驗證

執行 `node --test automation/tests/quiz-pool-study-text-citation.test.mjs`，3 個含多情境的測試案例通過。使用 repo 正式 schema／函式快照建立隔離 PGlite，只有合成身分、題目與教材，沒有讀取正式作答或登入帳號。

| 案例 | 已驗範圍 |
| --- | --- |
| 形狀、交易及並行守衛 | 17 組原有無效 metadata／複核資訊與20組新增頁碼形狀拒絕、5 種畸形 JSON 不通過；4組合法補充標籤完整保存並驗來源存在時拒絕回復；整份安裝交易回滾、重裝、重複回復、新引用存在時拒絕直接回復、未知 helper 修改拒絕安裝與回復 |
| 自組卷 RPC 與固定包 | 三／四／六／九年級的實際 `quiz_compose`、加入、送答及接回；重試不重建、答前不漏解析或教師筆記、答後揭露、跨使用者拒絕、舊固定包保持、先前未綁卷不補綁；版本、年級、學年度、科目、完整題目不符時不綁 |
| 原分支回歸 | 混合 3 筆原頁連結、2 筆明確無可靠對照，5 題照正式順序送答；原教材頁、引用與解析仍可讀，未以新 metadata 要求阻斷原頁來源 |

匿名及 authenticated 角色不能直接讀來源表或執行新增 helper；來源與已固定資料不可變守衛保留。這些是隔離資料庫及 RPC 證據，不是正式 OAuth、實際媒體 HTTP 或桌手機畫面驗收。

另以 Windows 原生 PostgreSQL 17.12 重跑相同 3 個案例，全部通過，包含整份安裝交易回滾、精確指紋、重裝、回復及新來源存在時拒絕直接回復。每案建立獨立暫存資料庫，沿用同一份正式 schema／函式快照與合成 auth 邊界，只將 PGlite 換成原生連線，測試斷言及兩份候選 SQL 不變；每案結束刪除自己的暫存庫，驗證後已停止本機服務。這仍不驗證外部 OAuth 邊界。

原生執行檔由 [PostgreSQL 官方 Windows 頁](https://www.postgresql.org/download/windows/)所指的 [EDB binaries](https://www.enterprisedb.com/download-postgresql-binaries)取得，以同頁連結的 SHA-256 核對封存檔：`520c8c6f19abb3b31fa83ec5e486e2f769eedd7593d94e60a7cda8a5bfb4df91`。本機只監聽 `127.0.0.1`，採密碼認證；執行檔、測試接頭與日誌留在 repo 外。初版只接受數字頁碼的原生收據 SHA-256 為 `21ca579fc6cf65e28388166941b376d603bcba93f9d0e8e2b0f81c814191c833`，其歷史測試日誌 SHA-256 為 `37436afe12e352ebfc5ea7db4c054b02ae7c75eee685d51863324165655ef133`；不拿初版收據替代下述新版證據。

## 補充頁標籤驗證

逐題教材核對遇到真實教師補充頁標籤，初版候選只接受正整數，會拒絕已有可靠對照的來源。新版按原標籤保存，不將75-5壓成755，不改填其他頁或無可靠對照。PDF頁與印刷頁仍分別記錄；接受標籤形狀不等於證實該頁存在，仍須逐題核原件與SHA。

新版3個多情境案例在PGlite及原生PostgreSQL17.12均通過，含4種合法標籤、20種無效頁碼形狀拒絕、實際九年級自組卷的混合補充標籤、固定教師筆記完整保存、答前不洩漏、答後揭露、既有作答不補綁及精確回復。繫結函式與CHECK指紋未改，helper及兩份SQL指紋已更新；安裝只接受原正式快照或本新版，不默認可由未套用的初版候選直接升級。若隔離庫仍留初版，先保持拒絕並唯讀盤點實際指紋／來源，再另備精確遷移或資料回復；不能跳過守衛、重設指紋或直接刪除來源。

先前被擋的一包9筆私有停用來源，原題、來源版本、候選包SHA及原頁標籤不變，以新版候選逐筆完整讀回相符，整批交易回滾後回復舊schema通過。另使用該包實際組卷、加入及逐題送答9題，教師筆記與原標籤精確保留，答前不漏解析、答後解析逐題相符；先前未綁卷仍未補綁。測試只備9個可用來源，依既有不足題量行為請求10題實際產出9題，不冒稱產出10個真題。這只是該包與新版候選的隔離演練，沒有新增已核題數，不能擴大成整庫或正式四入口完成。私有來源不進本PR；本機暫存庫已清除、服務已停止。

新版原生及該包演練收據SHA-256：`f6c50132e4dce95b5cd9188c6a03027d50412cd06c18f1a1c07095e010791641`。依SOP經`chat-mode`只讀複核4份候選檔，未見本次窄範圍阻擋；Codex採納回復後自驗及格式邊界建議後重跑最終測試，Claude未親自跑資料庫或讀私有題目。正式函式核准、main流程、資料啟停／移除方案、正式讀回及OAuth均仍待完成。
