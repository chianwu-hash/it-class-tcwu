# 考前練功房僅限學生

日期：2026-10-28。使用者明確要求非學生帳號一律鎖住，題庫不可公開。此決策取代先前「教師可從練功房試答」的安排。

## 變更

- 僅115學年度三／六年級名冊中的已驗證學生帳號可開啟選卷清單。確認資格前保持鎖定；教師、未列名冊、未登入皆不顯示自組卷、清單或錯題。
- 後端 `quiz_action` 拒絕教師呼叫 `library_sessions/join/resume/submit/view_question`，包括既有教師 personal 試答連結，不靠隱藏按鈕判斷權限。原有非學生名冊檢查、學生年級與本人卷隔離保留。
- `quiz_pool_catalog` 與 `quiz_wrong_questions` 經上述身分入口同步拒絕教師；組卷原本就拒絕教師。學生進度與答案繼續儲存在 Supabase。
- 教師題庫編輯、版本管理、開場與監看等獨立後台權限保留；管理後台能讀取本人題庫不等於公開練功房。教師努力樹的測驗葉片 adapter 回傳空集合，避免新限制影響其他教師努力樹功能。
- 說明文字明確標示僅限學生。先前的轉圈原因為停用按鈕一律套 `cursor:wait`；組卷按鈕改用 aria-busy 區分載入／生成與不可用，但非學生現已看不到這顆按鈕。

## 驗證

- 19項真實SQL與資料測試通過，包含教師題庫管理仍可操作、教師本人及他人不可藉舊 personal 連結作答、未列名冊拒絕、匿名權限拒絕，以及學生選卷／送答／接續／錯題／組卷／命名／刪除維持正常。
- 本機瀏覽器模擬 API 拒絕教師、未列名冊與未登入三種狀態，均只顯示鎖定卡，隱藏選卷內容、沒有試卷卡；恢復合成學生後可讀取並開啟自組卷設定。
