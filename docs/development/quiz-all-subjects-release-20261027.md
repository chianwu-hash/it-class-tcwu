## 努力樹與防快速灌葉

- 後端私人ledger記錄獎勵，活動接回既有 `my-tree.html`／shared reward model，不寫入student_progress冒充週次活動。
- 以實際完成題數為準：不足10題不計葉，10／15／20題完成且正確率至少60%計1葉；20題亦只1葉。沒有完整閱讀時間紀錄的既有作答不追溯計葉。
- 每attempt最多1葉；相同題目內容集合即使重組、換順序或改名也不再領葉。使用者可繼續複習；沒有自行新增每日上限。
- 閱讀起點及接受作答時間由後端記錄，不能用前端傳秒數。初步保守下限2秒；太快送答不保存答案，跳出「請看清題目和選項再作答」，等待後可重新選擇／送出。秒數是快速亂點防護，不宣稱可完整判定作弊或學生能力。
- 只有伺服器新發葉時播放慶祝；重送、重整及回看不重播。慶祝保留當題正誤及解析，不跳過末題回饋，支援減少動態偏好。
