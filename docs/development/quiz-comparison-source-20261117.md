# 三上數學比較符號題：程式候選與驗收

9 個父來源、23 個原複核目標、30 個答案位置，原件包括公斤／公克與分數比較。NAS 原件副本的 27 個檔案 SHA／大小重新核對；原教師鍵、固定 Notebook／AGY 複核及獨立有理數計算完全一致，沒有新增 AI 呼叫。

## 程式規則

`automation/lib/quiz_comparison_source.py` 僅接受完整、依序編號、文字及版面一致的比較式。原教師鍵也須完整依序，逐位置與固定複核、`Fraction` 獨立計算相符。公斤先換公克；分數精確比較，不用浮點近似。圖像、未知單位／版面／指示、零分母、不同量綱、不完整或錯序位置都拒絕推測。來源有列式／直式等要求者，由來源要求關卡先隔離。

這批每個父題確實有多個比較式，採 `fields`、每式 `input:single`，三個穩定選項 ID 為 `lt`／`eq`／`gt`；保留原外層一次送出。單一比較式不適用此多欄產生器，不因書商類別一律套成 fields。教師數字標記只用於核位置，學生選項只顯示比較符號。

原件完整留存；學生內容把空格編號，分數保留 KaTeX。每個比較式透過既有 `numbered` 呈現規則緊接自己的選項，不把六個比較式全放上方、六組選項全放下方。`shared/quiz-comparison-reviewed-sources.mjs` 只登記本批題目 ID、內容指紋、原件 SHA 與一對一位置；共用回顧表匯入此表，沒有改外層、CSS、判分或既有作答。指紋不符便不套用此計畫。
