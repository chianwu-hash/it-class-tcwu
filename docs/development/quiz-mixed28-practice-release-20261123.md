# 三年級混合複選題 7 組上線與課本對照驗收

2026-11-23 正式練習卷「三年級數學：複選與生活應用」保留 7 組共用材料、20 小題原順序及獨立判分，其中 8 小題為複選。選項按原卷順序顯示。

| 檢查 | 結果 |
| --- | --- |
| 28 筆來源篩選 | 優先處理原卷明列選項、教師鍵可逐項對應的題組。7 筆上線，21 筆保留分流。 |
| Dry-run 與等值讀回 | 23 個作答位置、38 組情境，含複選漏選、多選及勾選順序不影響評分。 |
| 題圖 SHA 與登錄 | 6 張查無可沿用檔案；補齊私有 Drive、Worker 索引及正式媒體登錄。6 張供圖的 SHA、MIME、大小與登錄讀回一致。 |
| 課本必經關卡 | 逐題核對 20 筆課本原頁與正式對照，使用 7 張翰林三年級上學期印刷頁。 |
| 正式 OAuth 抽驗 | 7 筆按 5% 進位抽 1 題。課表複選題在桌機與手機皆可開第 133 頁、翻到第 134 頁、返回原題並保留三項勾選。送出判分與重載讀回通過。 |
| 上線後逐題讀回 | 正式練習庫可找到卷；20 小題的原序、題幹、答案、共用材料和課本對照一致。 |
| 總帳 v58 | 累計已上線原始題目來源由 384 增為 391 筆，101 筆混合題仍在分流。 |

尚待處理的 21 筆複選或多值答案分為表格推導選項 6 筆、逐式整除勾記 6 筆、圖表或代號位置 5 筆、多個可能值或圖選項 2 筆、圖中單選選項待對應 1 筆，以及原卷有 10 選項而現行上限為 8 的 1 筆。
