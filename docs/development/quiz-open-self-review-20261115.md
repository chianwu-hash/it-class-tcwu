# 一般題庫開放作答與自評（正式 SQL 已套用，前端待發布）

六年級國語尚有造詞、造句、接寫與閱讀問答等378個開放來源。使用者指定保留原本開放作答，不改選答，也不以單一參考答案自動判分。本次為既有一般題庫增加 opt-in `open` 題型，既有單選、簡答及多欄自動判分保持原契約。

學生流程：本人登入後，依原題各個作答位置輸入文字；整組儲存成功才提供參考例答與檢核重點；學生主動選擇「符合重點」或「還想再練習」並可留下想法。自評兩種結果都保留，不換算為自動對錯或成績。重整接回本人答案與自評；換人或登出清除當頁狀態。未完成自評仍列待完成，不能靠空白送答或只開參考跳過。

功能契約：沿用 `quiz-server.mjs`、`quiz-document.mjs`、題庫 RPC、既有登入與 workspace；不另做登入、導航或 localStorage 進度。原始題目、全體目標及參考版本固定，未授權前不把例答送到學生端。新開放作答紀錄與自動正誤分開儲存，避免被當錯題或污染原自動判分統計。自評不代表教師評分；本次先交付自評流程。

必要驗收包含：未登入／未列名冊／跨帳號／教師錯用學生入口拒絕；先答後看、全欄非空、字數及未知欄位拒絕；相同 request_id 重送與遺失回應接回；自評前不完成、兩種自評均完成；原一般判分、固定版本、組卷、揭答時機、媒體授權與既有作答保持；桌面及手機可操作、無橫向溢出。只採合成測試資料。

本機驗證：新增自評 SQL 整合測試10項、既有完整父題／精簡回應8項，以及題序快照3項均通過。原題序測試未安裝現行 study wrapper 與 class helper，先以未改題目模組重現，再只補齊測試 scaffold；保留拿掉 ORDER BY 必須失敗的對照組。新增自評測試另用真實本機函式核對5個完整父題組卷、教材授權、強制 hash join 下依序保存與自評，不用 scaffold 的 study stub 代表整合測試。

1280／390瀏覽器實際操作28項通過，包含未送答不揭參考、空白拒絕、保存後參考、想法跨狀態更新保留、自評已寫入但503回應遺失、同 request_id 重送、重整登入接回、原自動判分接續、登出清除，以及教師預覽參考與檢核重點。已目視桌機手機截圖；合成測試不代表真人 OAuth 驗收，測試分頁與本機伺服器已關閉。`quiz:build`／`quiz:check`通過。

資料庫套用範圍：新增受 RLS／ACL 保護的 `quiz_open_responses` 與3個內部 helper，保護式更新11個既有函式，維持既有 learning／study 包裝層。SQL 先核對全部原函式 MD5，拒絕未知版本、部分安裝及未核定的歷史 open 型別；同一候選可冪等重套。原固定題目、學生作答、自動對錯與既有獎勵不重寫。開放自評不計自動正確率，也不產生新的延伸葉學習積分；原自動題獎勵規則保持。

公開程式與 SQL 不含書商原題、課本、學生資料、雲端憑證或私有模型輸出。內容378來源與新字框媒體仍需獨立完成全科驗收，不因功能測試通過就宣稱國語已全數上線。
