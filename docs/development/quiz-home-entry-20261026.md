## 實作契約

- 頁型：三、六年級 115-1 首頁工具入口及題組選卷／作答頁；不新增週次或改週卡可見性。
- 視覺：沿用各年級首頁白底圓角、彩色圖示與邊框；卡片放在課程進度上方，導覽列使用既有年級 navbar。
- 三上入口 `/grade3/115-1/quiz-library.html`，六上入口 `/grade6/115-1/quiz-library.html`；各有同層 `quiz.html`，共用呈現與 API。
- 登入：既有 `initNavbarAuth` 與集中 Google 登入，登入後返回原頁；不重寫 Auth，不以 localStorage 保存進度。
- 學生：後端名冊提供年級，只看本人年級試卷，年級選單隱藏；誤入另一年級入口時自動導回本人年級。直接呼叫另一年級場次仍由後端拒絕。
- 教師：保留自己的試答場次，可切換三／六年級頁面。
- 保存：既有 `quiz_attempts`／`quiz_answers`、固定版本、穩定選項亂序、私有媒體揭答、末題回饋；不接努力樹或改 `student_progress`。
- 驗證：兩年級首頁卡片／navbar、匿名鎖定／集中登入返回、學生名冊分流／誤入、教師切換、手機 390px、原進度接回、跨年級拒絕及正式站媒體 CORS。
- 發布：以目前正式 Git 基準隔離產生部署，僅加入必要程式與資產；不發布題庫原始檔、SQL、憑證、測試輸出或不相關工作區變更。發布資訊與最終驗證於完成後補記。
