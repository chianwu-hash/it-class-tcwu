# 題目出錯回報移至題目右上角

一般答題與個人考古卷原本在選項下方顯示整個回報區，即使表單收合仍占一個大框。現在沿用原回報元件，只把按鈕移至題號／計算紙標題列右側，表單仍在題目下方，收合時連外框一起隱藏。

共用 `mountQuestionReport(host,box)` 以WeakMap保存同一表單與按鈕，重繪時重新掛到該題新標題列；不重建輸入內容、待重試請求或已送出狀態。一般題、考古完整題組與整份回顧皆保留一題一入口。無標題列及既有錯題詳情的內嵌用法維持。

手機一般題沿用同列，回報按鈕至少44px高；考古卷長標題先占一列，避免被計算紙、分數與回報按鈕擠成多行窄欄。點開表單後沿用原焦點、類型／選項及文字說明操作。

驗證：

- 102項1280／390／360原答題入口合成操作通過，含一般／考古、右側幾何位置、收合無空框、計算紙保留、展開焦點、收合及答案送出重繪保留內容、失敗重試同一request_id、原題與模式綁定、成功不重送、登出與換人清除。
- 整份回顧的逐題入口、未送回報草稿與唯一表單ID，以及無標題列的內嵌用法通過；桌機與兩種手機寬度截圖已檢視。
- 10項教材／建置回歸及1項既有真SQL回報測試通過：本人、固定版本選項、權限、限流、重試、教師處理及媒體隔離。21產物及95正式任務目錄、排除來源0前檢通過。
- 瀏覽器使用合成身分與回報API，沒有送出正式回報或學生答案；不聲稱真人OAuth端到端測試。SQL測試為本機PGlite合成資料，不接正式資料庫。

只改DOM掛載、樣式及版本產物；原回報請求、驗證、後台與資料表不改。沒有SQL、RLS、Worker、教材、題庫或學生紀錄變更。沿用既有驗證後上線流程，PR進main、乾淨main發布及正式回讀，收據另補。
