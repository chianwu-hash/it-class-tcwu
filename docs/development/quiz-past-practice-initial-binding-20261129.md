# 九年級社會首次補配題：登錄契約候選

**只完成隔離證據，尚未登錄正式配題。** 本案先核對首次補齊與既有配題改版的界線，不修改主要SOP、資料庫函式或原卷內容。

## 原卷不可重複建同內容版本

正式`quiz_past_versions`有`UNIQUE (paper_id, sha256)`。隔離PostgreSQL已確認，同卷相同內容即使換UUID也被拒絕。因此，先前[配題候選紀錄](zhongzheng-g9-social-practice-candidates115-20261128.md)「新配題隨新固定來源版本」的計畫不能直接用相同原卷複製實作；也不應為產生新SHA而任意改題。

## 待核對的首次補齊方案

現行`quiz_learning_topics`把原卷來源版本與重點連到獨立的不可變普通練習版本。候選方案只在該來源／重點**尚無任何既有配題**時新增固定版本及連線，並保留原卷、學習圖、舊作答與夥伴副本。已有連線者拒絕本流程，改版須另依製作手冊處理；不能用`ON CONFLICT UPDATE`替換舊練習。

隔離交易已驗證：

- 新練習的題目ID沒有一般題池成員資料，仍可由原生`quiz_learning start`開兩題固定練習；一般題池沒有新增資料。
- 原卷原有錯題可從尚無練習變為有兩題練習；相同request ID只回同一場次，同班其他使用者不能開本人的來源或加入這份個人練習。
- 一正一誤送答與同ID重試保持兩筆作答，答前不洩漏答案；原卷版本、SHA、原答案資料列及學習圖均保持。
- 回復只移除本次新增連線，原錯題恢復無練習；已產生的練習版本、場次與答案仍可由本人重開，未刪除歷史資料。

這是技術證據，尚不是正式發布決定。[製作手冊](past-exam-playbook.md)要求改版不得將新解析／配題默默套至舊作答，仍須核對本次「原先沒有連線的首次補齊」如何符合該要求，並在正式計畫中明列影響與回復。

## 固定覆蓋紀錄與目前開放狀態

原生證據顯示，新增連線後，`quiz_learning_review`的`practice.available/count`依正式連線回傳true／2；固定學習圖的`practiceCoverage.available`仍為原本0，原未開放原因也仍在API資料中。現有renderer在available為true時顯示兩題按鈕，未顯示該未開放原因；不能把技術上能啟動誇稱為已完成全部資料語意核對。

正式登錄前須確認：以何欄位作目前開放狀態的依據、哪些欄位保留原固定製作紀錄、是否需要其他修正及相應授權。未釐清前不修改正式學習圖或新增連線。

## 候選來源進度與驗證邊界

私有候選現有29份兩題練習、39道不同書商原題，含一份明列前後SHA的私有候選修訂；先前25份固定包保留。新增四份及修訂一份均通過原生文件驗證，其餘24份文稿保持。從已核SHA的115上康軒原光碟取出222份現行目錄原題供篩選，不將取件數列成已轉化或已上線數；也不擴大一般教師題池轉化範圍。原件、答案、教冊與私有輸出不上公開repo。

上述首次連線、權限、存答與回復均只在隔離PostgreSQL；正式OAuth、教材開頁返回、正式資料全量讀回、同PR收據及正式配題啟用仍待完成。PR #636 SQL及夥伴第二身分另依既有待辦處理。
