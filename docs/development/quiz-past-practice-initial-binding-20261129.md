# 九年級社會首次補配題：登錄契約與驗證界線

**只完成隔離證據，尚未登錄正式配題。** 本案先核對首次補齊與既有配題改版的界線，不修改主要SOP、資料庫函式或原卷內容。

## 原卷不可重複建同內容版本

正式`quiz_past_versions`有`UNIQUE (paper_id, sha256)`。隔離PostgreSQL已確認，同卷相同內容即使換UUID也被拒絕。因此，先前[配題候選紀錄](zhongzheng-g9-social-practice-candidates115-20261128.md)「新配題隨新固定來源版本」的計畫不能直接用相同原卷複製實作；也不應為產生新SHA而任意改題。

## 首次補齊與改版的區別

現行`quiz_learning_topics`把原卷來源版本與重點連到獨立的不可變普通練習版本。候選方案只在該來源／重點**尚無任何既有配題**時新增固定版本及連線，並保留原卷、學習圖、舊作答與夥伴副本。已有連線者拒絕本流程，改版須另依製作手冊處理；不能用`ON CONFLICT UPDATE`替換舊練習。

隔離交易已驗證：

- 新練習的題目ID沒有一般題池成員資料，仍可由原生`quiz_learning start`開兩題固定練習；一般題池沒有新增資料。
- 原卷原有錯題可從尚無練習變為有兩題練習；相同request ID只回同一場次，同班其他使用者不能開本人的來源或加入這份個人練習。
- 一正一誤送答與同ID重試保持兩筆作答，答前不洩漏答案；原卷版本、SHA、原答案資料列及學習圖均保持。
- 回復只移除本次新增連線，原錯題恢復無練習；已產生的練習版本、場次與答案仍可由本人重開，未刪除歷史資料。

依[製作手冊](past-exam-playbook.md)第1節與第6節的原則，本次僅首次補齊沒有任何連線的重點：不替換舊練習，不改原題、答案、解析、教材範圍、原學習圖或舊作答。這與書商來源或內容改版須另固定版本不同。上述界線經現有schema、函式與SOP的聚焦唯讀複核，再由Codex核對實際map及補驗；不能為製造新SHA而改原題，也不能把本流程延用為既有連線的換版捷徑。

影響範圍須在啟用收據明列：該來源版本既有已作答者的對應錯題，以及已完成原卷者的主動練習清單，將可開新固定練習；來源原本未完成者仍可保存、續答，主動練習仍須完成整卷。夥伴副本保留，本次連線並不直接授權夥伴副本或替代多人入口驗收。

## 固定覆蓋紀錄與目前開放狀態

原生證據顯示，新增連線後，`quiz_learning_review`的`practice.available/count`依正式連線回傳true／2；固定學習圖的`practiceCoverage.available`仍為原本0，原未開放原因也仍在API資料中。現有renderer在available為true時顯示兩題按鈕，未顯示該未開放原因；不能把技術上能啟動誇稱為已完成全部資料語意核對。

本批以`practice.available/count`及topic連線作目前開放狀態依據，coverage與原未開放原因保留為原map固定時的製作紀錄。已核113／114兩份實際map共57個重點，沒有非空的`practiceCoverage.studentLabel`；目前兩個學生renderer不會因此同時顯示舊未開放標籤。不能把API裡保留的coverage 0當成目前可練習數，也不就地改map或函式。本批以外若新增消費端直接讀該欄位，須另核其語意。

## 登錄與回復的硬性條件

- 逐一核原卷active版本、文件SHA及map雜湊；每個concept須確實存在map，並記錄可由錯題進入或只適用完成後主動練習。逐一確認原先沒有topic連線，使用普通INSERT；已有連線、版本或來源變動就拒絕，不用upsert覆蓋。
- 新練習逐份核文件SHA、兩道不同原題、115教材及來源證據，固定publisher、school_year、subject、unit等catalog。新bank、不可變version、教材package及topic同交易啟用；預演以ROLLBACK結束，不把沒有topic的新bank先commit為一般教師清單項目。
- 精確回復比對source_version、concept_id及本批version_id才移除連線，停用本批教材package；不刪除已發生的練習版本、場次、作答或積分。不改原卷active版本，因本批原卷並未換版。
- **已知回復副作用**：現有教師清單只隱藏仍有topic連線的bank。解除連線後，保留的不可變bank會重新出現在其擁有者的教師編輯清單；不是一般題池新增成員，也不會自動產生班級測驗，但不能宣稱完全不可見。正式計畫須記本批bank擁有者及數量，回復收據核此狀態；不為隱藏紀錄而刪歷史資料或私改函式。

隔離補驗以合成身分完成113原卷全部題組，確認主動練習只對完成者開放、相同request重試同場次、跨使用者拒絕、答前不揭答案；回復後主動清單移除，本人既有練習仍可重開。既有未完成錯題作答及map保持，重複INSERT被唯一約束拒絕，一正一誤及重試只累積兩筆練習積分。34份候選均通過原生文件驗證，前29份深度比對保持；這些不是34份皆已正式作答的證明。

## 候選來源進度與驗證邊界

私有候選現有34份兩題練習、45道不同書商原題，共68個題目位置；57個重點另有23個尚待篩選。含一份明列前後SHA的私有候選修訂，先前25份固定包保留。從已核SHA的115上康軒原光碟取出222份現行目錄原題供篩選，不將取件數列成已轉化或已上線數；也不擴大一般教師題池轉化範圍。原件、答案、教冊與私有輸出不上公開repo。

上述首次連線、權限、存答與回復均只在隔離PostgreSQL；新增普通練習的教材package、正式OAuth、教材開頁返回、正式資料全量讀回、同PR收據及正式配題啟用仍待完成。正式抽驗依現行SOP區分程式批次3%與人工批次5%，不以本機樣本代替。PR #636 SQL及夥伴第二身分另依既有待辦處理。
