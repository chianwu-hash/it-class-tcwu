# 考前練功房：難度選擇與自動補題

2026-10-27。使用者已定案不讓學生處理缺題選項，並授權實作、本機通過後上線。本文件取代先前「難度選擇維持規劃」的狀態。

## 組卷規則

| 所選難度 | 易／中／難目標 | 先完成目標後的補題順序 | 不加入 |
| --- | --- | --- | --- |
| 易・基礎練習 | 60%／40%／0% | 中→易 | 難題 |
| 中・綜合練習 | 20%／60%／20% | 中→易→難 | — |
| 難・進階挑戰 | 0%／40%／60% | 中→難 | 易題 |

- 預設中等、10題；仍可選5／10／15／20題，各配比皆為整數。
- 先依三類目標分別取題，再按順序補缺額，避免補題先占用其他類別的目標題額。
- 限定所選單元、可用題池、同卷內容家族不重複。跨卷已做過的題目仍可練習，優先選較少做過的題目；學習重點及單元仍盡量分散。
- 允許使用的題目仍不足才少出；全部為零則回報沒有符合所選難度的題目，不建立空卷。
- 不跳出缺題確認。成功提示列出缺少的類別、自動補入的類別及實際易／中／難題數；個人清單保留所選難度、補題提示及實際配比。
- 例如分數20題難卷，目標中8／難12；可用難題5，實際中15／難5。乘法10題難卷則為中9／難1。

## 資料相容與安全

- RPC `quiz_compose` 對自組新增 `difficulty=easy|medium|hard` 白名單，伺服器決定配比、補題、判斷缺題；前端不能自訂比例或超出題數上限。
- 新參數納入 request 設定比對，不能以同一 request_id 改難度。省略參數仍是中等，舊 request 的 config 格式維持相容。
- `actual_distribution` 保存所選 difficulty、target、目標階段 shortages 與最終實際數量，隨本人清單投影；不新增學生直接讀取題池的權限。
- 舊卷不重組、不重排、不改答案；舊卷顯示中等。錯題延伸不接受難度參數，繼續同重點、排除原家族、有解析且不高於原題難度。
- 既有 Google 登入、Supabase 作答、Google Drive＋Cloudflare 圖片、字型、燈箱及回饋動畫沿用。
