# 自編數學問題3來源

3來源保留原式、共用材料及8個來源作答位置，轉為6小題：3個開放文字作答、3個商餘數結果題。共9個輸入欄，其中6個結果欄可自動判分；另外2份直式筆跡只保存供核對，不宣稱自動批改。

原生open沿既有self-review-v1，例答與檢核重點是參考資料。驗收作答須於私有固定包明列，不從例答自動取第一筆。先送答、重開保留，再由學生按自評、重開核對；correct維持null。未完成自評不可前進下一題，送答與自評使用不同request_id，各自同ID重試不重寫。

本次製作端只承接純文字open，拒絕open手寫欄及參考媒體；沒有擴充前端、資料庫函式或權限。其餘閉合結果欄沿既有契約。教師原圖留私有原件證據，這批學生題面不需要新增媒體登錄。

原件及教師答案逐筆固定，商餘數另以整數除法核算；6小題均核課本90頁自編問題原頁與正式對照，91頁作切頁驗收。原先同行的黑熊閱讀來源，其109／115舊對照不能支持閱讀問題，另列課本證據例外，未匯入本批。

16項針對性測試、15個正式快照情境及1280／390／320顯示預檢通過。包含空欄、超長、送答前自評拒絕、送答後未完成狀態、不同request_id自評、同ID重試、兩種自評結果及correct:null讀回。5%抽1來源正式OAuth已通過：桌手機課本開頁、返回與作答保留，以及儲存、自評兩次重開。

通過後整批啟用、逐題讀回並更新總帳；最終收據留本批同一PR。尚未完成的正式證據不得由本機預檢替代。
