## 原題與作答

五張原題／教師解答合頁及 20 原檔 SHA 已核。原題均屬「寫出算式做做看」，沒有指定直式或另印直式空格。四筆舊複核把教師直式末列兩數再列成兩個答案角色；這八個教師過程結果改映射至人工 work 追溯，保留原複核及數值，不讓學生重填。每個完整父來源用一份算式紀錄及最後公斤、公克兩格，合計五個人工過程、十個答數欄；沒有拆題。

沿既有 expression `work-v1`，合理方法不以單一字串批改；系統只核最後答數。精確原件與實際 `copy_self` 指紋新增五筆，既有 87 筆 work 及其他全部來源匯出保持。欄寬依原標籤與實際輸入伸展，不從參考答案推算。

三題只問「有多重／重多少」，沒有指定公斤與公克複名數。保留原先可用全部公克的規則，使用現有 `fields-v1` 的跨欄 tuple：公斤、公克兩欄可填標準複名數，也可填 0 公斤與全部公克；兩數必須成組，不能混搭。另兩題明問幾公斤幾公克，維持原答法。不新增判分函式、不改既有作答。

## 固定解析與教材

解析逐題交代加減方向、單位換算、完整算式與答句、逆運算，並補同單位分欄算法。哈密瓜題原數字本來就是公克，直接相減即可，不說成原題已給複名數；其學習重點是比較重量，而非總重與部分重量。教師直式是解答示範，不把它當作來源強制要求；原圖留在私有原件及複核包追溯，本批沒有必要題意圖或新增媒體。
