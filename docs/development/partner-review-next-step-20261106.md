# 夥伴練功答題底部下一步指示

原本全員送答後的回顧引導在頁首與懸浮提示，題目底部只留下停用的下一題與回顧按鈕，學生容易不知道接下來要做什麼。

在目前題目下方、換題列上方增加文字與操作入口，沿用現有伺服器狀態：

- 已到最後一段／題、仍有本人未送出答案：顯示剩餘題數與返回未送出題目的按鈕。
- 本人全部送出、隊友尚未完成：明示「下一步是共同回顧」，列出全組送答進度與解鎖條件。
- 全員送出：明示「答題完成！下一步：共同回顧」，直接前往既有回顧畫面，提醒按「我看過大家的題目了」。
- 本人已確認回顧：說明等待全員確認後結算；已完成任務則導向共同紀錄冊。

只更新提示 DOM；狀態更新不必替換答題內容。忙碌／結果待確認時停用新操作，維持現有回顧開放條件、任務與作答紀錄及計獎方式，不新增 API 或資料庫遷移。四個年級入口更新快取版本。

驗證：既有 focused／outcomes 共 8 項 Node 測試、模組語法與 git diff --check 通過；隔離合成題瀏覽器 13 項 DOM／狀態操作檢查通過，含未送出跳轉、等待進度、同步解鎖、進入回顧、390px 無水平溢出、忙碌鎖定、已確認與已完成提示，pageerror 0。

瀏覽器檢查以 DOM click event 驗證操作，沒有實體手機觸控或正式雙帳號實測。背景截圖逾時、前景保護拒絕啟用，截圖及真實滑鼠點擊未列為通過；未修改共用瀏覽器保護。私有原始檢查紀錄留在 repo 外。
