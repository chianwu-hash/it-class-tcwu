# 全科上線計畫：Claude兩輪討論與主線核對

2026-10-27。使用者要求先將規劃交Claude討論，找出問題。本輪只做唯讀討論與規劃文件修訂，沒有改產品程式、匯入、功能測試、雲端操作、正式資料庫或部署，也沒有commit／push。

## 結論

方向可行，原計畫需明確區分「來源整理」「可抽池」「功能開放」，補上課程隔離、來源修訂及逐題發布門檻。首批不先追求十科全冊深度轉換，改先輕量盤點、跨書商樣本、通用化相容，再做雙書商期中獨立單選試點。

## 第二輪校正

- Claude撤回「每單元至少5題才開放」。維持使用者定案：符合條件只剩1～4題也自動出短卷，標實際數量；零題才不建卷，沒有缺題確認。
- 位置依賴與揭答洩漏改列單題／題組發布門檻，不能讓問題題先啟用後再處理。「以上皆是」不一概視為會被亂序破壞。
- Claude只讀到session reveal='immediate'，不足以斷言既有題組引擎逐子題洩漏；主線另查既有SQL的block處理。新抽題有無保留block仍須實測。
- 缺難度／重點的限制改到題目層級。Codex另外計數現有康軒四科、南一兩科的期中轉換catalog：均有difficulty=-3/0/3，未見該欄缺值；這只說明這批轉換資料，不證明全冊來源完整或映射皆已驗收。
- 不要求全新request在架構調整後仍抽到與舊演算法一樣的題；必須相同的是舊request的同份固定卷、題序及配比。
- 來源識別保留課程、原題、子題及修訂，不用「原題ID複合唯一」限制掉同原題多子題／多修訂。延伸應依凍結修訂，沒有採用以最新修訂默默取代。
- 媒體保留界線是仍被可回看版本引用，不是所有媒體永不刪除；本輪未授權任何清理。
- 主線補充：學生可合法換選同年級已開放科目；拒絕跨年級及課程關係不符的混搭，不能誤寫成所有跨科選擇都禁止。

## 討論後前三工作包

1. 十科輕量盤點＋三書商與兩英語版本代表樣本，定最小資料契約。
2. 課程隔離、移除硬編碼、舊請求與來源版本相容、發布批次狀態；先保持既有三上數學正常。
3. 六上數學＋南一六上自然期中獨立單選試點，通過數量／難度補題／內容／權限／保存接續後再開放。

第1、2包可交錯進行；通用資料契約需採樣本結果，其他科不得在隔離完成前啟用。其他科期中池、後半冊、題組與其他題型循分批核對擴充。同儕、排名、AI出題等仍延後。已將這些建議寫回 [全科上線計畫](quiz-all-subjects-rollout-plan-20261027.md)，尚非實作授權。
