# 中正九年級二段社會：57份首次固定配題登錄計畫

**狀態：私有內容及隔離整批驗證完成，正式配題尚未啟用。** 本批是113／114社會原卷的延伸配題；二段其他考古卷、後續三段及正式夥伴多人驗收仍未完成。

## 固定範圍與教材證據

57個重點各有兩題固定草稿，共81道不同書商原題、114個題目位置。來源為73道既有正規化來源及8道由共用Word解析器取出的歷史第五課來源；文義複核與補充解析逐題固定，沒有手工重打原題或改選項。一般教師題池及題池成員沒有新增，不能把新普通練習bank數加進一般老師卷轉化數。

逐一核原Word題幹、原選項與答案，對帳保留的MDB獨立匯出鍵；原MDB需密碼，本輪未重新讀取，不冒稱新開原MDB成功。原光碟SHA已與歷史紀錄相符。另對正式既有1,124筆社會來源讀回，全部與原封存內容相符，73道選用來源逐筆相符，新增8道來源未寫入一般題池。

教材採**115學年度**。本批重新核16份課本／教冊PDF的實際SHA、34個教師原頁及其學生課本對應頁；逐頁沿用有實際目視且圖像SHA相符的學生頁證據。普通練習重用原已核准的6筆教冊book、61筆頁紀錄，實體頁內容有34種；不新增課本、不補寫已固定book的頁，也不重傳素材。四張書商原圖均保留完整內容，逐張與Word內嵌原始bytes／SHA相符；新普通練習情境下的正式HTTP供圖仍待驗。

書商題目的歷史出版來源與115教材分開記，不冒稱所有原題都是115年出版。解析標AI整理，保留原書商解析身分。各重點未涵蓋的圖表、人物、完整義務或其他細節，逐份列在[固定清單](zhongzheng-g9-social57-first-binding-manifest-20261129.json)的`coverageNote`，不以兩題推稱整章完整覆蓋。114企業責任組合分別核資源耗用挑戰與回收循環的相關經營實踐，未宣稱覆蓋企業責任全部定義及勞權。

## 隔離整批證據

以main `e9864d4b`的正式schema／函式建立原生PostgreSQL隔離庫；安裝本批實際會遇到的八個教材不可變、插入守衛及普通版本快取觸發器。來源兩卷由合成身分實際完成，並先釘選原教材package，再測首次登錄。證據見[原生驗證收據](zhongzheng-g9-social57-first-binding-native-proof-20261129.json)。

- rehearsal交易結束ROLLBACK後沒有新bank或普通package；activate一次建立57份、114筆教材item、57個topic及57筆版本快取，擁有者一般編輯清單不列出這些仍綁定的bank；再次activate被拒絕。
- 57份均經原生`quiz_learning`開始及普通`quiz_action join`，114個答前教材連線完全相符，答前不揭固定答案／解析。61筆引用頁及四張原圖的本人存取允許、跨人拒絕；57份跨人加入皆拒絕。這些是descriptor與權限證據，不是正式HTTP bytes證據。
- 三份代表練習實際送六次正誤答案並重送同request，保留六筆積分、重開相符。原自核題維持自核、不自動判對錯；對應練習只由完成原卷後的主動模式開啟，錯題模式及錯題詳情皆拒絕。
- 已啟用package的item及既有book頁無法改寫。精確detach與restore均通過；原卷、map、教材、一般題池、社會夥伴範圍及來源／練習作答摘要保持。

## 正式登錄、回復與待驗

此PR進main後，從新建乾淨main執行固定資料交易；正式前重核11個相關函式與main快照指紋、原卷active／SHA、map雜湊、6筆既有book、61筆引用頁、四張既有素材descriptor及所有新識別均未存在。以來源版本交易鎖、原卷行鎖及逐筆guard處理並行變更，遇差異即拒絕。

1. **rehearsal**：完整建立、檢查並ROLLBACK，比對受保護狀態摘要；不把未連線bank先commit為暫存。
2. **activate**：同一交易建立固定bank／version／package／item／topic並啟用，正式全量讀回文件、快取、連線、教材與來源狀態。
3. **detach**：逐一核source_version／concept_id／version_id及固定內容後，只移除本批連線、停用本批package。原卷與既有練習答案保留；停用後該普通練習教材連結停止。**57個保留bank會回到擁有者編輯清單**，不宣稱撤回後完全不可見，不刪歷史資料掩蓋狀態。
4. **restore**：只在本批內容完全相符且連線皆不存在時，重新INSERT同版本連線並啟用原package。既有答案與釘選教材package可續用，不建立另一套重複版本。

本批未改資料庫函式、共用程式或網站產物，不需網站部署；不把PR #636的待核准函式SQL混入本次資料交易。

正式OAuth依[現行批次規則](quiz-batch-conversion-rules.md#4-代表題驗收與證據重用)計原始來源：共用程式轉換81筆的3%向上取整為**至少3筆**，不能用114個位置作分母；若另有需逐題人工轉錄部分，該部分另用5%。逐題教材／語意複核不等於手工改寫題幹。本批沒有另列手工轉錄來源。

抽驗從正式九年級學生入口開始，涵蓋錯題→重點→固定練習→答前教冊→返回保存／重開，以及完成原卷後的主動練習、自核分流、四張原圖實際HTTP SHA及手機冷圖。新來源ID、既有儲存答案、素材及教材權限有受影響分支時補代表證據；其餘沿用未變契約收據。正式讀回及同PR收據尚待完成，不把隔離成功記成已上線。

單批仍是里程碑。長線須先完成九年級二段考古卷，再接續三段，並按適用年級科目從正式學生入口實際驗證老師準備的卷、考古卷、自己組卷及夥伴練功四項。九年級新轉化仍只做考古卷；可靠配題是其延伸，沒有擴張一般教師題庫轉化分母。
