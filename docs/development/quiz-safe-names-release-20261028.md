## 規則與邊界

- 後端維護22組固定配對，涵蓋寶可夢、吉伊卡哇、三麗鷗、名偵探柯南、超級瑪利歐、哆啦A夢、星之卡比、貓貓蟲咖波、好想兔；不使用即時AI產名或學生文字。
- 格式如 `三年級數學｜寶可夢・皮卡丘｜003`。年級、科目及學年度取自建卷時已驗證的固定場次資料；作品與角色由配對表一次抽定，保存在獨立欄位，重新開卷不重抽。
- 每位學生、每學年度跨科遞增，至少3位數，超過999不截斷；刪卷不回收號碼，同request_id重送仍回原卷原名。流水號只供顯示，原試卷UUID不變。
- 前端移除組卷名稱欄、改名表單與相關用詞，保留範圍、題數、難度、儲存時間、刪除及接續作答。舊前端傳入name會被忽略，學生呼叫舊改名RPC明確回paper_name_locked；資料表觸發器也拒絕已配發名稱與命名欄位被改寫。
- 舊generated paper連同已刪除但仍有葉片的卷一併換安全顯示名。原始config及舊名稱私有備份不向學生呈現，不改不可變題卷、原題、正解、作答、葉片或student_progress。老師preset沒有generated row，保留原名。
- 清單、作答標題及努力樹既有adapter繼續讀同一個display_name，不新增一套獎勵或發葉。
