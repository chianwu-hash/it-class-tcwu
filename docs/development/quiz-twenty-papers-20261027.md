# 自組卷上限20題

2026-10-27，使用者要求將自組卷題數上限提高到20題。選單提供5／10／15／20題，預設仍為10題。

- 目前實作沿用中等配比20%易／60%中／20%難：5題為1／3／1、10題2／6／2、15題3／9／3、20題4／12／4。切換題數即顯示目標配比，組卷後顯示實際配比。
- 題目不足仍如實顯示，不重複湊題、不跨出學生所選單元。題數與難度選擇是不同設定；先前提出的易／中／難選擇仍是設計提案，本次未新增難度切換。
- 後端白名單與配比計算同步更新，拒絕超過20、非選單題數，以及將錯題延伸偽造為20題。錯題延伸仍為3／5題規則。
- SQL測試驗四種題數的配比、題目唯一、20題全數送答與重整後20筆答案／解析，以及非法題數拒絕；相關6組組卷／命名／刪除測試全通過。
- 本機瀏覽器用全冊9單元組20題，確認4易12中4難、未答即儲存、清單20題、改名與重整、送1題後接續第2題，以及390px無溢出、頁面錯誤0。

正式schema更新重用 `names-deploy.mjs --twenty`，不重匯題庫或圖片，前後比對原答案／版本摘要。瀏覽器透過AI工作瀏覽器租約執行 `named-browser.cjs`，設定 `QUIZ_PAPER_COUNT=20`；本機／正式證據存於ignored `qa/twenty-local.json`、`qa/twenty-production.json`，schema證據在 `twenty/deployment.json`。
