# 英打基礎十二關：課程與實作契約

更新：2026-10-02。僅六年級開放；三年級待 Google 帳號啟用後另行開放。每週作業、中打與原期末成績公式不在此次變更範圍。

## 研究依據與取捨

- [KidzType 官方課程](https://www.kidztype.com/typing-web/)提供基準列、上排、下排、數字、符號與 Shift 分組。我們保留既有第一關，採逐排認鍵，但上、下排先由食指向外擴展；不宣稱與 KidzType 遊戲的十二關完全相同。
- [Typing.com 六年級課綱](https://www.typing.com/curriculum/grade_6)採鍵位分組、複習、評量與應用；順序不一定逐排。因此十二關是本課程的重新編排，題目自行生成，未複製外站題庫或圖片。
- [TypingClub 難度設定](https://www.edclub.com/help/class-management/class-settings/adjust-class-difficulty.html)將正確率與速度作為可調條件。下列門檻為本課程暫定值，並非臺灣六年級統一標準；先供教師測試再依學生表現調整。
- [Ratatype 指法說明](https://www.ratatype.com/learn/)作為對側 Shift 提示依據。畫面同時標出打字手指與另一手的小指。軟體不能證明學生真的使用指定手指，需教師觀察。

## 十二關

| 關 | 主題 | 五個練習步驟／最後綜合挑戰 | 一般／初學 WPM |
|---|---|---|---|
| 1 | 手指的暖身運動 | FJ、DK、SL、A;、GH → 基準列 | 12／8 |
| 2 | 往上探索 | RU、TY、EI、WO、QP → 上排與基準列 | 12／8 |
| 3 | 往下探險 | VM、BN、C逗號、X句點、Z斜線 → 三排 | 12／8 |
| 4 | 字母大集合 | 左食指、右食指、中指、無名指、其餘換指 → 字母混合 | 12／8 |
| 5 | 大小寫搭檔 | 基準列左／右、上排左／右、下排 → 大小寫混合 | 12／8 |
| 6 | 標點小幫手 | 逗號句點、分號單引號、驚嘆問號、冒號雙引號、複習 → 混合 | 12／8 |
| 7 | 數字列探索 | 47、56、38、29、10 → 上方數字列 | 12／8 |
| 8 | 數字符號變身 | $&、%^、#*、@(、!) → Shift 數字符號 | 12／8 |
| 9 | 符號工具箱 | 連字號等號、括號、大於小於、反斜線直線、反引號波浪 → 混合 | 12／8 |
| 10 | 單字接力 | 四字母常用短字、換手與連接 → 單字流暢度 | 14／10 |
| 11 | 句子小旅行 | 句首、空白、標點、節奏、連句 → 短句 | 14／10 |
| 12 | 英打成果挑戰 | 字母、單字、句子、數字、符號 → 綜合應用 | 15／10 |

每關有六小關。前五小關正確率 90%，不限速度；第六小關正確率 95% 且達該關速度，同次兩組不同題連續達標。精進目標為一般門檻再加 3 WPM，不影響基本過關。

初學起步在每關開始前選擇，開始取得小關成果後鎖定；已過關不改門檻。未來教師調整可由課程設定集中維護，但目前沒有任意編輯雲端門檻的教師介面。前端與 SQL 設定一致性有自動測試。

## 題目、輸入與提示

- 每次換新題；同次與上次不重複整行。認鍵每段 67 鍵、綜合 117 鍵；句子每段 83 鍵，最後綜合 86 鍵。固定長度替換詞讓後端能核對完整題量。
- 第十關四字母詞庫，第十一／十二關為可讀短句與情境字串；這是英打練習，不是英文理解測驗。
- 錯字停留原位，正確率包含所有錯按；Backspace 不倒退，避免修正後把正確率變成 100%。所有正確字元含空白、標點以每五鍵一字計算 WPM。
- Caps Lock 提示關閉；大小寫必須和題目一致。數字用上方數字列；實體 NumPad 不納入此次指法練習。Shift 手指提示不代表能驗證實際用指。
- 小關顯示指法、綜合預設隱藏但可開啟；暫停或離開分頁的綜合不作速度確認。

## 儲存、解鎖、成果與重置

- 使用原有 Google／六年級名冊核對；後端以登入身分及 lesson_key 精準讀寫，不接受客戶端學生 ID。
- 前面所有大關完成才可 load/start/save 下一關；網址跳關也由伺服器拒絕。地圖列出十二關、目前關及鎖定狀態。
- 小關完成自動保存，下次接續；挑戰 1/2 不跨練習 session。儲存失敗先重試，不開放切換或前進。
- 已過關小關的重練不寫入成果；整關不重複發葉。努力樹列出十二項，每一關一片葉。期末保留原公式不擅自分配權重。
- 教師可匯出全部關卡，或確認後精準重置某學生的某一關。只收回該關葉子；後面已存成果保留，但後續練習暫停，補過缺少的前關再恢復。每次重置增加 revision、留稽核，不刪除歷史與週次作業。
- SQL 以交易與同學生鎖序處理跨關讀寫，避免重置與保存交錯。既有第一關 lesson_key、資料與版本保留。
- 速度、時間仍由前端回報，是教學練習而非防作弊考試。
