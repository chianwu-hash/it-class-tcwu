## 第07週教學影響

- 302、305、306以整班改密碼主線支援為主；不只依上週302／306的路徑分組。
- 301、303、304依個人狀態分流：已完成者保留原新密碼，直接登入親師生平台驗證，不再進校務系統；未自行完成者確認目前有效登入方式後再修改。
- 系統「已完成」只代表設定狀態，不代表學生現在知道密碼或能正確輸入。教師另記「本人本週登入驗證」。不能由完成比例推定全班操作能力、忘記人數或第06週整體任務完成率。
- 橘色警告者不能繼續假定本人紙條的舊預設密碼有效；教師依校方程序確認目前帳號狀態，不直接全班還原。

## 防止反覆還原

1. 已完成者先私下查本人有效記錄，教師不收新密碼；不以強迫背熟當唯一使用方式。
2. 登入失敗先核對帳號、入口、英文模式、Caps Lock、漏字空白、自動填入舊密碼、同步與帳號狀態。學生仔細修正一次仍失敗即停下，交由老師診斷。
3. 已改者直接登入親師生平台。確認平台仍無法登入，且教師確認遺忘無有效記錄、密碼失效或需處理帳號，才個別還原。
4. 還原後協助一次做完整：校務系統登入與修改 → 明確成功 → 更新本人私下記錄 → 親師生平台新密碼登入 → 教師記驗證結果。
5. 同一人再次失敗，先記卡點再診斷，原則不在一節裡反覆還原。未解決者另排個別支援；這是課堂安排，不是系統的次數限制。
