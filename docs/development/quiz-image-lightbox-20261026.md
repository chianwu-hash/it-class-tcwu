# 題庫圖片燈箱

日期：2026-10-26。使用者要求將答題介面裡的圖片改為點擊後以燈箱展示。沿用 `shared/image-lightbox.js` 與 `image-lightbox.css`，不另造圖片檢視器。

`grade6/115-1/quiz.html` 載入共用燈箱樣式，`shared/quiz-student.mjs` 以 `initImageLightbox({ root: serverQuizElement, selector: 'img' })` 初始化。只處理題目、共用材料、選項及已揭露解析中的實際圖片，網頁公式、表格、動畫 SVG 保持原有呈現。

共用燈箱支援動態內容事件代理，並用 MutationObserver 補上圖片的鍵盤焦點、按鈕語意及放大提示，逐題重繪後仍有效。選項中的圖片會攔截預設 label 動作，點圖只放大；選答仍透過其餘選項區域。圖片按 Enter／空白也能開啟，關閉後回到圖片焦點。既有不帶參數的課程頁呼叫相容。

放大圖使用目前已獲授權並載入的原圖來源，不提供公開副本、額外解析權限或另開分頁。不把短效網址存回題庫或紀錄；關閉燈箱移除放大圖 src。沿用共用縮放、重設、置中、拖曳、雙擊及手機雙指操作，Esc／關閉鈕／背景可關閉，並恢復頁面捲動。

已作答時改為逐一停用 radio／textarea，並以 fieldset 的 data-locked 表示鎖定狀態，避免停用整個 fieldset 同時阻擋圖片滑鼠事件。保存中、等待重試、場次關閉等情況亦鎖住輸入；後端保存／揭答流程不變。實測點選已作答的其他選項，保存答案不變。

本機4344及4345試答服務原有精確靜態檔案清單，需額外允許 `/shared/image-lightbox.js` 與 `/shared/image-lightbox.css`；修改忽略目錄中的兩個服務並重啟，使用原有持久資料庫，沒有重建題庫或重設作答。正式網站與後端未部署。
