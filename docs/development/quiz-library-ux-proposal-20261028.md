# 考前練功房選卷頁整理提案

日期：2026-10-28。此文件保留原討論提案。使用者後續已核准實作，並增加主題／角色選擇；現況與驗收以[實作發布紀錄](quiz-library-ux-release-20261028.md)為準。

## 使用者需求與現況

使用者希望自組卷設定預設隱藏，按「我要自組卷」才出現，並改善整頁資訊安排。現況是表單、我的自組卷與系統預設卷全部展開；分頁與區塊跳轉並存，造成頁面很長。

## 建議採用的共識

1. 縮小品牌橫幅，保留網站既有風格與年級標示。
2. 自組卷設定預設收起；「＋我要自組卷」按鈕展開原頁紫色區塊。收起保留當頁選擇，切換帳號則清空。
3. 清單統一為「老師準備的卷／我的自組卷／我的錯題」三分頁，取消既有區塊跳轉按鈕，一次只顯示目前分頁。老師卷藍色、自己的卷紫色，搭配文字辨識。
4. 預設顯示老師準備的卷，避免新生看到空清單。若現有資料能可靠判斷最近作答的未完成卷，上方提供一張「繼續上次練習」卡；若只有儲存時間而無作答先後，不能把最新建立卷誤稱為上次練習。
5. 科目篩選放在分頁下方；第一階段先整理既有功能，不新增後端。錯題頁沿用自己的篩選語意，避免同頁重複出現科目篩選。
6. 卡片優先顯示範圍、題數、難度、作答進度和主要動作。保留完整安全自動名稱，但降低視覺比重；實際易中難配比與整理操作收進「試卷詳情」，補題提醒仍顯示在卡片上。
7. 組卷成功顯示獨立成功卡：已儲存、名稱、實際題數與配比、「開始作答」「查看我的自組卷」「再組一份」。不自動跳分頁，也不讓刷新清單抹掉成功訊息。
8. 我的自組卷全部仍可找到，不以只顯示最近三卷取代完整清單；未完成／已完成篩選與其他分頁記憶可後續再做。

## 互動與驗收界線

- 組卷區獨立於清單分頁；切換分頁不突然丟掉已選設定。只在明確操作時收起。
- 分開管理資料可用、使用者展開、生成中三種狀態；目錄重新讀取不得自動展開，生成中避免重送或丟失狀態。
- 不可用原因必須能區分載入中、失敗與未開放；不能將所有失敗誤稱為無權限。登入後才依已驗證身分提供功能。
- 展開按鈕提供 aria-expanded／aria-controls；收起時回復焦點；手機 390px、鍵盤與分頁操作都要驗證。
- 不改學生身分、年級限制、雲端儲存、作答紀錄、獎勵、防弊、固定命名與組卷冪等性。
- 需驗證組卷成功立即入清單、重新整理不重送、切帳號重設、接續作答、錯題解析與刪卷仍正常。
