# 夥伴練功自組卷與選題器

## 契約

- 普通老師卷／自組卷10題只2人，20題2～4人；考古題沿用2～4人。
- 自組卷須為本人未刪除、開放、當學年且適用本人班級的固定卷；requested count與實際題數只開10／20，extension、5／15維持個人模式。現行題池只含獨立單選題；未知題型不轉換。
- 原個人題庫、quiz_action、登入、作答、刪卷與個人計葉不改。只讀來源，不建立個人作答／個人獎勵。
- 小隊每次建立一份不透明ID的私有快照；不回傳原個人session／version。只有本人catalog有原卷帶入資訊；加入者只能使用該小隊。
- 邀請碼顯式驗證當前名冊、年級、到期、未出發；加入在房鎖內重驗碼／容量。無GUC權限捷徑。
- 原卷刪除後不能新建；已分享小隊保留題目、未出發邀請、進度與紀錄。原卷個人成績不分享。
- 10題1葉／20題2葉，全部作答、全員回顧、全組最新自動判分達60%；訂正可補達。canonical內容＋排序成員集合沿用唯一領取；換題序／卷名／來源session不會重領，換成員可領。考古花沿用。
- 已出發舊10題3／4人房保持分題與獎勵；未出發舊房不加到超過2人，需由多餘成員自行離開後發起人改2人，不能強制移除成員。
