## 原位題卡

精確來源的 `responseGroups` 將每小題原文、原算式部分與原答案控制放在同一卡。只有範圍連續完整、欄位 ID 唯一全覆蓋、組數與 work parts 相同、來源與複本指紋都吻合才啟用。`groupUnit:'layout'` 以完整原生區塊分組，保留共同表格，未改通用內容切片器或把表格轉成圖片／攤平成文字。

控制項直接搬移，保留 listener、原值與一次保存；同一組原數字符號鍵盤隨目前聚焦的算式移動。保存／待確認按部分顯示；舊單一文字過程仍以整題原文顯示，不猜分組。刻意隱藏已重複呈現的 work 時，參考畫面仍保留各原問題與正確欄寬，重複呼叫不複製題文或控制。沒有實答的教師預覽也保留完整原題。

目前版面區塊模式只核全數學答案欄、純文字段落及原生純文字表格；媒體、其他區塊、不連續、重複／漏欄、模型或來源變動均拒絕套用並保留原文。它不是已涵蓋所有圖文多題的通用宣告。後端仍只驗非空人工 scalar，前端正常 parts 才檢查缺部分；編碼後合計 250 字上限保持，不冒稱自動判算式語意。

## 解析、教材與複核

固定解析依完整小題說明為何用加減乘、單位換算、完整列式與答句、逆算，保留承上題關係，未拆成逐格答案卡。各來源的學習重點分開寫，不把無乘法或無承上關係的題目標成相同重點。

教材 111 頁與雜糧題三小題相同，但未印完整答數，明示直接支持及界線；112／115 頁提供其他重量加減列式的相關觀念，不冒稱同題解答。三頁均目視核對及固定 SHA，沿既有 70 頁閱讀器；無可靠延伸配題，保持缺項與入口限制。
