# 明確選用的數學單格簡答核對

2026-11-12。數學題庫仍有整數、分數與比較符號的單格填答待接線。新資料在 `answer.normalizer: "math-v1"` 明確選用時，重用已存在的數學正規化，讓 `２／４`、`0.5` 與 `1/2` 可視為等值，保存學生原始輸入；不執行使用者算式，`2+2` 不會當成最後答案4。未帶標記的舊簡答仍只做原有trim字串核對，既有成績與固定版本不改。

## 保護範圍

- 只更改 `quiz_validate` 與 `quiz_action_before_learning` 的唯一目標片段；學習、課本包裝、登入、年級、順序、重送、計時、RLS與ACL保持。
- 三個相依函式定義的雜湊都須吻合；既有數學正規化本身不重裝。兩個目標都等於after hash時可以安全重跑。
- 升級前檢查既有normal版本、草稿與題池是否已帶這個原本會被忽略的key，任何一筆存在就拒絕，避免舊未作答卷意外改判分。最前面以5秒逾時的短交易鎖保護這三張來源表，避免檢查期間另有草稿或版本帶入同名key；學生既有作答表不鎖。
- 拒絕 `1 1/4`、全形或換行等兩個數字間隔空白的歧義，不悄悄吃掉空白變成 `11/4`。`1 / 4` 的分數線前後空白仍可用。accepted有同樣歧義也不允許發佈。
- 新SQL保留主線快照中的混合換行位元組，`.gitattributes`固定為`-text`；測試從固定的升級前主線定義重建，逐字核對待部署SQL，避免檔案轉換使before/after hash失效。

## 驗證與啟用順序

四項新PGlite測試通過，包含同一舊固定版本換另一學生仍保留原判分、等值分數／全形、原始response與重送、拒絕非法輸入不存答案、匿名與直接helper權限、既有marker及函式／相依定義不符時原子拒絕、重裝冪等。七項相關既有測試與quiz:check通過。

正式PostgreSQL將本次實際SQL完整放在回滾交易：4種判分案例、3種帶空白數字拒絕、揭答前無答案通過；合成資料回滾，兩個正式函式雜湊均恢復原值。Claude唯讀審查無P0，指出帶分數空白P1後採其建議加上防護；也補足它提出的待部署SQL與測試生成器一致性問題。

PR153已合併，已從乾淨main `4b763e1` 核對SQL位元組後套用，13類既有學生／固定版本摘要不變。production-snapshot已更新且171函式live check通過，只有預定兩個函式雜湊改變；新資料另行驗證啟用。這是後端明確選用的相容增量，既有short介面及揭答回顧可直接使用，不需要Vercel部署。

## 資料與後續

本輪另備妥203個完整單位置來源（113選答、90簡答，其中89明確選用math-v1），由原question-only Word保留原生表格、可見分數與圖片；不使用會缺分數的stem文字索引當題幹。比較符號、重量單位與奇偶可改為完整選項點選，原數值、判斷目標及答案保持。其他90個單位置候選仍待選圖／完整選項或原生表格接線；完整多欄題組另行保留，不能硬合一格。

第一批已上線378不受本候選影響；新203目前尚未啟用。57張所需新題圖已在原學校私有Drive逐檔回讀驗證，學生資料仍須完成逐題正式送答與固定解析／課本接線才可啟用。原始題庫、教材、個人資料與逐題輸出均留repo外。

回復原則：停止新選用題的抽題而保留已固定版本的正確核對。只在尚無任何已帶標記的版本、草稿或題池時，才可受保護恢復兩個舊函式；已啟用資料後不能直接降回舊字串判分。正式套用與資料收據會另行補記。

驗證固定升級前定義存於automation/fixtures，正式快照更新後不重抓新定義冒充舊基準；SQL與快照均保留真實混合換行，Git只將行尾CR視為合法換行，不改位元組。
