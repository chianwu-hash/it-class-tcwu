# AI解析中的數學表示式

問題：固定學生解析以純文字保存「1又2/3」與「105÷（1又2/3－1）×1又2/3」，原排版器只識別有美元公式標記的內容，所以解析保留斜線分數，沒有使用現有KaTeX數學排版。

修正僅作用於解析顯示。`quiz-explanation-render.mjs` 以小型數字文法辨識帶分數、普通分數、括號及四則算式，轉成既有排版器可讀的標記；不計算、不改題意、參考答案、固定資料或作答紀錄。既有美元標記公式保持，另支援AI常見的TeX括號標記。日期鏈、題頁標籤、識別字及不完整式子保持原文，不推測補全；HTML保持文字，KaTeX沿用trust:false與資源限制。

一般答題的固定學生解析、個人考古題的學生／舊版AI解析及錯題回顧的AI解析共用同一處理。原書商圖文解析保持既有renderContent流程。長公式在自身範圍內可橫向捲動，不把手機頁面撐出螢幕；分數使用既有完整字級。

驗證以使用者提供的水果重量解析重現，包含帶分數及完整算式；另外檢查原有TeX、日期、題頁標籤、非法HTML及不完整式子的處理。14項解析／原生圖文／固定課本及建置模組測試通過。瀏覽器驗證與正式發布結果記於agent-handoff.md。
