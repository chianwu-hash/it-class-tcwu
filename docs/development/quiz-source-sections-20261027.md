# 自組卷與系統預設卷分區

2026-10-27，使用者要求自組卷與系統預設卷分開，並用不同顏色標示。

- 「我的自組卷」：淡紫底、紫色外框／標題／來源標籤，列出自組及錯題延伸卷；組卷表單同步採淡紫色。
- 「系統預設卷」：淡藍底、藍色外框／標題／來源標籤，獨立包住原系統卷清單。
- 兩區各顯示篩選後卷數與空清單提示。卡片同時有文字來源標籤，科目仍保留原文字與圖示；不只靠顏色辨識。
- 仍沿用網站原本導覽、字型、圓角與主要操作按鈕風格；科目篩選、命名、刪除、開始／接續連結皆沿用原功能。
- 切到「我的錯題」會一併隱藏兩區及組卷表單，返回後恢復；六年級或非學生沒有自組卷時，不強制顯示該區。
- 本輪只改前端分區與樣式，不修改資料庫、原試卷或學生答案。瀏覽器驗證為唯讀，不組新卷或送答。
