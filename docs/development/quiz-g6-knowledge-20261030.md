## 分類來源與核對

- 康軒國語 347 題：逐筆核對原題 ID、課次、知識點代碼與正式題目指紋。保留書商完整知識點組合及課文識別碼，避免不同課文的閱讀理解混為同一重點。34 種技能代碼的顯示名稱經代表題幹核對，名稱為本次整理標籤，不冒稱書商字典原文。
- 康軒英語 154 題：原知識點分為國家詞彙、be from 句型、病症詞彙、have／has 描述、病症問答及不同母音辨識，共 11 組。課次、書商知識代碼逐題對應，發音分類依原知識點與原解析文字核對，未新增音檔或變更聽力答案。
- 南一自然 140 題、社會 289 題：逐題檢視正式題幹與選項，以書商章節／課綱交叉核對，明列每題對應，不以關鍵字批次猜測或整單元當作同重點。自然細分 32 組、社會細分 45 組。
- 共 930 題有分類紀錄，928 題標記可靠。自然原題 `675931` 的兩個選項均有科學敘述疑義；社會 `1504811` 題幹問推翻政權，選項卻描述戰後族群情況。兩題保留分類及待查原因，`knowledge_reliable=false`，不作為延伸來源或候選；本次未修改原題或既有作答，也未改一般組卷的 usable 設定。

`automation/quiz-knowledge/g6-reviewed.json` 保存每題 ID、題目指紋、來源版本、課程、知識代碼／名稱與核對依據，不含題幹或答案副本。南一逐題對應在 `g6-science.json`、`g6-social.json`；康軒名稱對應在 `kang-knowledge-labels.json`。整份核對清冊的 canonical SHA-256：`e90a44644e198404438193d17a5622da4a1f001c8bcea6bb566c4cae291847a6`。

「可延伸的錯題來源數」是題庫中符合配對條件的來源題數，不是學生錯題筆數或新建試卷數。仍須是本人答錯且已開放解析的題目；來源與候選同課程、同知識代碼，候選具書商詳細解析、不同題族，難度不高於來源。題數不足時保留原有 1～2 題短卷行為，不補錯誤重點、不冒充 3 題。

國語僅 7 題有書商詳細解析，是目前主要覆蓋限制。本次沒有將「正確答案」充作詳細解析，也未代寫解析後冒標為書商解析。原截圖的自然颱風路徑題已分類為「侵臺颱風路徑的分類與方向」，但該組仍缺符合條件的解析候選，所以那一題本身仍不會顯示延伸按鈕。不能宣稱四科每一題均已可延伸；未來如需提高覆蓋率，須另行補充並核對解析／同重點題目。

## 正式套用與驗證

只更新 930 題的 `knowledge_code`、`knowledge_name`、`checks.knowledge_reliable`／`checks.knowledge_review`，以及對應 membership 的 reliable。資料庫既有觸發器會使目錄快取失效，同交易預建三、六年級快取；不是另造學生進度。

正式套用使用 repeatable read 單一交易、目錄 advisory lock、930 筆正式原列 MD5 與名冊課程核對。任何題庫內容已改變、分類已套用或清冊不完整均拒絕，不覆寫新資料；SQL 大小約 180 KB。寫入前後核對所有其他 `quiz_*` 表、非本批 pool／membership、題庫非分類欄位與其他 checks，差異會使交易失敗。原題、試卷版本、學生答案、歷次作答、葉片、題號 aliases、課程等均保持不變。

已通過：

- 三項公開清冊／指紋／候選邊界 Node 檢查。
- 本機真實 SQL：四科各測原題 ID 與舊題號 alias，共八個錯題→延伸卷情境；重試同卷、其他使用者拒絕、題族與難度邊界、兩題疑義來源排除及再次套用拒絕均通過。另測四科易／中／難共 12 份一般自組卷。

- 正式分類套用後重新匯出：930 題題目內容指紋、四個課程定義、三個相關 RPC 定義均與先前相同；每筆分類與 review SHA 完全符合清冊，四科覆蓋數符合上表。

## 重跑與後續維護

私有書商來源、正式前後快照與 SQL／結果放在 ignored `automation/output/quiz/identity-sync/`；不得提交題幹、答案或憑證。`inspect.sql` 僅讀取四科資料；輸出須放 ignored 目錄。`review.mjs` 以解析後的 snapshot 物件、原書商 `all-midterm-local` 目錄及輸出位置為三個參數。`migration.mjs` 以已簽原列快照、清冊、輸出 SQL 與可選 `apply` 為參數，預設產生 rollback 模式，不自行連線執行。

正式已套用，不要再次執行原 apply SQL；防護會拒絕。也不要重跑舊 `quiz-all-subjects/deploy.mjs --apply` 或重灌舊 quiz SQL：它們不知道本批可靠分類，且可能覆蓋其他已發布修正。原題內容、課綱版本或分類需要變更時，先重新快照與核對，保留本批清冊，再產生新的增量修正。需要回復時，使用私有 before 快照的原分類與 checks，並以目前 review SHA／列指紋作條件，只還原本批分類欄位；不得還原整張表或學生紀錄。
