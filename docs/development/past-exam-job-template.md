# 考古題製作任務與交接範本

搭配[考古題製作與上線指南](past-exam-playbook.md)。由執行者從任務、原件與現有系統自動補齊；這不是教師逐項簽核表，也不是可直接匯入的題庫 schema。複製到每次私有輸出目錄後，刪除不適用項。

## 任務契約

- 任務識別／日期／開始時間：
- 來源學校與穩定識別碼：
- 試卷學年／學期／考次／年級／科目／出版社與版本：
- 目標網站、管理者、學生目前學年／學期：
- 指定卷數與 paper IDs：
- 已有授權及限制（本機／候選／驗證後發布、未開放範圍）：
- 原件與配對 manifest 位置：
- 最新正式程式／題庫基準及取得時間：
- 自有輸出目錄、工作區、必要工具、瀏覽器 lease／target（如使用）：

預設：Codex 獨立解題＋Claude 複核，實質分歧才找 AGY。小問題有證據能定案即驗證並依已有授權完成，不逐題等待教師。有官方完整稿依稿製播，缺稿可製作明示改編聽力，保留原題、官方 raw 及缺稿事實。確需使用者選擇才附證據提問，其餘繼續。

## 媒體與聽力

- 圖片 manifest、原頁預覽、圖片 QC：
- 稿件身分：官方完整稿／缺稿改編，不因已有合成音就填官方稿。
- 稿／題／答案對照、改編標示與配分說明：
- 聲音、語速、重複方式、工具版本、音訊 manifest：
- 解碼、音量、無提示 ASR、重複播讀及真播放器結果：
- 真人抽聽範圍（若有；未知題號或數量如實寫，不填全段完成）：

## 驗證與發布收據

- 來源逐題校對、原卷與線上配分帳本：
- 真 SQL 正錯／變體／多欄／集合／排序／自核／60% 邊界：
- 完整作答、重作、重送、歷次、舊版鎖定、跨版只一葉：
- 桌面及 390／360 手機視窗全題組、畫圖／復原等操作：
- 真私有 Storage、授權、學生安全 payload、換帳號／延遲回應：
- 教師預覽正確帳號、指定 paper、題卡及音軌載入：
- 證據層級：模擬 OAuth／本機 SQL／正式 SQL rollback／正式 Storage／真人帳號／實體手機，逐項如實寫。
- 正式測試 rollback、學生資料及無關內容未變證據：
- 候選版本、hash、實際啟用版本、時間、開放範圍及正式重查：
- 回復版本／方法、自有 worker 與測試資料清理：

## 可重用起始提示詞

> 請依本任務契約及《考古題製作與上線指南》完成指定範圍。先查原件、版本、試卷解答配對、現有系統契約及最新正式基準，做 5–10 題代表小樣再補完整卷。保留原題、官方 raw、原頁、SHA 與修訂來歷。小問題先獨立解題並與 Claude 複核，實質分歧再找 AGY；能定案即驗證並依已有授權完成，不逐題等待教師。缺官方聽力稿可製作明示改編版，不假稱官方原音。逐一檢查題型、網站風格、手機、媒體權限、重作、首次完整達 60% 給葉、歷次及舊版相容。不用舊工作區／批次腳本蓋回正式後續修正，不改寫學生既有答案、進度與歷次。真正需要我決定才附原題、官方解答、討論結論及影響提問，其餘繼續。交付檔案、驗證、耗時與限制，更新交接及原記憶鍵。
