# 考古題製作任務與交接範本

搭配[考古題製作與上線指南](past-exam-playbook.md)。由執行者從任務、原件與現有系統自動補齊；這不是教師逐項簽核表，也不是可直接匯入的題庫 schema。複製到每次私有輸出目錄後，不適用項保留並註明原因，不能默默刪除必要交付條件。

## 任務契約

- 任務識別／日期／開始時間：
- 來源學校與穩定識別碼：
- 試卷學年／學期／考次／年級／科目／出版社與版本：
- 目標網站、管理者、學生目前學年／學期：
- 指定卷數與 paper IDs：
- 已有授權及限制（本機／候選／驗證後發布、未開放範圍）：
- 原件與配對 manifest 位置：
- 最新正式程式／題庫基準及取得時間：
- 自有輸出目錄、工作區、必要工具、瀏覽器 lease／target（如使用）：

預設：Codex 獨立解題＋Claude 複核，實質分歧才找 AGY。小問題有證據能定案即驗證並依已有授權完成，不逐題等待教師。有官方完整稿依稿製播，缺稿可製作明示改編聽力，保留原題、官方 raw 及缺稿事實。確需使用者選擇才附證據提問，其餘繼續。

解析、學習重點與書商配題隨本卷製作同步完成並固定版本；學生線上只讀已確認資料，不即時呼叫AI。這是製作要求，不代表通用工具或正式adapter已存在；先查實際支援能力。

## 整卷配題結構（隨卷完成）

- paper ID、固定內容版本／SHA、原卷來源檔／頁次：
- 原卷已列出的獨立題數、題組數、各組子題／作答目標數、合計與計數例外：
- 單位及子題穩定ID、原卷題號、共同材料範圍、跨頁／承上依賴：
- 現有group／field對應、來源子項識別；多格單題與一欄多題的處理：
- 共享同一field的storageCouplings、必須同人及adapter限制：
- 複選選項完整保留、是非命題、排序／整體找錯、共用詞庫與聽力的分類證據：
- 原卷、可作答、blocked／彙總佔位、選做與人工自核的不同數量；無題目口試／缺頁／未知數量：
- Codex判讀、Claude疑義複核、實際看過的原頁、採認理由與未解項：
- 欄位／來源子項完整唯一覆蓋、加總、版本／SHA、不可用與選做狀態的驗證收據：
- 結構版本／交付位置、可供adapter使用範圍；未接多人配題／未上線限制：

沿用SOP「整卷配題結構整理」的計數規則。不能拿technical group／輸入格數代替題組／子題數，不因盤點重算配分、花葉或舊作答。

## 解析、重點與書商配題（隨卷完成）

- 逐題解析位置、核對答案依據、官方／書商／AI補充標示：
- 本卷重點清單：穩定ID、標題／內容、適用範圍及證據；多題共用，不冒稱未核實的書商知識代碼：
- 題目識別：學校／paper／內容版本／題組／欄位；到重點的連線及理由：
- 候選篩選：程式採用的年級／科目／教材範圍／章節／可靠索引、AI實際比較資料：
- 每重點預備兩題的原始書商來源、原題ID、版本／章節、原答案／解析、必要圖文聽力與SHA；格式轉換／AI補充：
- Codex獨立判讀、Claude複核範圍／結論；實質分歧才用AGY及其實讀資料：
- 各題狀態：已複核可用／無可靠配題／不適合延伸／疑義；原因、實際可練題數、尚缺項：
- 固定解析／重點／練習版本、依賴對照、雜湊與manifest位置；後續只重核受影響部分：
- 小樣整條流程：我的錯題→解析→自選重點→固定書商練習→回同次同版本原題：
- 學生端只讀固定資料、零即時AI請求、揭答前無答案、本人隔離／刷新／換帳號／晚回應驗證：
- 原卷成績／歷次／葉片不變，人工自核不判錯，延伸無額外葉片／不自動遞迴推薦；缺配題不顯示可開始按鈕：
- 全卷題數、解析／重點處理覆蓋率、可用練習數及缺項；未配到不冒稱完成，不因此一律暫停原卷：

## 每題疑義／修訂紀錄（有需要才新增）

- 原題 ID、版本、頁碼、圖／共同題幹及來源 SHA：
- 原題與官方答案 raw：
- 問題分類、Codex 獨立解答：
- Claude 意見、實際讀取資料及限制：
- AGY／一手來源（若有）、分歧及反證：
- 最終採認與理由：
- 修訂類型：轉錄更正／線上答案勘誤／等價答案／補圖／明示改題／改編聽力／保留未開放。
- 原始配分、線上配分及是否另訂改編細則：
- 新版對應題組／欄位、驗證案例：
- 若仍需使用者決定：未解選擇、影響、原題／官方解答證據、建議；不受影響部分進度：

## 媒體與聽力

- 圖片 manifest、原頁預覽、圖片 QC：
- 稿件身分：官方完整稿／缺稿改編，不因已有合成音就填官方稿。
- 稿／題／答案對照、改編標示與配分說明：
- 聲音、語速、重複方式、工具版本、音訊 manifest：
- 解碼、音量、無提示 ASR、重複播讀及真播放器結果：
- 真人抽聽範圍（若有；未知題號或數量如實寫，不填全段完成）：

## 驗證與發布收據

- 來源逐題校對、原卷與線上配分帳本：
- 真 SQL 正錯／變體／多欄／集合／排序／自核／60% 邊界：
- 完整作答、重作、重送、歷次、舊版鎖定、跨版只一葉：
- 桌面及 390／360 手機視窗全題組、畫圖／復原等操作：
- 是非表示法與四畫面（個人／夥伴／共同回顧／教師預覽）及已作答摘要符號不重複、原始 ID 暫存及送答不變、一般兩選項與圖文未被誤改：
- 真私有 Storage、授權、學生安全 payload、換帳號／延遲回應：
- 教師預覽正確帳號、指定 paper、題卡及音軌載入：
- 證據層級：模擬 OAuth／本機 SQL／正式 SQL rollback／正式 Storage／真人帳號／實體手機，逐項如實寫。
- 正式測試 rollback、學生資料及無關內容未變證據：
- 候選版本、hash、實際啟用版本、時間、開放範圍及正式重查：
- 回復版本／方法、自有 worker 與測試資料清理：

- 自動化、AI 複核、人工操作／抽查、限制：
- 內容製作與工具開發成本分開；AI用量／token僅有實際紀錄才報，重用原頁／共用題幹／重點／固定成果的結果：
