## 目標與範圍

以115學年度上學期三、六年級的五個考科為範圍，共10個年級科目組合。目標是各科可依課／單元自組卷、選難度、保存接續及回看錯題；具備可靠學習重點與候選題的科目再開放同重點延伸。

建議每科先開放期中前範圍，再擴充到全冊。十科先做輕量盤點，完整課次與來源範圍先對齊；逐題深度轉換及核對先做試點，再逐科擴充。每批分清原題、子題、抽選單位、可用與待處理題量，不用「全科已上線」代表所有來源題型均已啟用。

## 工作順序與交付

### 1. 十科輕量盤點與跨書商代表樣本

每科列出光碟／來源路徑、版本冊次、全冊課／單元順序、期中範圍、原題／子題／共用材料、題型、難度、學習重點、解析、媒體、已核對與待修狀態。

先量到各欄實際覆蓋率、題組比例與格式差異，尚未量到者明列待盤點。提早核對翰林六上數學、南一六上自然、康軒國語及兩版英語聽力的代表樣本；用結果確定最小共同資料契約，避免只用翰林格式就凍結通用架構。完整十科逐題深度目錄不作為首個試點上線前提。

先檢查7份既有ISO與已擷取來源的可讀性及對應範圍；需要的檔案確實缺少時才補取。原始書商資料維持唯讀，原題內容與憑證不進公開Git。

### 2. 將三上數學流程改成通用多科架構

**前置門檻：課程隔離與相容測試完成前，其他科資料只可進離線／待發布區，不得成為現有池的可抽題。** 現況只有三上數學一科，沒有確認已發生混題；風險是在不同課程可用題的單元ID重疊且符合抽選條件時發生。

- 以學年度／學期／年級／科目／版本／冊次識別課程，單元與學習重點隸屬該課程。三上數學第1單元與六上國語第1課不會混在同一抽題範圍。
- 統一可用池的課程、課次、原題ID、子題ID、內容家族、原始分類、正解、解析與審核版本。原始ID保留，跨書商同號不碰撞。
- 原題、子題與來源修訂的識別分開；共用材料題組ID與內容去重家族是兩種關係，不共用含糊的group欄位。
- 後端由名冊判斷年級與可用課程；學生只能選已開放的科目與單元，不能靠更改參數抽其他年級、未核對題目或讀取未揭答答案。
- 前端按科目載入課次名稱及可用量，沿用命名／改名／刪除、完整個人清單、科目篩選及實際配比。
- 舊三上數學紀錄以明確的相容規則接回；固定版本與歷史答案不重寫，既有連結可繼續使用。
- 清除寫死點清單包含：三年級名冊條件、catalog只開三年級、單元1～9限制、前端只初始化三年級、九個數學單元名稱、卷標題與版本資料、延伸只辨識數學及其可用條件。
- 舊請求未帶課程時只沿用原三上數學契約，不能因此改變已保存config造成重試衝突；舊request須回傳同一份固定卷，不要求全新請求永遠抽到舊演算法的相同題目。
- 預設卷的舊題對照須包含課程、原版本、原題／子題及修訂，延伸依凍結的來源修訂查回，不以字串拼接原題號或直接套最新修正版。查回不唯一者先不提供延伸。
- 學生可合法切換本人年級已開放的科目；須拒絕的是跨年級繞過，以及把其他課程的單元／題目／重點混入已選課程。

### 3. 按書商建立可重跑的來源轉換

重用既有翰林SQLite、康軒Access與Word、南一Access與Word書籤，以及英語舊格式／音檔的擷取方法。批次處理以程式為主，先用涵蓋特殊格式的代表樣本核對，再擴到該格式全量；未知格式進待處理清單。

- 題幹、選項、共用材料、答案及原解析分開擷取，保留來源路徑及比對依據。
- 全量驗證結構、選項ID、答案對應、媒體引用、去重與缺漏；原畫面抽查按題型／特殊格式／媒體分層，不能把抽樣稱逐題人工驗收。
- 解析引用原選項編號者建立原選項ID與顯示順序對照，核對能安全映射才啟用；尚不能保證對應者保留在待處理清單。
- 沒有詳細原解析者保留正解與中性缺解析提示，不捏造原解析。

### 4. 分科內容核對

| 科目 | 優先核對 |
| --- | --- |
| 國語 | 國字／純注音／附注音、聲調、多音字、標點、底線及閱讀共用材料；沿用標楷體與已核對的特殊字型轉換，未知字碼不猜讀音 |
| 數學 | 分數／算式、單位、原圖、表格與答案；公式依可見原圖核對，不只信舊OLE值 |
| 社會 | 地圖、圖例、表格、年代、示意圖及材料依賴 |
| 自然 | 實驗圖、圖中標籤、觀察表、流程與共用材料 |
| 英語 | 原版音檔與題目對應、播放／重播、文字與圖片選項、共用聽力材料，沿用Andika字型 |

第一批以已可靠支援的單選為主。閱讀／圖表／聽力題組須整組保留材料，抽題前核對整組題數、上限20題與揭答時機；不能為湊配比切斷材料。其他題型如是非、填充、連連看、計算等，分別盤點題量與輸入／判分／解析需求，再分批啟用。

首批自組池限定可獨立作答、必要文字／圖片／原音檔均已完整保留的單選。現行compose會另建空material，依賴共用材料的題組子題不得直接標可用，先留在已驗證預設卷或待處理清單。

後續題組設計契約：以整組為原子抽選單位，題數按子題算、材料不計題，不超所選題數與20題；放不下改找其他可放單位，仍不足就少出，不能切組或擅自加題。配比依子題原難度統計；易卷不含難子題、難卷不含易子題。保留組內次序與block揭答。這是待樣本驗證的後續設計，不代表抽選演算法已完成。

選項或解析依賴原編號／位置，以及前題揭答可能洩漏後題的情況，都列為該題／題組的發布門檻；未解決前不啟用。「以上皆是」需依實際語意核對，不一概視為不可亂序。既有引擎有block揭答契約，驗收重點是新抽題有無保留正確block，而非假設舊引擎必然逐子題洩漏。

### 5. 接上各科錯題延伸

- 先查各書商是否提供逐題學習重點，保留原始分類。學習重點代碼以課程為範圍，不把不同書商或科目的同名代碼視為相同。
- 有可靠分類者沿用同重點、相近或較低難度、有解析、排除原內容家族的規則。
- 缺分類時先提供一般組卷及錯題回顧；另列待核對映射。不能只因同單元就宣稱同重點延伸，更不能宣稱診斷錯因或精熟。
- 預設卷的舊題ID也要能回查新池來源，避免只支援從新自組卷產生的錯題。

資料缺漏採逐題處理：

| 缺漏 | 處理 |
| --- | --- |
| 無詳細原解析 | 可一般出題，顯示中性提示；維持不列入現行延伸候選 |
| 無可靠學習重點 | 可一般出題及回看錯題；該題不提供或不列為同重點延伸，其他可靠題照常 |
| 無可靠難度映射 | 該題不進三種難度自組池，不一律預設中；整科皆無可靠難度才只保留已核對預設卷 |
| 正解、選項對應、注音、媒體或必要材料無法確認 | 該題／題組先不啟用 |
| 亂序位置依賴或揭答洩漏未解決 | 該題／題組先不啟用 |

既有期中康軒、南一轉換目錄已有難度欄，康軒A/B/C映射亦有歷史依據；仍需逐科保留來源映射證據並盤點全冊覆蓋率，不能把期中結果當全冊驗收。短卷不設5題啟用門檻：1～4題也可依定案如實出題，零題才不建卷。

### 6. 媒體、容量與私有備份

- 圖片沿用私有Google Drive＋Cloudflare Worker，以內容雜湊去重、只上傳新增素材；Supabase保留登入、驗權、組卷及作答紀錄。
- 原版音檔先沿用既有授權讀取路徑，盤點全冊音檔的增量、格式與流量後再評估是否調整。
- 各批記錄新增圖片／音檔／資料庫大小及實際讀取情形，檢查大量資料下的抽題與清單效能；不拿先前期中素材大小推估全部全冊容量。
- 保存原始來源、轉換程式、私有素材索引與可重跑報告；被Git忽略的資料需另作私有備份並確認可復原。
- 仍被可回看固定版本引用的媒體內容鍵與位元組不可刪改；無引用素材待另有保留政策才議清理，本計畫不授權刪除。
- 先量課程過濾後的抽題／catalog、既有作答次數排序、清單與一班同時使用的效能，並以預計題池及累積答案規模測試；是否調索引或查詢依量測決定。

### 7. 每批驗收、開放與維護

每科每批完成以下條件才開放：

1. 原題、可用題與待處理題數能對帳，來源版本及開放單元明確。
2. 易／中／難×題數、自動補題、缺題提示、內容去重與單元限制正確。
3. 題目／選項／正解／原解析對應；重點格式、標點、注音、公式、圖表、音檔有核對證據。
4. 三／六年級本人授權、未揭答保護、私有媒體及跨科／跨年級拒絕通過。
5. 本機試卷走到答錯解析、最後一題回饋、雲端保存／重整接續、錯題與可用延伸；桌面／390px正常。
6. 正式匯入以新增版本為原則，核對既有答案及版本未遭覆寫；只在新建驗收卷作答。
7. 以可追溯清單管理可用／待修／停用，修正有來源與新版本，不擅自重算歷史答案。
8. 每批有匯入識別、待發布／已啟用狀態，資料與媒體核對通過才一起開放；失敗不半開放。回退只停用新池批次，保留已生成試卷、答案與舊媒體引用。

## 建議批次

| 首三工作包 | 最小產出與硬門檻 |
| --- | --- |
| 1. 輕量十科盤點＋跨書商樣本 | 翰林六上數學、南一六上自然、康軒國語及兩版英語聽力先驗代表格式；量欄位覆蓋率，定原題／子題／修訂／材料／難度契約，未知者列待處理 |
| 2. 課程隔離骨架與相容 | catalog、compose及延伸都限定課程；移除寫死點；舊request、固定版本與來源修訂可追溯；加入其他課程測試題後，三上數學不混題；跨年級及課程關係不符被拒，匯入失敗不半開放 |
| 3. 翰林六上數學＋南一六上自然期中試點 | 先啟用可靠獨立單選；題數對帳、三模式×四題數、自動補題與短卷、解析媒體、本人授權、舊卷及390px通過；延伸只用可靠分類及有解析候選 |

第1、2包可在不凍結未知資料契約、不開放新科的前提下交錯進行。試點後再擴三上自然、康軒國語／社會、南一社會及兩版英語；仍優先補全科期中可抽池，再擴後半冊。題組、其他題型依樣本結果另分批啟用。

實際順序依盤點結果調整，無資料前不承諾確切工期或全量題數；完整十科深度轉換、題組演算法及全題型不作為獨立單選試點上線前提。
