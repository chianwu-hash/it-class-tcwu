# 考前練功坊圖片儲存硬規則

生效日期：2026-11-08。適用本專案的一般題庫、考古題、轉錄／轉化、解析、延伸練習及課本參照製作。這是後續製作的規範，不代表既有媒體已完成遷移，也不是自動執行的程式檢查器。

## 唯一預設圖片路徑

**新製作或修訂的題目圖片、選項圖、共同材料圖、解析圖、官方參考圖及課本頁面 WebP，一律存放私有 Google Drive，經既有 Cloudflare Worker 驗權提供。不得因一般題庫／考古題／教師發布入口不同而改用另一個圖片雲端。** Supabase 負責登入、媒體可見性、題目與作答紀錄等控制資料，不作這些新圖片的預設儲存或轉送位置。

- 使用既有已核對的學校帳號與受控圖片庫；上傳前確認實際帳號、資料夾及既有工具，不猜路徑，不另建公開圖床。課本可用專屬子資料夾與教材版本識別，仍走同一私有供圖架構。
- 禁止新傳、複製或同步圖片到 Supabase Storage、公開靜態網站、公開 repo、公開 Drive 分享或其他圖床，除非使用者另有**明確且可追溯的該項例外授權**。授權製作、上線、修正故障或同意整體任務，不得自行解讀為允許變更儲存架構。
- 不得以「舊程式只支援 Supabase」「參考圖另有揭答時機」「本機或舊案例曾成功」「急著完成」為理由放錯位置。若 `freeze`、考古題路由、Worker 白名單或授權尚不支援，記錄缺口，先完成本地素材／對照／候選接線；受影響項目保持待完成，不新增 Supabase 副本、不偷偷 fallback、不宣稱已上線。所需程式／資料庫／發布變更仍依各自授權與 main／PR 流程辦理。
- 儲存位置與授權時機分開設計。題目素材、解析及官方參考圖須依原卷固定版本、學生／教師身分、作答及自核狀態驗權，不能為統一儲存而提前揭答。課本參照依其已確認的登入與學習存取規則辦理，不能直接沿用答案圖的顯示時機。

## 音檔、舊檔及例外

- 音檔不在本次圖片統一範圍，維持既有 Supabase 私有音檔及播放授權流程；不得順便遷移或新增其他服務。
- 既有 Supabase 圖片、備援與舊作答版本先保留。此規則不授權遷移、刪除、覆寫、改既有路由或重跑歷史發布。使用既有圖片時逐筆標記實際 backend 及舊版相容範圍，不能把舊檔例外沿用為新圖預設。
- 如確須偏離，先列具體檔案／類型、原因、目的服務、權限與流量影響、替代方案及回復方法，取得使用者明確例外指示，再把日期、範圍、來源與期限／回復條件記入任務契約。不得用執行者自己的交接摘要冒充使用者授權；沒有例外證據就維持本規則。

## 上傳、接線及發布前必查

由執行者填寫並附實際收據，不要求教師重填技術資料。任一必要項未完成，不得標記該媒體已完成或發布。

1. **先列目的地**：manifest 逐檔記錄素材角色、來源與內容版本、SHA-256、MIME、bytes、預定 backend、私有 Drive file ID／資料夾及 Worker 索引鍵；敏感索引與原件留私有輸出，不提交公開 repo。課本另保留教材版本、印刷頁碼、PDF 頁序及完整拉頁對照。
2. **核對原件**：上傳前依內容雜湊去重；回應未知先對帳，不盲目重傳。上傳後回讀來源位元組並比對 SHA-256、MIME、bytes，確認檔案非公開分享。
3. **核對正式路由**：確認題庫登錄、實際授權回傳 backend、Worker 私有白名單及儲存位置一致；新圖片不能仍被考古題等舊路由強制導向 Supabase。只傳好 Drive、只產生 ticket 或本機圖可顯示，都不算接線完成。
4. **驗證真實供圖**：從目標網站的授權流程經 Worker 取得原始圖片位元組，核對 SHA-256；確認這些圖片內容不經 Supabase／Vercel 轉送。測冷圖自然載入、跨頁／裁切、桌機與手機、登出／換人、匿名／竄改／過期票證及未到揭答時機的拒絕。授權與顯示檢查分開留證。
5. **交付對帳**：列出新圖、重用舊圖、音檔、已核准例外及待補媒體的數量、位置、實際讀取 backend 與驗證狀態；無未說明的 Supabase 新圖片、無不明副本或繞路 fallback，才能宣稱該範圍完成。
