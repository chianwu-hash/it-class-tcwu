## 一、功能範圍草案

| 功能 | 第一階段建議做到 |
|---|---|
| 題目建立 | 匯入既有Markdown題目，也能在教師頁新增與修改；匯入先預覽並指出缺答案、格式或題組錯誤，再確認儲存 |
| 題庫管理 | 分類、標籤、搜尋、草稿/可用、題目預覽；可用題目才可加入正式測驗 |
| 版本 | 題目修改可產生新版；已發布場次使用當時版本，保留當時題目、判分依據與媒體；不追改舊成績 |
| 選擇題 | 建議先單選，含文字/公式/圖片選項；選項可保留原序，避免打亂破壞題意。多選尚未確認，不默認已包含 |
| 簡答題 | 短文字/簡短數字字串答案，可設多個可接受答案；採明確文字比對，未符合者保留原始答案供教師覆核，不做AI語意評分或代數判等 |
| 題目內容 | 文字、表格、一般數學/物理公式與圖片；題幹/選項/解析可使用支援內容，音檔可置於題幹或題組材料並預覽試播 |
| 媒體管理 | 上傳、選用、替換、圖片放大、音檔手動播放/暫停/重播、載入失敗提示；舊版本引用的媒體仍保留 |
| 基本題組 | 一份共用文章/圖表/音檔加多個單選或簡答子題；選入測驗時整組保留，組內順序固定，切子題仍可查看材料 |
| 組卷 | 老師手動選題/題組、設各題分數並預覽；題序/選項亂排可分別設定。題組內題序固定，不混入全卷亂序；題組整組的位置是否隨卷亂序尚待確認。亂排既有題序不等於從題庫隨機抽題 |
| 即時上課 | 老師開場並監看，學生登入同場後自行作答與進下一題/題組；老師看到各人進度、完成狀態與結果，管理整場開始/結束，不逐題開放或收答 |
| 遊戲回饋 | 基本得分、作答進展、結算慶祝與排行榜；暫不做速度加分、道具商店或複雜遊戲模式。待覆核簡答時明示暫算結果，覆核完成才定最終排名 |
| 紀錄與復原 | 保存作答成功後的狀態，重複送出不重複計分；師生重整/斷線可接回同場次，沒有伺服器收件確認就不能顯示已交卷 |
| 教師結果 | 查看各題/各學生作答、簡答覆核、修正紀錄與最終成績；結果依學生身分與教師權限提供 |

簡答細節建議：去除答案前後空白；可由教師明示是否忽略英文字母大小寫。全形/半形、標點、單位等不任意刪除；如需接受不同寫法，由教師列出可接受答案。此為首版建議，不假稱能理解所有答案。需覆核者先顯示待確認，不能讓學生將暫算分數誤認最終成績。

## 二、老師的操作流程

### 課前備課

1. 登入教師入口，開題庫或建立新的分類。
2. 匯入既有題目，或新增單選/簡答；填題幹、選項或可接受答案、解析與分數。
3. 插入圖片、公式、音檔；題組先放共用材料，再新增子題。
4. 看匯入檢查與媒體狀態，修改後以學生畫面預覽，切換揭答前/後試看並試播。
5. 題目標為可用，選題與題組組卷，設定順序及班級後發布此版本。

### 課堂進行

1. 開啟測驗場次，顯示學生加入入口或房號，確認進入正確班級/場次。
2. 查看加入名單；學生完成耳機試播後開放場次。
3. 學生各自閱讀、聽音檔、作答並前進，不必等全班。
4. 老師監看每人已答/未答與完成情況，處理個別媒體或作答問題，不替學生逐題切換。
5. 依教師所選揭答模式執行：逐題模式下一般單題送出後顯示正誤/正解/解析，題組則等該學生答完整組才顯示正解與解析；整份模式則等該學生自己答完整份才對答看解析。皆不等全班，老師不逐題控場。
6. 老師結束整場或依整場截止規則結束（待定）。中途結束須明示未完成題目，不補造作答或完成紀錄。

### 課後確認

1. 查看自動計分與待確認簡答；可於課堂空檔覆核，也可課後處理。
2. 教師確認接受/不接受並保留修正原因、原始作答及原判定；如接受新寫法，是否加入往後可接受答案需另行明示。
3. 有待確認答案時先顯示暫算成績；覆核完成後更新最終成績與排名，學生可回看已允許公開的題目及解析。

## 三、學生的操作流程

1. 從課程網站進入測驗，使用既有登入與名冊身分，加入老師指定場次。
2. 確認自己的身分、場次與耳機；場次開放後開始個人作答。
3. 依自己的進度閱讀內容，需要時放大圖片或自行播放音檔。
4. 單選點選答案；簡答輸入短文字；題組可查看共同材料。可否跳題/回頭修改尚待設定。
5. 按送出並等候「已收到」；失敗可重試，已收到後如何修改或重答仍待確認，不能把網路重送與另一次作答混淆。
6. 按本場設定查看回饋，自己進下一題/題組，不等老師開題；待覆核簡答明示狀態。
7. 斷線或重新整理後，接回目前場次及伺服器已收到的作答；未送出的文字不承諾復原，不儲存正式進度於localStorage。
8. 結束後查看自己的暫算/最終成績及允許公開的排名；不發努力樹葉片。

## 四、個人進度模式下待討論的課堂規則

### 簡答與排行榜

可接受答案自動判對；未匹配者待教師確認。處理完成前排行榜明示暫算，不把待確認直接當最終錯誤。基本分數不加速度分。

### 耳機音檔與計時

學生戴耳機自行播放已確認。整場截止、逐題計時、重播次數、速度是否影響分數仍待討論，不能沿用老師逐題收答的舊設定。前端按鈕限制不等同防下載或防重播。

### 題組

學生依自己的進度進入題組，材料與子題保持整組；其他學生可在不同題目或不同組。使用者已確認組內題序不變、選項可亂排，正解與解析不得早於該學生答完整組；逐題回饋模式即在整組完成後顯示，整份回饋模式仍等整份完成。整組位置是否跟隨全卷亂序、組內回頭/送出方式仍待確認；題組未完成時是否先顯示純正誤，本次未另定，不由正解/解析規則自行推定。

### 教師可選的揭答與亂序設定（使用者已確認）

- 逐題回饋：每題送出後立即得知正誤、正確答案與解析，再自行進下一題。
- 答完後回饋：作答過程先不揭露，該學生自己答完整份後對答看解析，使用者已明確確認不等全班。
- 題目亂序與選項亂序獨立設定。題組內的子題順序始終固定，選項可亂排。
- 題組的正確答案與解析須等該學生完成整組才顯示，已由使用者確認；整份回饋模式仍維持整份完成才顯示。整組位置規則仍待確認；簡答待覆核時不能假稱已能確定正誤；不因亂序就默認A/B等互相引用的選項一定可安全洗牌。
