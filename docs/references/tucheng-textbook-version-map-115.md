## 本次接入需求與契約衝突

使用者要求土城四年級學生使用現有努力樹及題庫，並為既有學校測試帳號新增 407 班 30 號（40730）測試身分；本人正式帳號與姓名稍後提供。

使用者已於 2026-11-01 確認擴充原共用契約；正式名冊與四年級測試切換已登錄，首批四科題池匯入後待正式入口驗收。發布進度另記於 `docs/development/tucheng-grade4-release-20261101.md`，不得將候選題或私有匯入當成全部已上線。

下列原有限制已依專案 AGENTS.md 回報，並經使用者確認採擴充共用模組的方式處理；不能只新增名冊或複製三年級頁面宣稱完成：

- `supabase/quiz-pool.sql` 的 `quiz_courses.grade` 只允許 3、6；組卷名冊與試卷命名也有限定。
- `shared/quiz-grade-route.mjs` 只接受三、六年級；四年級沒有既有正式入口。
- `supabase/test_identity_switch.sql` 只支援 30730、60930，並修改既有同一筆測試名冊。新增身分時應保留兩個原身分及既有成果，不能覆寫成只剩 40730。
- `my-tree.html` 的題庫成果載入目前只接三、六年級；`supabase/quiz-rewards.sql` 也限制年級解析。
- 正式題庫後端有後續批次效能修改，主工作區與正式發布來源不同；不能重裝舊 SQL 或整包部署目前的混合工作區。

四年級已獲准納入原共用契約。仍須逐科確認可上線範圍與答案／媒體，驗證跨年級隔離、40730 切換及正式保存／得葉後，才可稱該批已上線。不得借用三、六年級題目冒充四年級。
